# Chronicle Demo 范围规格

**文档定位**：Demo 阶段边界文档
**依赖总纲**：`texts/CHRONICLE_CORE_DESIGN_GUIDE.md`
**版本**：v0.1
**日期**：2026-06-13

---

## 1. 本文档的作用

本文档用于限定 Chronicle Demo 阶段到底做什么、不做什么。

Demo 的目标不是展示完整游戏，也不是堆系统、堆地图、堆事件。

Demo 只验证一件事：

> Chronicle 的核心玩法是否成立：
> 世界先自行演化，玩家在其中选择人生方向，关键节点来自世界状态，选择会留下长期回声，最终能被纪事系统回收。

---

## 2. Demo 核心目标

Demo 必须验证以下五件事：

1. **事件来自状态，而不是事件池。**
2. **选项来自可行动性，而不是固定按钮模板。**
3. **玩家选择能改变人、地点、关系和未来。**
4. **长期人生模式能产生时间厚度。**
5. **纪事文本能回收真实发生过的经历。**

如果 Demo 只是：

```text
随机事件
三个选项
数值变化
获得印记
继续抽事件
```

则 Demo 失败。

---

## 3. Demo 最小范围

Demo 只做一个小世界，不做大地图。

### 3.1 地点范围

Demo 只包含两个核心地点：

```text
湖湾镇
第七哨站
```

湖湾镇用于验证：

```text
地区慢变量
粮食危机
NPC 需求
短期状态事件
玩家介入后的局部变化
```

第七哨站用于验证：

```text
长期人生模式
固定人物变化
重复仪式变化
五年服役
离别
旧物
错过感
```

---

## 4. Demo 主要人物

Demo 不需要大量 NPC。

建议控制在 8–12 个核心 NPC。

### 4.1 湖湾镇 NPC

```text
老陈：店主，受粮价和债务影响
陈米：老陈女儿，粮食危机链的核心人物
粮商：掌握粮食流通，可能成为压迫者或交易对象
镇守卫：秩序代表，可被利用、求助或对抗
药师 / 老妇：提供地方记忆和草药线索
```

### 4.2 第七哨站 NPC

```text
罗恩：队长，沉默克制，代表军纪和旧物传承
伊莱：新兵 / 战友，适合做多年回声
玛塔：厨子，用食物表达关心
赛拉：军医，记录伤病、死亡与旧伤
霍克：老兵，代表边境经验与退役阴影
妮娅：传令兵，连接外部世界消息
```

NPC 不要求一开始都有完整系统。

但至少要有：

```text
身份
位置
关系
需求
记忆
状态变化
可被纪事回收的痕迹
```

---

## 5. Demo 慢变量

Demo 只保留 3 个主要慢变量：

```text
粮食
治安
战争张力
```

### 5.1 粮食

影响：

```text
粮价
饥饿
偷窃
债务
商队
走私
疾病
```

### 5.2 治安

影响：

```text
巡逻
盘查
盗匪
举报
抓捕
道路安全
```

### 5.3 战争张力

影响：

```text
征兵
军粮
边境冲突
哨站损耗
死亡名单
服役压力
回乡变化
```

Demo 不要一开始加入复杂经济、完整生态、复杂政治、全大陆战争。

---

## 6. Demo 人生模式

Demo 只做两种人生模式：

```text
定居
服役
```

### 6.1 定居模式

玩家在湖湾镇停留一段时间。

目标：

```text
验证地区状态如何生成生活场景
验证 NPC 需求如何暴露为痕迹
验证玩家是否能改变一个家庭或地方
```

示例链条：

```text
粮食下降
↓
粮价上涨
↓
老陈欠债
↓
陈米饥饿
↓
陈米偷发霉麦子
↓
玩家看见她藏袋子
↓
玩家介入或无视
↓
老陈一家状态改变
↓
湖湾镇后续变化
```

### 6.2 服役模式

玩家进入第七哨站服役五年。

目标：

```text
验证长期时间压缩
验证固定人物多年变化
验证重复仪式变化
验证离别文本是否有真实状态支撑
```

服役不做成五个随机事件。

服役必须包含：

```text
年度摘要
固定人物变化
重复仪式
战友情
旧伤
错过家乡
退役离别
```

---

## 7. Demo 阶段结构

Demo 推荐分为四段。

### 第一段：湖湾镇

验证短期状态链。

玩家能看到陈米藏发霉麦子的场景。

该场景必须来自真实状态链，而不是手写固定事件。

### 第二段：第七哨站

玩家选择服役，进入长期人生模式。

系统推进五年，但只展示关键节点。

### 第三段：回到湖湾镇

玩家回到湖湾镇。

湖湾镇状态根据玩家早期选择和五年世界推进发生不同变化。

### 第四段：纪事片段

系统生成一段短纪事。

纪事必须引用真实经历，而不是泛泛总结。

---

## 8. Demo 必须有的系统

### 8.1 世界状态

至少包含：

```text
地点状态
NPC 状态
关系状态
慢变量
世界事实
痕迹
记忆
```

### 8.2 线索 / 痕迹系统

玩家看到的不是变量，而是痕迹。

示例：

```text
关门
涨价告示
发霉麦子
空货架
雪夜点名
旧短刀
硬面包
弓弦
缺席的名字
```

### 8.3 可行动性选项

选项必须来自玩家状态和场景状态。

例如：

```text
玩家有食物 → 给她食物
玩家有钱 → 买下麦子
感知高 → 发现粮食异常
与老陈关系好 → 进屋找老陈
地区有守卫 → 举报
道德低 / 商人倾向 → 低价收购
```

### 8.4 长期回声

早期选择必须在后续出现。

例如：

```text
救过伊莱 → 后续伊莱替玩家说话
帮助陈米 → 回乡后陈米记得玩家
举报陈米 → 回乡后老陈一家命运变差
无视粮食危机 → 湖湾镇更冷漠或更贫困
```

### 8.5 纪事系统

Demo 结束时输出短纪事。

纪事必须引用真实发生过的：

```text
人物
地点
物品
旧伤
承诺
错过
离别
```

---

## 9. Demo 明确不做的内容

Demo 阶段暂缓：

```text
大地图
大量地区
复杂魔法
复杂装备词条
完整职业树
完整经济系统
大型战斗系统
大量随机事件
本地 AI 叙事模型
复杂 UI 美化
完整存档系统
```

这些不是废弃，只是 Demo 阶段不优先。

---

## 10. Demo 验收标准

Demo 通过必须满足：

1. 陈米藏麦子场景能追溯到粮食状态链。
2. 玩家看到的选项会因物品、关系、属性、地区状态变化。
3. 玩家早期选择能在五年后改变湖湾镇或 NPC 状态。
4. 第七哨站服役能体现固定人物、重复仪式、旧伤和离别。
5. 退役文本背后有真实状态支撑。
6. Demo 结束纪事能引用玩家真实经历。
7. 玩家能理解自己不是在刷事件，而是在经历一段人生。
8. 世界在玩家不看时仍会变化。

最核心标准：

> 玩家读到退役离别和回乡文本时，能相信这几年真的发生过。

---

## 11. 当前开发优先级

### P0：先跑通核心闭环

```text
状态 → 行为 → 痕迹 → 选择 → 后果 → 回声 → 纪事
```

### P1：湖湾镇短期链

```text
粮食危机 → 老陈一家 → 玩家介入 → 后续变化
```

### P2：第七哨站长期链

```text
服役五年 → 战友变化 → 仪式变化 → 退役离别
```

### P3：纪事输出

```text
把真实经历整理成短文本
```

### P4：再考虑 UI、战斗、装备、AI 文本增强

这些不应抢在核心闭环前面。

---

## 12. 一句话边界

Chronicle Demo 不是要证明“我们能做很多内容”。

Chronicle Demo 要证明：

> 一个很小的世界，也能让玩家相信自己在那里生活过。
