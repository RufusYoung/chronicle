# 🧩 《冒险纪事》系统蓝图 v3

> 以“世界有呼吸、角色有体温”为核心理念
> 文字冒险 × 涌现叙事 × 系统化生命体验

---

## 1️⃣ 世界系统（World System）

### 🌍 世界逻辑

* 全世界共享统一时间轴（年 / 季 / 日 / 昼夜）。
* 深层（梦境层、地下世界等）存在**时间流速差异**。

  * 玩家在深层停留时，世界时间仍在推进。
  * 返回表层后系统自动执行“时间对齐”：

    > 「你在深层停留 1 日，地表已过去 30 日。」
  * 所有 NPC、生态、市场、政治等状态根据“真实世界时间”更新。

### 🌋 世界事件

* 世界会随时间演化，触发“**大事件系统**”：

  * 自然灾害（瘟疫、地震、暴风雪）
  * 政治动荡（王国更替、叛乱）
  * 神秘异变（异界裂缝、梦雾蔓延）
* 玩家可以作为**参与者 / 见证者 / 旁观者**介入。
* 大事件在纪事中有独立章节记录。

---

## 2️⃣ 旅程系统（Journey System）

### 🗺 自由旅行逻辑

* 玩家随时可打开地图选择目的地。
* 若连续事件结束后无操作，会出现“**继续旅行按钮**”：

  * 点一下，系统会**自动推送下一个事件候选**。
  * 事件可能来自：

    * 世界动态（外部）
    * 主角的想法（内部）
  * 玩家可选择“接受 / 拒绝”，确保节奏不断、无停滞感。

---

### 💤 睡眠机制（Sleep System）

#### 🏕 睡眠方式

* 可选择：

  * 背包帐篷（安全低）
  * 旅馆（安全高）
  * 特殊环境（洞穴、神庙等）
* 睡眠质量受以下三项综合影响：

  ```
  睡眠质量 = (理智系数 × 身体状态系数 × 环境系数)
  ```

  * 理智高 → 梦安稳；理智低 → 梦魇概率+
  * 身体状态健康 → 恢复效率+
  * 环境安全 → 干扰事件-

#### 🕓 睡眠条算法

* 睡眠积累条：记录“未睡小时数”。
* 每小时+1，休息时按质量清除。

  * 100%睡眠质量：积累条归零
  * 80%睡眠质量：减少80%积累值
* 超过阈值触发不同惩罚：

| 未睡小时  | 状态   | 效果                        |
| ----- | ---- | ------------------------- |
| 0–12  | 正常   | 无影响                       |
| 12–18 | 轻度疲惫 | 理智下降，赶路耗时+10%             |
| 18–24 | 疲劳   | 力量下降10%，旅行耗时+20%          |
| 24+   | 极度疲惫 | 理智-3/h，赶路耗时+40%，事件失败率+20% |

#### 🧬 体质影响算法

> 体质越高，耐受度越强，阈值动态提升：

```
疲惫阈值 = 18h + (体质 × 0.2)
理智影响延迟 = 24h + (体质 × 0.3)
```

#### 💤 其他机制

* 固定耗时：7小时。
* 可随时选择“昼夜颠倒”模式（探索时仍可休息）。
* 睡眠可恢复少量生命值与轻微负面状态。
* 有道具可缓解疲惫，但不能阻止生命/理智下降。

## 3️⃣ 食物系统（Food System）

* 食物按时间自动消耗。

  * 每6小时扣除一份食物单位。
  * 若无食物：体质下降、理智下降。
* 不需手动喂食。
* 特殊食物可提供短期增益（灵感、抗寒、理智恢复）。

---

## 4️⃣ 属性系统（Attribute System）

### 🧠 综合属性公式

每项属性都在战斗与探索中参与计算：

```
战斗生命值 = (力量×0.2 + 敏捷×0.15 + 体质×0.2 + 智慧×0.15 + 魅力×0.05 + 感知×0.15) × A
攻击力 = (力量×0.25 + 敏捷×0.2 + 智慧×0.2 + 体质×0.1 + 感知×0.15 + 魅力×0.1) × B
```

* A、B为战斗算法常数，用于平衡职业间差异（如 1.2 / 1.0 / 0.8）。
* 战斗外的**角色生命值**主要由体质决定，但其他属性也提供轻微修正：

  ```
  角色生命值 = (体质×0.6 + 力量×0.1 + 感知×0.1 + 智慧×0.05 + 魅力×0.05 + 敏捷×0.1) × C
  ```
* 重伤会降低体质，但可通过修养、医疗或身体改造恢复。

---

### ⚙️ 装备数值加成公式

每个装备类型都有自己的属性依赖：

| 装备类型 | 加成公式           | 说明           |
| ---- | -------------- | ------------ |
| 重甲   | (力量 + 体质) / 25 | 增加生命与防御      |
| 轻甲   | (敏捷 + 感知) / 25 | 增加闪避与反应      |
| 武器   | (力量 + 智慧) / 30 | 提升攻击与命中      |
| 饰品   | (魅力 + 感知) / 20 | 提升社交、洞察事件成功率 |

> 这样不同角色构成都会有不同的装备适配风格。

## 5️⃣ 成长与印记系统（Growth & Journey Marks）

### ✳️ 印记逻辑

* 每次关键事件都会获得一个“印记（Mark）”。
* 相似事件叠加后会**升级印记**并**提升属性**：

  * “帮忙干活”5次 → 力量+1 → 解锁印记【劳作者】
  * “安抚他人”3次 → 魅力+1 → 解锁印记【抚慰者】
* 印记是经验系统的灵魂，代替传统经验值。

### 🌠 风格演化

* 多个印记融合后形成“角色风格”：

  * 劳作者 + 梦行者 = 「赤手筑梦者」
  * 愚者 + 异乡记录者 = 「流浪见证者」
* 风格提供特殊效果（如理智减缓、旅行效率提升）。
* **初始特质即第一个风格雏形**，后续成长由印记延展。
  → 两个系统正式合并。

---

## 6️⃣ 战斗系统（Combat System）

* 每场战斗为临时状态，战斗生命值独立于角色生命值。
* 战斗失败 → 不立即死亡，但会损伤真实生命值或体质。
* 战斗胜利 → 获得经验印记、战利品或新事件触发。

---

## 7️⃣ 身体改造系统（Body Augmentation）

### 💀 改造逻辑

* 可通过特殊仪式、科技、诅咒进行永久强化。
* 改造类型：

  * 增强属性（力量+1）
  * 获得特性（夜视、抗毒）
  * 副作用（理智消耗、周期性痛觉）

### ⚖️ 承载上限（耐受度）

```
承载上限 = 体质 × 5 + 稳定修正（事件/装备）
```

* 超出上限触发“身体崩溃”：失明、癫狂、变异等事件。
* 体质上升可提高上限；老化、重伤、诅咒会降低上限。

### 📜 记录系统

* 独立界面显示全部改造：

  ```
  [义肢：右臂 - 力量+1]
  [梦石嵌入 - 理智消耗+1/h]
  [血肉同化 - 感知+2，体质-1]
  ```
* 这些都会在最终纪事文本中被写入。

---

## 8️⃣ 纪事系统（Legacy Chronicle）

### 📖 实时记录机制

* 从游戏开始起，系统就**自动记录**：

  * 背景、选择、事件、状态变化、世界大事。
  * 生成结构化叙事日志（按时间轴存储）。
* 玩家不知晓此记录存在。

### 🕯 结局触发

* 角色死亡 / 理智归零 / 完成主线 / 世界大事件。

### 🪶 输出

* 游戏结束时生成一部“奇幻传记文本”：

  > 《异乡行者叶某的编年史》
  > 从出生到陨落，一生的旅程被书写成小说体文本，可下载保存。

## 🔁 核心循环（Core Loop）

```
选择目标地 / 旅程推进
↓
触发事件 / 战斗 / 休息 / 改造
↓
属性成长 / 印记积累 / 世界时间推进
↓
大事件发生 / 风格演化 / 身体变更
↓
最终纪事生成
```
