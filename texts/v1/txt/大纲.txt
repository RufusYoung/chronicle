# 🎮 《冒险纪事》游戏设计大纲（Game Design Document）

---

## 一、游戏概述

**游戏名（暂定）：** 《冒险纪事 / Chronicle》
**类型：** 像素风文字冒险 × 涌现式叙事 × 探险人生模拟
**核心理念：** 世界有自己的时间与命运，玩家是其中的生命个体。故事不是预设的，而是由规则自然生长。

> “你不是在读一段冒险，而是在生活一段冒险。”

---

## 二、游戏定位与风格

* **核心体验：**
  玩家在一个有呼吸的奇幻世界中，以自由旅行、事件决策、自动战斗、身体成长为核心循环，体验一段从出生到陨落的冒险人生。

* **风格基调：**

  * 气质参考：《来自深渊》《葬送的芙莉莲》
  * 视觉：像素绘 + 文字叙事UI
  * 叙事风格：诗意、孤独、神秘、有代价的温柔
  * 节奏：缓慢但持续推进，带时间的重量感

---

## 三、核心系统框架

---

### 1️⃣ 世界系统（World System）

#### 世界时间与逻辑

* 世界拥有**统一时间轴**（昼夜、季节、年份）。
* 世界中的事件与生态都随时间演化。
* 玩家进入“深层区域”后，时间流速不同步。

  * 离开深层时触发“时间对齐”：

    > 「你在深层停留 1 日，地表已过去 30 日。」
  * 世界事件随时间流逝推进。

#### 世界事件（Global Events）

* 世界会定期发生“**大事件**”：

  * 自然：瘟疫、寒潮、地震。
  * 社会：政变、迁徙、战乱。
  * 超自然：梦雾、星陨、时空错位。
* 玩家可成为：

  * 参与者 → 触发特殊印记。
  * 见证者 → 改写纪事篇章。
  * 旁观者 → 承受后果。

---

### 2️⃣ 旅程系统（Journey System）

#### 自由旅行

* 玩家可随时打开地图决定目的地。
* 若长时间无操作，会出现“**继续旅程按钮**”：

  * 系统自动推送新事件（外部/内心）。
  * 玩家可选择接受或拒绝，确保游戏不断线。

#### 旅行计算

* 目的地 → 距离 → 转化为时间与物资消耗。
* 考虑：地形、天气、身体状态、负重、时间。
* 所有行动都会消耗时间。

#### 时间影响

* 昼夜交替与季节变化影响事件类型：

  * 夜晚 → 幻觉、梦境、暗袭。
  * 冬季 → 疾病、寒冷、食物耗尽。

---

### 3️⃣ 睡眠与身体系统（Sleep & Condition System）

#### 睡眠方式

* 帐篷 / 旅馆 / 野外 / 特殊地点。
* 睡眠质量 = 理智系数 × 身体状态系数 × 环境系数
* 固定耗时：7小时。

#### 睡眠积累条

记录“未睡小时数”，按质量减少：

| 未睡小时  | 状态  | 效果             |
| ----- | --- | -------------- |
| 0–12  | 正常  | 无影响            |
| 12–18 | 轻疲惫 | 理智下降，赶路+10%    |
| 18–24 | 疲劳  | 力量下降10%，耗时+20% |
| 24+   | 极疲惫 | 理智-3/h，失败率+20% |

体质影响耐受度：

```
疲惫阈值 = 18h + (体质 × 0.2)
理智影响延迟 = 24h + (体质 × 0.3)
```

* 睡眠恢复生命、理智、轻伤。
* 可昼夜颠倒。
* 道具可暂缓疲惫，但无法阻止生命/理智下降。

---

### 4️⃣ 食物与消耗系统（Survival System）

* 食物自动按时间消耗（每6小时-1单位）。
* 饥饿时体质下降、理智下降。
* 特殊食物提供短期增益（灵感、抗寒、理智回复）。

---

### 5️⃣ 角色系统（Character System）

#### 初始创建

* 背景、特质、初始装备与属性。
* 背景无优劣，均有独特代价。

#### 动态特质

* 特质可随旅程变化、退化、升华。

  * “谨慎”→“冷静老练”
  * “梦游者”→“梦行者”
  * “冲动”→“麻木”

#### 角色状态

| 状态   | 说明                 |
| ---- | ------------------ |
| 生命值  | 角色的真实生理状态，归零则死亡    |
| 理智   | 反映精神状态，低理智会引发梦境、幻觉 |
| 疾病   | 影响属性与事件触发          |
| 负重   | 决定移动耗时             |
| 睡眠积累 | 决定疲惫状态             |

---

### 6️⃣ 属性系统（Attribute System）

每项属性在战斗与探索中都有作用。

```
战斗生命值 = (力量×0.2 + 敏捷×0.15 + 体质×0.2 + 智慧×0.15 + 魅力×0.05 + 感知×0.15) × A
攻击力 = (力量×0.25 + 敏捷×0.2 + 智慧×0.2 + 体质×0.1 + 感知×0.15 + 魅力×0.1) × B
角色生命值 = (体质×0.6 + 力量×0.1 + 感知×0.1 + 智慧×0.05 + 魅力×0.05 + 敏捷×0.1) × C
```

#### 装备依赖系数

| 装备类型 | 加成算法         | 效果     |
| ---- | ------------ | ------ |
| 重甲   | (力量 + 体质)/25 | 增生命、防御 |
| 轻甲   | (敏捷 + 感知)/25 | 增闪避、速度 |
| 武器   | (力量 + 智慧)/30 | 增攻击    |
| 饰品   | (魅力 + 感知)/20 | 增社交、洞察 |

> 每项属性的成长都反映“角色经历塑造的自己”。

---

### 7️⃣ 战斗系统（Combat System）

* 自动战斗，系统计算伤害。
* 战斗生命值为临时数值，每次战斗重置。
* 战斗失败 → 可能重伤、感染、理智下降。
* 战斗胜利 → 获得印记、装备、触发新事件。

---

### 8️⃣ 成长与印记系统（Growth & Marks）

#### 印记机制

* 每次关键事件生成“印记（Mark）”。
* 相似事件叠加后升级印记并提升属性。

  * “帮农活”×5 → 力量+1 → 【劳作者】
  * “救助他人”×3 → 体质+1 → 【守护者】

#### 风格系统

* 印记融合后形成角色风格（如“梦行者”“异乡记录者”）。
* 风格提供被动特效（旅程耗时-5%、理智回复+2/日等）。
* 初始特质 = 第一个风格雏形。

---

### 9️⃣ 装备与身体改造系统（Equipment & Augmentation）

#### 装备机制

* 双词条：战斗词条 / 探索词条。
* 装备可进化、损坏、觉醒。
* 特殊装备可触发专属事件。

#### 身体改造

* 永久强化系统（生物义肢、机械嵌入、梦石共鸣）。
* 每次改造带有收益与代价。
* 承载上限：

  ```
  上限 = 体质 × 5 + 稳定修正
  ```
* 超限 → 崩溃事件（失明、幻觉、变异）。
* 独立面板记录改造历史。

---

### 🔟 纪事系统（Legacy Chronicle）

#### 实时记录

* 从游戏开始即自动记录角色一生：

  * 决策、旅程、世界事件、改造记录、印记演化。
* 玩家不知晓该系统存在。

#### 结局

* 由以下触发：

  * 死亡 / 理智归零 / 大事件 / 老化 / 诅咒。

#### 输出

* 结局生成一本奇幻小说风格文本，可下载：

  ```
  《流浪见证者·叶某的编年史》
  ——从出生到梦境消逝，他见证了时代的呼吸。
  ```

---

## 四、核心循环（Core Loop）

```
选择目的地
↓
旅程推进（消耗时间与资源）
↓
触发事件 / 战斗 / 睡眠 /改造
↓
获得印记与属性成长
↓
世界时间推进 / 大事件发生
↓
角色风格演化 / 状态变化
↓
最终纪事生成
```

---

## 五、游戏哲学

| 关键词      | 含义                   |
| -------- | -------------------- |
| 🌍 世界自运转 | 世界不为玩家存在，而玩家只是世界的部分。 |
| 🕰 生命是过程 | 旅程即人生，没有终点，只有记录。     |
| ⚙️ 系统造诗  | 文本不是写的，而是由规则生长。      |
| 💀 代价即意义 | 每一次成长都伴随损失。          |
| 📖 纪事永存  | 角色会死，故事会留下。          |
