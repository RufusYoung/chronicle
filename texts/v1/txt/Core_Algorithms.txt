# 核心算法逻辑（Chronicle v0.1）

## 1. 睡眠与疲惫
- 睡眠条：每小时 +1
- 睡眠：固定7h；睡眠质量 Q ∈ [0,1]
  - Q = 理智系数 × 身体状态系数 × 环境系数
  - 归还量 = 7 × Q（小时）
- 阈值（受体质影响）：
  - 疲惫阈值 H1 = 18 + 0.2×体质
  - 理智阈值 H2 = 24 + 0.3×体质
- 梯度惩罚：
  - 12–18h：轻疲惫 → 赶路耗时+10%，理智-1/6h
  - 18–24h：疲劳 → 力量-10%，耗时+20%，理智-1/3h
  - >24h：极疲惫 → 理智-3/h，事件失败率+20%

## 2. 食物
- 每6小时自动消耗1单位
- 无食物：每6小时体质-1（不低于1）、理智-1

## 3. 战斗面板（自动战斗）
- 战斗生命 = (力×0.20 + 敏×0.15 + 体×0.20 + 智×0.15 + 魅×0.05 + 感×0.15) × A
- 战斗攻击 = (力×0.25 + 敏×0.20 + 智×0.20 + 体×0.10 + 感×0.15 + 魅×0.10) × B
- 角色生命（非战斗）= (体×0.60 + 力×0.10 + 感×0.10 + 智×0.05 + 魅×0.05 + 敏×0.10) × C
- 推荐初值：A=8，B=5，C=12（可在 Balancing_Playbook 调整）

## 4. 装备依赖与边际
- 重甲加成系数 = (力量 + 体质) / S，默认 S=25
- 轻甲 = (敏捷 + 感知)/25；武器 = (力量 + 智慧)/30；饰品 = (魅力 + 感知)/20
- 最终加成 = 基础词条 × (1 + 系数)；并可设上限cap避免失控

## 5. 事件触发
- 候选条件：地点标签、时间段、天气、玩家状态/装备标签 满足门槛
- 从候选池按权重抽取1条；设置冷却（cooldown_days）

## 6. 印记成长
- 行为计数 → 达阈值升级印记并加属性
  - 例：帮工×5 → 力量+1，解锁【劳作者】
- 多印记融合 → 风格 → 被动（例：旅行耗时-5%、理智回复+2/日）

## 7. 深层时间对齐
- 对齐：world_time += stay_hours × (region.time_scale - 1)
