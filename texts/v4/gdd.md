## 1. 游戏愿景

### 1.1 核心体验

**玩家不是在"玩游戏"，而是在"活一生"**

这是一款涌现式文字冒险游戏，玩家将在一个自我运转的西幻世界中度过80年的虚拟人生。世界不为玩家暂停，NPC有自己的生活，生物有自己的迁徙，时间的流逝是真实而有重量的。

### 1.2 设计支柱

**支柱1：完全涌现的世界**
- 世界按规则自我运转，不依赖预设剧本
- 事件、冒险、奇遇都从世界状态中自然产生
- 玩家缺席时，世界继续演化

**支柱2：真实的时间流逝**
- 80年生命周期，每一年都有意义
- 角色会衰老、NPC会死亡、世界会变迁
- 时间是稀缺资源，选择有代价

**支柱3：高信息密度的文学叙事**
- 每句话都是线索，每个细节都有意义
- 参照《来自深渊》与《葬送的芙莉莲》的文学性
- 诗意与残酷并存（磷光、雾盐、霜线、铁腥）

**支柱4：自由但有后果**
- 玩家完全自由选择行动
- 所有选择都有真实后果
- 可以是旁观者，也可以改变世界

### 1.3 对标作品

**涌现深度**：矮人要塞（冒险模式）  
**奇遇密度**：冒险生活（Life in Adventure）  
**叙事风格**：《葬送的芙莉莲》+ 《来自深渊》  
**战斗机制**：冒险生活（骰子判定）

## 2. 核心玩法

### 2.1 玩法概述

玩家创建一个角色，在西幻世界中自由探索、冒险、生存，最终度过完整的一生，生成独一无二的人生纪事。

### 2.2 核心循环

```
角色创建 → 进入世界
    ↓
[每小时/每天的循环]
    ↓
选择行动 → 遭遇事件/战斗/互动 → 世界推进
    ↓
角色成长/装备获取/关系变化
    ↓
世界状态演化（NPC老化/生物迁徙/危机爆发）
    ↓
重复循环直到死亡
    ↓
生成纪事 → 游戏结束
```

### 2.3 玩家自由度

**目标自由**：
- 无强制主线，玩家自定义目标
- 可选目标：探索、复仇、成为传奇、寻找某物、隐居、体验世界

**节奏自由**：
- 可以频繁冒险（前期高密度）
- 可以隐居平静（后期低密度）
- 可以混合（自由切换）

**道德自由**：
- 可以行善、作恶、中立
- 可以杀死智慧生物（获得材料，但有后果）
- 可以放过敌人（获得关系，但失去奖励）

### 2.4 游戏时长

**现实游玩时长**：75小时/存档  
**游戏内时间跨度**：15-100岁（根据寿命，基准80年）  
**存档数量**：最多3个并行存档  
**续命机制**：每局游戏可续命1次

## 3. 世界观

### 3.1 世界设定

**类型**：西方奇幻世界（非异界入侵设定）  
**风格**：诗意残酷（磷光、雾盐、霜线）  
**参照**：《来自深渊》的世界设计感（不照搬设定）

### 3.2 世界构成

**地理**：
- 10-15个核心地区（湖区、冬原、废墟城、深林、沙海、高山等）
- 每个地区有独特生态、危险、资源、NPC
- 地点可探索（洞穴、遗迹、神秘区域）

**种族**：
- 人类（主要）
- 类人种族（精灵、矮人、兽人等）
- 智慧生物（高级龙、古老存在）
- 野兽/怪物（狼、熊、低级龙、魔法生物）

**魔法与科技**：
- 存在魔法系统
- 存在遗物/古代科技
- 存在身体改造技术（有代价）

### 3.3 世界大势（叙事锚点）

**不是主线任务，而是世界的宏观演化趋势**

设计3-5个"叙事锚点"，影响世界慢变量：
- 示例：王国与叛军的持续战争（10-20年跨度）
- 示例：古老封印的松动（异变生物增多）
- 示例：瘟疫的爆发与治愈
- 示例：气候的长期变化

玩家可参与、可旁观、可逃避，但世界会继续演化。

## 4. 世界模拟系统

### 4.1 核心原则

**世界自我运转，不依赖玩家**

世界由多个系统组成，每个系统按规则运行，玩家的行动影响世界状态，但世界不会暂停。

### 4.2 地区系统

**每个地区包含**：
- 气质配比（温暖/险恶比例，影响事件类型）
- 慢变量（繁荣度、治安、物价、战争张力、瘟疫风险等，0-100）
- 固定NPC（3-5个核心NPC）
- 次要NPC（10-15个有名字的角色）
- 地理特征（洞穴、遗迹、湖泊等可探索地点）
- 生物栖息地（哪些生物初始分布在此）

**地区更新频率**：
- 玩家所在地区：每小时精细模拟
- 邻近地区：每天更新
- 远方地区：每月/每年更新

### 4.3 世界时间线

**时间单位**：年/季/月/日/昼夜/小时  
**全局时钟**：统一推进，所有地区同步

**年度更新**（每年1月1日执行）：
1. 所有NPC年龄+1，检查死亡
2. 地区慢变量推进
3. 检查阈值触发大事件（战争、瘟疫、饥荒）
4. 生物迁徙/繁殖周期更新
5. 生成年度大事记

### 4.4 慢变量与阈值系统

**慢变量示例**：
- 战争张力（0-100）：受政治事件、军事行动、资源争夺影响
- 瘟疫风险（0-100）：受卫生、气候、人口密度影响
- 繁荣度（0-100）：受贸易、战争、灾害影响

**阈值触发**：
- 战争张力>80 → 触发战争爆发
- 瘟疫风险>70 → 触发疫情
- 繁荣度<20 → 触发经济崩溃/地区废弃

### 4.5 世界记忆系统

**分层记忆**：
- 短期（1-7天）：具体细节（"老陈被抢"）
- 中期（1周-1月）：抽象标签（"湖区治安下降"）
- 长期（1月-1年）：重要事件（"第10年战争爆发"）
- 永久（1年+）：世界编年史（"第15年王国战败"）

**记忆用途**：
- 影响NPC对话（"你听说老陈被抢了吗？"）
- 影响事件生成（盗贼活跃→遭遇盗贼概率+）
- 生成纪事内容

## 5. 角色系统

### 5.1 角色创建

**流程**：

**步骤1：选择背景（20个，选1）**
- 背景决定：起始属性配比、起始物品、起始声望、风格雏形、年龄限制
- 示例：流浪学者、老兵、富商子弟、矿工、逃犯、猎人、教士等

**步骤2：选择年龄**
- 在背景限制范围内自由选择（如流浪学者：20-50岁）
- 年龄影响：起始属性、成长速度、预期寿命

**步骤3：选择起始特质（5选1）**
- 每个背景有5个候选特质
- 特质影响：能力、关系、特殊机制

**步骤4：选择起始印记（10选2）**
- 从10个基础印记中选2个
- 印记是成长系统的基础

**步骤5：属性分配**
- 背景给予基础属性
- 玩家获得5点自由分配点数

**步骤6：开局故事生成**
- 通过2-3个快速事件决策，确定角色初始状态
- 生成个性化开局叙事

### 5.2 六大基础属性

| 属性 | 说明 | 影响 |
|------|------|------|
| 力量 | 肌肉力量 | 近战伤害、负重、破坏 |
| 敏捷 | 反应速度 | 闪避、先攻、逃跑 |
| 体质 | 生命韧性 | 生命值、抗病、耐力、寿命 |
| 智慧 | 知识理解 | 魔法、研究、识破 |
| 感知 | 观察洞察 | 发现线索、避开陷阱、射击 |
| 魅力 | 社交魅力 | 说服、交易、领导 |

**属性范围**：1-10（基准5）  
**属性成长**：通过印记系统缓慢提升

### 5.3 生命与死亡

**双生命值系统**：
- 战斗生命值（临时，战斗结算用，战斗后重置）
- 角色生命值（真实，受伤会降低，需治疗恢复）

**生理年龄 vs 实际年龄**：
```
生理年龄 = 实际年龄 + 负面因素 - 正面因素

负面因素：诅咒、旧伤、慢性病、理智低
正面因素：祝福、身体改造、高体质
```

**预期寿命计算**：
```
基准75岁
+ 体质影响（每点体质±5岁）
+ 祝福/诅咒
+ 身体改造
- 旧伤/慢性病
- 理智影响
```

**死亡条件**：
- 理智归零（立即死亡）
- 角色生命值归零（立即死亡）
- 体质归零（立即死亡）
- 战斗中战败且未逃脱（可能死亡）
- 年龄>预期寿命（每年X%概率死亡）

**续命机制**：
- 每局游戏仅可续命1次
- 续命条件：特殊物品/仪式/NPC帮助

## 6. 时间系统

### 6.1 时间推进机制

**核心原则**：时间推进速度由行动类型决定，不是固定的

**行动类型与时间消耗**：

| 行动类型 | 时间消耗 | 现实游玩节奏 |
|---------|---------|------------|
| 高密度行动 | 1小时-1天 | 频繁决策 |
| 中密度行动 | 1天-1周 | 中等决策 |
| 低密度行动 | 1周-1个月 | 低频决策 |
| 长期项目 | 1个月-10年 | 每年几次关键决策 |
| 日常过渡 | 自动推进 | 无决策，系统生成摘要 |

**示例**：
- 战斗：1小时
- 探索废墟：3-6小时
- 长途旅行：10-30天
- 闭关研究：1-3年
- 在村庄定居：自动推进（可选1月-1年）

### 6.2 生命阶段设计

**不是阶段限制，而是倾向引导**：

**青年期（15-35岁）**：
- 奇遇密度：高（50%）
- 特点：探索世界，建立印记，频繁冒险
- 长期项目：少

**中年期（35-55岁）**：
- 奇遇密度：中（30%）
- 特点：战略规划，参与大事件，建立影响力
- 长期项目：增多

**晚年期（55-70岁）**：
- 奇遇密度：低（20%）
- 特点：回顾、传承、偶尔冒险
- 长期项目：可能很多（隐居/担任职务）

**暮年期（70-80岁+）**：
- 奇遇密度：很低
- 特点：告别之旅，等待死亡
- 玩家仍可选择冒险（如果身体允许）

**关键**：以上只是"倾向"，玩家完全自由选择节奏。

### 6.3 时间弹性体验

**长期项目的处理**：
- 不是"跳过时间"，而是"浓缩体验"
- 每年触发1-2个关键时刻让玩家决策
- 可随时中断（保留进度）
- 世界继续运转（NPC老化、大事发生）

**示例：闭关研究3年**
```
Year 1: 建立基础 + 1个关键决策
Year 2: 遇到瓶颈 + 1个关键决策
Year 3: 完成/失败 + 最终结果

期间世界：
- NPC老化3岁
- 可能发生战争/瘟疫
- 玩家的朋友可能死亡/搬离

出关后：
- 玩家看到世界变化
- 通过NPC口述了解发生的事
```

## 7. 生存系统

### 7.1 睡眠系统

**睡眠债务累积**：
- 每经过1小时，睡眠债务+1
- 疲劳阈值 = 18 + 体质×0.2

**睡眠固定7小时**：
- 睡眠质量 = 理智×身体状态×环境
- 睡眠清除债务 = 债务×睡眠质量

**疲劳惩罚**：
- 12-18小时未睡：轻度疲惫（理智-1/h）
- 18-24小时：疲劳（力量-1，敏捷-1）
- 24-30小时：极度疲惫（理智-3/h，战斗-20%）
- 30+小时：强制睡眠或理智归零

### 7.2 食物系统

**自动消耗**：
- 每6小时消耗1单位食物
- 缺粮惩罚：体质-0.1/单位，理智-2/单位

**特殊食物**：
- 某些食物提供buff（抗寒、理智恢复、治疗等）

### 7.3 理智系统

**理智上限**：100 + 智慧×2 + 魅力×1 - 诅咒修正

**理智消耗**：
- 目睹恐怖事件
- 使用禁忌魔法
- 长期孤独
- 暴露于神秘现象

**理智恢复**：
- 睡眠（质量好）
- 社交（与好友互动）
- 美丽风景/平静时刻
- 特定物品/仪式

**理智归零**：立即死亡（精神崩溃）

## 8. 战斗系统

### 8.1 战斗流程

**触发战斗**：
- 遭遇敌对生物/NPC
- 玩家主动攻击

**战前选择**：
```
遭遇敌人 → 查看信息（实力评估）

选项：
[战斗]
[逃跑]
[沟通]（仅智慧生物，需条件）
[威慑]（需条件）
```

**战斗判定**（参照冒险生活）：
1. 掷骰子（1d20）
2. 加上综合修正值
3. 与难度对比，判定胜负

**综合修正值**：
```
基础属性（力量+敏捷+感知）
+ 装备加成（武器+护甲）
+ 身体状态（疲劳/受伤惩罚）
+ 环境因素（天气/地形）
+ 特质/风格加成
+ 敌我实力差
```

**战斗结果**：
- 大成功（骰子≥难度+5）：完胜，无损伤
- 成功（骰子≥难度）：胜利，可能受伤
- 部分成功（骰子≥难度-5）：惨胜，必定受伤
- 失败：战败

### 8.2 战败与逃跑

**战败后选择**：
```
[逃跑]：敏捷判定，成功逃脱
[求饶]：魅力判定，可能被放过
[死战]：继续战斗（可能死亡）
```

**逃跑判定**：
- 敏捷为核心
- 装备影响（重甲-5）
- 地形影响
- 敌人追击能力

### 8.3 击败智慧生物的选择

**击败后选项**：
```
敌人战败倒地

[杀死]：
- 获得材料/装备（更多更好）
- 可能获得稀有物品
- 可能形成印记（【屠龙者】）
- 可能成为传说
- 关系网记仇（朋友/族群报复）

[放过]：
- 对方记住你
- 可能感激（后续帮助）
- 可能记仇（后续报复）
- 可能中立（互不相欠）
- 奖励较少

[沟通]（仅智慧生物）：
- 建立关系
- 可能获得知识/情报
- 可能结盟/交易
```

**邪恶智慧生物**：
- 不会报恩，可能装死后偷袭
- 系统会侧写暗示（"它的眼神闪烁着狡诈"）

## 9. 装备系统

### 9.1 装备槽位

**装备栏**：
- 武器：单手×2 or 单手+盾 or 双手×1
- 防具：躯干
- 头盔：头部
- 鞋子：足部
- 饰品：4个槽位

### 9.2 装备词条

**双词条设计**：
- 战斗词条（攻击、防御、暴击、格挡等）
- 探索词条（抗寒、夜视、负重、地形适应等）

**词条不设兼容性限制**：
- 允许创意组合（火焰盾牌、灵羽重甲等）
- 鼓励意外的有趣结果

### 9.3 装备来源

**手工精品装备（50-100件）**：
- 独特名字、外观、故事
- 与核心NPC/事件关联
- 示例：【狼王的最后吼声】（冬狼之誓奖励）

**涌现装备（无限）**：
- 组合生成：材质×类型×词条
- 历史来源：从世界状态推导故事

### 9.4 装备生成系统

**生成公式**：
```
装备 = [材质] + [基础类型] + [词条] + [来源故事]

材质（20种）：
- 普通：铁、钢、皮革
- 特殊：龙骨、霜铁、精灵布、魔晶

类型（10种）：
- 武器：剑、斧、弓、法杖
- 防具：轻甲、重甲、长袍
- 饰品：护符、戒指、腰带

词条（30种）：
- 元素：火焰、冰霜、雷电
- 属性：力量、敏捷、智慧
- 特殊：吸血、穿透、反伤

来源故事：
- 从地点历史推导
- 从世界事件推导
- 意象模板库填充
```

**示例生成**：
```
地点：古战场废墟
世界记忆：第15年王国军队战败

生成装备：
【染血的王国军剑】
材质：钢
类型：长剑
词条：攻击+4，威慑+2
故事："剑刃上仍有深褐色的血迹，
      剑柄刻着王国的纹章——已经模糊了。
      不知道它的主人是谁，
      但他一定战斗到了最后一刻。"
```

### 9.5 装备品质与稀有度

**品质等级**：
- 常见（70%）
- 少见（20%）
- 稀有（8%）
- 传奇（2%）

**稀有度决定因素**：
- 材质稀有度
- 地点危险度
- 玩家运气（骰子）
- 世界状态（战争期间军用装备+）

**品质差异**：
- 常见：基础词条1-2个
- 少见：特殊材质或复杂词条2-3个
- 稀有：多重词条3-4个+有故事
- 传奇：4-5个强力词条+特殊技能+深刻故事

### 9.6 装备成长系统

**契合度系统**：
```
使用时间 → 契合度提升（0%-100%）

契合度效果：
- 数值提升：攻击力/防御力小幅增长
- 能力解锁：
  * 50%：解锁隐藏词条
  * 100%：解锁特殊能力

示例：
【铁剑】使用500小时
→ 契合度100%
→ 【老伙伴·铁剑】
→ 攻击+3变成+4
→ 解锁【心剑合一】：暴击+10%
```

**装备历史记录**：
```
装备会记录：
- 击杀数（按类型：狼/龙/人）
- 参与的重要战斗
- 陪伴时间

历史转化为词条：
- 击杀50只狼 → 【狼之宿敌】+20%对狼伤害
- 参与屠龙 → 【染龙血】+火焰抗性
- 使用10年 → 【忠诚伙伴】+全属性
```

**装备品质提升**：
```
常见装备：不会变成稀有（设计决策）

少见 → 稀有：
触发条件（全部纳入判定）：
- 特定事件（击杀强敌）
- 灌注仪式（消耗材料）
- 装备历史（使用足够久+重要战绩）
- 世界状态（特殊时期）

稀有 → 传奇：
极难，一局最多2件
触发条件：
- 超级稀有事件（屠龙、改变历史）
- 命运时刻（一生仅2次机遇）
- 装备深刻历史+仪式
```

### 9.7 装备耐久

**三种耐久类型**：

**Gradual（逐时衰减）**：
- 每小时损耗固定值
- 适用：衣物、绳索、消耗品

**Charge（次数耗用）**：
- 使用X次后损毁
- 适用：一次性物品、魔法道具

**Eternal（几乎不损）**：
- 正常情况不衰减
- 极端事件可能降级
- 适用：遗物、神器、传奇装备

**耐久状态**：
- 完好（100%-70%）：100%效果
- 磨损（69%-25%）：60%效果
- 破损（24%-1%）：30%效果
- 损毁（0%）：无效，需修理

## 10. 成长系统

### 10.1 印记系统

**核心概念**：
印记是可成长的经历标签，代表角色的专长与经验积累。

**印记结构**：
- 名称（如【学者】【战士】【医者】）
- 等级（1-10）
- 进度值（0-100，满则升级）
- 属性奖励（每级提升特定属性）
- 能力解锁（特定等级解锁特殊能力）

**进度来源**：
```
【学者】印记进度+：
- 阅读书籍 +10
- 研究文献 +20
- 解开谜题 +15
- 教导他人 +10

【战士】印记进度+：
- 参与战斗 +5/次
- 击败强敌 +20
- 训练 +5/小时
- 保护他人 +10
```

**印记升级奖励示例**：
```
【学者】：
Lv1: 智慧+1
Lv2: 智慧+1, 感知+1
Lv3: 智慧+1, 解锁【博闻强识】
Lv5: 智慧+2, 研究速度+20%
Lv10: 智慧+3, 解锁【真理追寻】
```

**印记上限**：玩家可拥有的印记数量无上限，但同时"活跃"的印记建议5-8个。

### 10.2 风格系统

**核心概念**：
风格是印记组合+属性走向的产物，代表角色的独特定位。

**风格触发条件**：
```
【博学旅人】：
- 【学者】Lv5+
- 【探险者】Lv3+
- 智慧≥8

【扛盾行者】：
- 【劳作者】Lv3+
- 【守护者】Lv3+
- 体质≥7

【梦境学者】：
- 【学者】Lv5+
- 【梦行者】Lv4+
- 智慧≥9
```

**风格效果**：
```
【博学旅人】：
被动效果：
- 旅行时可教导遇到的NPC
- 每次帮助他人，智慧经验+10%
- NPC对你的初始好感+10

主动能力：
- 【知识共享】：与NPC分享知识，关系大幅提升
```

**风格进化**：
- 高级风格可由多个基础风格组合而成
- 示例：【梦境学者】+【异界见证者】→【梦境行者·真理追寻者】

### 10.3 身体改造系统

**核心概念**：
通过手术/仪式/魔法改造身体，获得超常能力，但有代价。

**改造类型**：

**正面改造**：
- 【生命强化】：体质+2，预期寿命+10年
- 【力量增幅】：力量+3，但体质-1
- 【夜视眼球】：夜间无惩罚，感知+1
- 【机械义肢】：恢复失去的肢体，力量+1

**代价改造**：
- 【梦石嵌入】：智慧+2，但理智消耗+1/h
- 【血肉同化】：感知+3，但体质-2，外貌变异
- 【诅咒刻印】：获得特殊能力，但理智上限-20

**承载上限**：
```
承载上限 = 体质×5

每个改造有"负载值"
总负载 > 上限 → 身体崩溃
崩溃后果：失明/癫狂/变异/器官衰竭
```

**改造获取**：
- 特定NPC/组织提供（需声望/金钱）
- 特定地点（古代实验室/神秘仪式场）
- 特定事件（击败强敌后获得材料）

## 11. NPC与关系系统

### 11.1 NPC类型

**固定NPC（40个）**：
- 有名字、完整背景、独特任务线
- 会老化、死亡
- 有记忆系统（记得玩家的行为）
- 分布在各地区（每地区3-5个）

**次要NPC（110个）**：
- 有名字、基础背景
- 简化的互动
- 会老化、死亡
- 主要用于填充世界

**随机NPC（程序生成，无限）**：
- 基于原型生成
- 用于短期互动
- 旅人、商队、士兵等

**智慧生物**：
- 高级龙、精灵长老、古老存在
- 可以像NPC一样互动
- 但有独特的AI和条件

### 11.2 NPC核心属性

**每个NPC包含**：
```
基础信息：
- 姓名、年龄、职业、性格
- 生理年龄、预期寿命

动态状态：
- 位置、健康、金钱、情绪、理智
- 需求（食物、安全、社交、目标）

关系网：
- 朋友、敌人、家人、债主
- 与玩家的关系值（-100到+100）
- 关系类型（朋友/恩人/仇人/债务人）

记忆：
- 记得谁帮过我/害过我
- 重要事件记录
- 对玩家的印象

AI行为树：
- 根据状态决定行动
- 寻求赚钱/社交/安全等
```

### 11.3 NPC AI系统

**需求驱动行为**：
```
检查需求（每小时）：
- 金钱<阈值 → 寻找赚钱机会
- 情绪<30 → 寻求社交/娱乐
- 健康<50 → 寻求治疗
- 压力>80 → 情绪崩溃/极端行为

检查威胁：
- 附近有盗贼 → 逃跑/求助/反抗
- 有追债者 → 还钱/躲避/哀求
```

**行为示例**：
```
商人老陈：
- 正常：在店铺卖货，每天赚10金
- 被抢后：金钱<阈值 → 寻求借贷
- 欠债后：压力增加 → 开始酗酒
- 压力>80 → 决定搬离地区
```

### 11.4 关系系统

**关系类型**：
- 朋友（friend）
- 恩人（benefactor）
- 仇人（enemy）
- 债务人（debtor）
- 竞争者（rival）
- 盟友（ally）

**关系强度**：-100到+100

**关系影响**：
```
对话口吻：
+70以上：温暖友好
+30到70：友善
-30到+30：中立
-70到-30：冷淡
-70以下：敌对

价格调整：
+70以上：7折
+30到70：9折
-30以下：1.5倍

任务解锁：
某些任务需要关系≥特定值
```

### 11.5 恩怨与约定系统

**恩（Favor）**：
```
结构：
- 描述（"你救了我的命"）
- 价值（1-10）
- 过期时间（年）

兑现：
- NPC在危机时帮助玩家
- 提供特殊物品/情报
- 兑现后，恩情消失，关系-30
```

**怨（Grudge）**：
```
结构：
- 描述（"你杀了我的儿子"）
- 严重程度（1-10）
- 衰减速度

衰减：
- 小仇（<8）会随时间淡化
- 大仇（≥8）永不遗忘，可能触发复仇事件
```

**约定（Oath）**：
```
结构：
- 描述（"在30天内送信到都市"）
- 截止日期
- 违约惩罚

完成：获得奖励+声望
违约：失去信任-50+声望-10
```

### 11.6 NPC衰老与继承

**每年更新**：
```
NPC年龄+1
检查死亡：
- 年龄>预期寿命 → 随机死亡
- 死亡后触发死亡事件

继承系统：
- 有子女的NPC → 子女继承关系（×0.5）
- 子女会记得"你是父亲/母亲说的那个人"
- 可能解锁新任务："父亲的遗物"
```

## 12. 生物系统

### 12.1 生物分类

**野兽（无智慧）**：
- 狼、熊、巨型野猪、低级龙
- 只能战斗，无法沟通
- 击杀后直接获得材料

**智慧生物（高智慧）**：
- 高级龙、精灵长老、古老存在
- 可以沟通（需条件）
- 击败后可选择：杀死/放过/沟通

**类人种族**：
- 精灵、矮人、兽人
- 像人类NPC一样互动
- 可以战斗、交易、结盟

### 12.2 生物初始分布

**固定栖息地**：
```
龙：高山、悬崖、古代遗迹
狮鹫：天空、悬崖
巨魔：深林、洞穴
水怪：湖泊、海洋
魔法生物：魔力浓郁区域
```

### 12.3 生物迁徙与涌现系统

**迁徙驱动因素**：

**环境变化**：
```
干旱 → 水怪离开湖泊，寻找新水源
寒潮 → 生物南迁
森林大火 → 所有生物逃离
```

**人类活动**：
```
战争 → 惊扰龙的巢穴，龙被迫迁移
开垦 → 巨魔领地缩小，进入村庄附近
猎杀 → 兽群逃离猎场
```

**生物竞争**：
```
更强生物入侵 → 原生物被驱逐
食物链变化 → 捕食者/猎物迁移
领地争夺 → 失败者离开
```

**繁殖/狩猎周期**：
```
繁殖期 → 迁徙到产卵地
狩猎季 → 跟随猎物迁徙
冬眠期 → 寻找安全洞穴
```

**生物AI行为**：
```
复杂AI（参照矮人要塞）：
- 有领地意识
- 记仇（记得攻击过它的人/生物）
- 学习（陷阱失败后会警惕）
- 社交（与同类互动）
- 衰老（老年龙行为不同）
- 繁殖（寻找配偶、筑巢、保护幼崽）
```

### 12.4 智慧生物沟通系统

**沟通条件**：
```
基础条件：
- 生物有智慧（高级龙、精灵等）
- 生物未处于狂暴状态

解锁条件（满足其一）：
- 击败它（证明实力）
- 有【兽语者】/【龙语者】印记
- 特定物品（龙族信物）
- 生物好感度>0（之前有过互动）
```

**沟通流程**：
```
遭遇高级龙 → 它先攻击（嗜血暴躁）

战斗 → 击败龙（HP<30%）

龙停止攻击：
"你……很强。"

选项：
[杀死]：获得龙骨、龙血、稀有材料 + 可能形成【屠龙者】印记
[沟通]：建立关系，可能交易/结盟/获得知识
[放过]：龙记住你，未来可能报恩/报仇

如果选择沟通：
- 龙的好感度：-50→+20
- 可以询问、交易、请求帮助
- 可能成为同伴（极难）
```

**邪恶智慧生物**：
```
某些智慧生物本性邪恶：
- 不会报恩
- 可能装死后偷袭
- 沟通是陷阱

系统侧写暗示：
"它的眼神闪烁着狡诈。"
"它答应得太快了。"
"你感到不安。"

玩家需要判断是否信任
```

### 12.5 生物与世界状态

**生物数量动态变化**：
```
繁殖 → 数量增加
猎杀 → 数量减少
疾病 → 大量死亡
迁徙 → 地区分布变化

示例：
狼群繁殖成功 → 数量过多 → 开始袭击村庄
村民组织猎杀 → 狼群数量锐减 → 生态失衡
鹿群爆发 → 狼群恢复 → 重新平衡
```

## 13. 涌现事件系统

### 13.1 核心原则

**不是事件库抽取，而是世界状态采样**

事件不是预设的剧本，而是从世界模拟的当前状态中提取"值得叙述的时刻"。

### 13.2 遭遇检定系统

**触发频率**：
- 高密度行动：每小时1次
- 中密度行动：每3小时1次
- 低密度行动：每天1次
- 长期项目：每年几次

**检定流程**：
```
1. 掷骰子（1-100）
2. 判定类型：
   - 1-30：奇遇事件
   - 31-80：日常涌现
   - 81-100：平静时刻

3. 根据类型生成内容
```

### 13.3 奇遇事件（30%）

**不是预设事件，而是情境系统的组合**

**核心系统**：

**地点危险度系统**：
```
每个地点有危险度（0-100）
危险度由世界状态决定：
- 兽群迁徙 → 洞穴危险度+20
- 盗贼藏匿 → 废墟危险度+15
- 异变蔓延 → 深林危险度+30
- 诅咒区域 → 该地危险度+25

危险度影响：
- 遭遇威胁的概率
- 探索时的挑战难度
- 奖励的丰厚程度
```

**探索生成系统**：
```
玩家探索洞穴：
系统检查：
- 当前洞穴危险度：60
- 危险来源：[狼群筑巢, 古老诅咒]

生成探索内容：
第1层：狼群挑战（因为有狼群）
第2层：诅咒陷阱（因为有诅咒）
第3层：奖励（与危险度匹配）

→ 每次探索都不同（取决于当前世界状态）
```

**神秘现象系统**：
```
现象类型：
- 消失（NPC随机消失）
- 时间异常（时间流速不同）
- 共同梦境（NPC分享噩梦）
- 幽灵目击（死者显现）

触发条件：
- 阈值触发（诅咒>40，瘟疫活跃等）
- 概率生成（30%）

效果：
- 持续影响NPC和世界
- 玩家可调查、解决、无视
- 解决后现象停止
```

**生物遭遇系统**：
```
检查玩家附近有哪些生物：
- 固定栖息地的生物
- 正在迁徙的生物
- 逃亡/受伤的生物

生成遭遇：
- 生物的当前状态（狩猎/休息/受伤）
- 生物对玩家的态度（中立/敌对/恐惧）
- 环境因素（夜晚/暴风雪）

→ 每次遭遇都基于真实的生物状态
```

### 13.4 日常涌现（50%）

**采样NPC状态**：
```
检查玩家附近的NPC：
- 是否有NPC处于特殊状态
  * 寻求帮助
  * 逃亡
  * 交易
  * 庆祝
  * 悲伤

生成遭遇：
- 基于NPC真实需求
- 玩家可选择互动或无视
```

**环境威胁**：
```
检查地区的活跃威胁：
- 盗贼团伙
- 野兽群
- 自然灾害

如果有威胁 → 生成遭遇
```

**示例**：
```
玩家在湖区行走

系统检查：
- NPC商人老陈刚被抢（3小时前）
- 老陈处于"寻求帮助"状态

生成遭遇：
"你在路上遇到商人老陈，他焦急地四处张望……"

玩家可以：
[帮助] [询问] [无视]
```

### 13.5 平静时刻（20%）

**美丽风景库**：
```
根据地点+时间+季节选择：
- 森林黄昏秋天："黄昏的森林笼罩在金色光晕中……"
- 雪原夜晚冬天："雪夜的寂静几乎是具象的……"
- 湖边清晨春天："春晨的湖面薄雾缭绕……"
```

**内心独白库**：
```
根据玩家状态选择：
- 压力>70："你深吸一口气，这段时间压力太大了……"
- 最近失去好友："你想起了{NPC}，如果他还在……"
- 年龄>60："你已经{年龄}岁了，还能看到多少次日落？"
- 正常："没有战斗，没有危险，只是走路看风景……"
```

**玩家选项**：
```
[继续赶路]
[休息一会儿]
[采集/记录（留作纪念）]
```

## 14. 地点与探索系统

### 14.1 地点类型

**可探索地点**：
- 洞穴
- 废墟（城堡、神庙、实验室）
- 深林禁地
- 古代遗迹
- 地下通道
- 神秘区域

**每个地点包含**：
```
基础属性：
- 类型、危险度、探索深度（层数）
- 是否已探索

动态内容：
- 当前危险来源（根据世界状态）
- 奖励（根据危险度生成）
```

### 14.2 探索生成系统

**生成流程**：
```
玩家进入洞穴 → 系统生成内容

检查世界状态：
- 兽群迁徙？→ 生成兽群挑战
- 诅咒蔓延？→ 生成诅咒陷阱
- 盗贼藏匿？→ 生成盗贼营地
- 异变扩散？→ 生成异变生物

根据深度分配挑战：
第1层：基础挑战
第2层：复杂挑战
第3层：核心奖励

→ 内容每次都不同
```

**挑战类型**：
- 战斗（生物/盗贼）
- 陷阱（物理/魔法）
- 谜题（需要智慧/感知）
- 环境（毒气/坍塌/迷宫）

**奖励类型**：
- 装备/材料
- 知识（古代文献）
- NPC（被困的人）
- 特殊物品（遗物）

### 14.3 探索中的选择

**每层都有选择**：
```
第1层完成后：
[继续深入]
[返回]
[休息后继续]

如果玩家受伤/疲劳：
系统警告："你的状态很差，继续深入很危险"
```

**失败后果**：
```
探索失败（战败/陷阱/理智归零）：
- 被迫撤退
- 可能失去物品
- 可能受重伤
- 地点状态不变（下次可再来）
```

## 15. 叙事生成系统

### 15.1 文字翻译架构

**核心**：把世界状态翻译成高信息密度的诗意文字

**流程**：
```
世界状态 → 检测值得叙述的时刻 → 提取信息
→ 匹配意象模板 → 注入细节 → 生成文本
```

### 15.2 意象模板库

**结构**：
```
状态签名 → 意象模板组

示例：
("low_mood", "high_stress") → [
    "{NPC}坐在{地点}，{手部动作}。{线索暗示}",
    "{NPC}的{衣物细节}沾满了{污渍}。{行为细节}。"
]

变量池：
- 手部动作：["不停搓手", "紧握酒杯", "抠桌沿"]
- 污渍：根据NPC职业/状态推导
- 线索暗示：从NPC记忆/状态推导
```

### 15.3 线索推导系统

**从状态推导线索**：
```
NPC金钱<阈值 且 最近卖掉贵重物品
→ 线索："他手指上的印痕——银戒指不见了"

NPC被监视 且 有债务
→ 线索："角落里有个壮汉盯着他"

地点有异常 且 最近有事件
→ 线索："货车翻倒，箱子是空的"
```

### 15.4 装备故事生成

**从地点历史推导**：
```
地点：古战场废墟
世界记忆：第15年王国军队战败

生成装备时：
1. 提取历史关键词：战败、王国、死亡
2. 选择意象模板：
   "剑刃上有{血迹状态}。
    剑柄刻着{所属标记}——{损毁状态}。
    {推测语句}。"
3. 注入细节：
   - 血迹状态："深褐色血迹"
   - 所属标记："王国纹章"
   - 损毁状态："已经模糊了"
   - 推测语句："不知道它的主人是谁，但他战斗到了最后"
4. 生成最终文本
```

### 15.5 遭遇文本生成

**示例流程**：
```
遭遇：玩家在森林遇到受伤的猎人

系统收集信息：
- NPC：猎人马克
- 状态：受伤（HP 40%），刚战斗过
- 时间：黄昏
- 地点：森林深处
- 世界状态：兽群迁徙中
- 玩家：有【医者】印记

选择遭遇原型模板："与猎人相遇"

注入信息：
- 时间氛围："午后的阳光穿过树叶……"
- 猎人状态："一个猎人跛行而来，腿上绑着粗糙的绷带"
- 猎人情绪："他咬着牙，额头冒汗"
- 关系："马克认出了你，苦笑道……"
- 世界线索："他指向远方：'狼群往北边去了，小心。'"

生成选项：
[帮助治疗]（因为玩家有【医者】）
[询问发生了什么]
[给他食物]
[离开]

最终文本：
"午后的阳光穿过树叶，在地上投下斑驳的影子。

一个猎人跛行而来，腿上绑着粗糙的绷带。
他咬着牙，额头冒汗。

马克认出了你，苦笑道：'又是你啊……这次栽了。'
他指向远方：'狼群往北边去了，数量比往年多。小心点。'

[帮助治疗]
[询问发生了什么]
[给他食物]
[离开]"
```

## 16. 纪事系统

### 16.1 记录机制

**自动记录**（从游戏开始）：
```
记录内容：
1. 所有重大事件（Tier 1核心事件）
2. 重要NPC互动（关系变化>20）
3. 世界大事（战争、瘟疫、灾难）
4. 角色成长（印记升级、风格获得）
5. 身体改造、诅咒、重伤
6. 装备获得（稀有以上）
```

### 16.2 筛选与分章

**筛选标准**：
- 只保留有叙事价值的条目
- 日常琐事不记录
- 优先保留情感冲击强的事件

**分章依据**：
- 按时间线（每10-15年一章）
- 或按主题（冒险/友情/复仇/探索）
- 开篇+正文+尾声

### 16.3 文学化生成

**使用手工文学模板**：
```
不是流水账："第10年，击败了龙"

而是文学化叙述：
"那是第10年的霜月。

他在悬崖上与古龙对峙，
风雪刮过，龙的鳞片反射着冷光。

战斗持续了整整一夜。
当晨光照亮山巅时，
龙倒下了，他也倒下了。

但他活了下来。
龙没有。

从那天起，人们开始传颂他的名字。"
```

**模板库**：
- 战斗事件模板（20个）
- 友情事件模板（15个）
- 探索事件模板（15个）
- 告别事件模板（10个）
- 成长事件模板（10个）

### 16.4 纪事输出

**格式**：纯文本，Markdown格式  
**长度**：5000-10000字（根据内容自动调整）  
**结构**：
```markdown
# 《{角色名}的编年史》

## 序章：{背景}
[根据玩家选择的背景生成]

## 第一章：{标题}（{起始年龄}-{结束年龄}岁）
[该阶段的重要事件]

## 第二章：{标题}
...

## 尾声：{结局类型}
[死亡方式、遗产、世界影响]

---
游戏时间：{实际年龄}岁
游玩时长：{现实小时}小时
印记：[列表]
风格：{最终风格}
改变世界的方式：[列表]
```

**只在游戏结束时生成一次**，玩家可下载保存。

## 17. 玩家体验设计

### 17.1 节奏设计（方案C）

**前20小时（青年期）**：
- 奇遇密度：50%
- 目的：吸引玩家，建立"这游戏有趣"的印象
- 玩家体验："天啊，总有新鲜事！"

**20-50小时（中年期）**：
- 奇遇密度：30%
- 目的：展现世界的真实感，平衡奇遇与日常
- 玩家体验："有冒险，但也有日常"

**50-75小时（晚年期）**：
- 奇遇密度：20%
- 目的：诗意的告别，回忆与传承
- 玩家体验："我老了，更多是回忆"

**关键**：玩家仍可自由选择节奏，以上只是"倾向引导"。

### 17.2 死亡与续命

**死亡即游戏结束**：
- 立即生成纪事
- 可查看最终状态

**续命机制**（每局1次）**：
```
触发条件：
- 死亡时自动提示
- 需要满足特定条件：
  * 有特殊物品（复活石/神器）
  * 有NPC欠人情（NPC救你）
  * 有神灵/强大存在庇护

续命后：
- 恢复生命，但可能有后遗症
- 可能失去某些能力/物品
- 续命次数归零
```

### 17.3 存档系统

**多存档**：最多3个并行存档  
**自动存档**：频繁自动保存，玩家无法手动读档  
**不可回档**：选择有后果，无法重来  
**存档信息显示**：
- 角色名、年龄、地点
- 游戏内时间、现实游玩时长
- 最后保存时间

## 19. 平衡性设计

### 19.1 装备平衡哲学

**不追求数值膨胀，而是适配性**：
- 常见装备：够用，可成长
- 稀有装备：强，但不必需
- 传奇装备：有特殊能力，但一两件就够

**核心理念**：
- 没有废物装备
- 老装备可以通过契合度成长
- 新装备不一定比老装备强

### 19.2 战斗平衡

**敌人实力评估**：
- 战前显示实力等级（远强/稍强/相当/稍弱/远弱）
- 基于玩家当前属性+装备计算

**失败不等于死亡**：
- 战败后仍有逃跑/求饶机会
- 鼓励玩家尝试挑战

### 19.3 时间平衡

**防止玩家"卡住"**：
- 长期项目可随时中断
- 濒死状态下有续命机会（1次）
- 平静时刻也是体验，不是"无聊"

## 22. 内容量估算

### 22.1 核心系统（代码）

**开发时间**：6-8个月
- 世界模拟引擎
- NPC AI系统
- 生物系统
- 涌现事件系统
- 装备生成系统
- 战斗系统
- 纪事生成系统

### 22.2 手工内容（写作）

**总手工内容量**：约15万-20万字

**详细分解**：

```
背景与角色创建：
- 20个背景 × 500字 = 10,000字
- 开局事件模板 = 5,000字

遭遇原型模板：
- 30个原型 × 300字 = 9,000字

意象库：
- 1000条片段 × 50字 = 50,000字

手工精品装备：
- 50件 × 200字 = 10,000字

固定NPC：
- 40个 × 500字 = 20,000字
- 次要NPC：110个 × 200字 = 22,000字

叙事瑰宝（手工精品事件）：
- 20个 × 1500字 = 30,000字
```

### 核心哲学

### 开发原则

1. **系统驱动叙事**：设计规则，让故事涌现
2. **质量胜于数量**：手工内容少但精
3. **模板支撑生成**：意象库保证文字质量
4. **测试驱动平衡**：数据记录，持续调整

### 体验原则

1. **尊重玩家时间**：75小时，每分钟都有价值
2. **鼓励探索**：奖励好奇心
3. **不惩罚失败**：失败也是故事
4. **每次都不同**：重玩有新体验
