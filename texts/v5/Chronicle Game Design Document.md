# Chronicle / 回响之境：冒险纪事

## 重构版游戏设计文档 v5：系统架构版

版本定位：
本文件不是最终数值表，也不是完整内容设定集，而是 Chronicle 的长期系统架构 GDD。它用于统一核心玩法、前台交互、世界模拟、人生阶段、状态成长、线索追寻、长期项目、传记生成与后续开发拆分。

本版本暂不锁定以下内容：

* 战斗具体公式

* 判定算法
* 经济平衡参数
* 食物腐败具体公式
* AI 文本模型部署方式
* 最终 UI 美术规格

本版本优先锁定：

* 游戏到底是什么
* 玩家在屏幕上做什么
* 世界如何产生事件
* 玩家如何度过一生
* 状态、经历、关系、痕迹如何进入成长与传记
* 系统如何分层搭建，避免所有内容混在一起

# 1. 游戏一句话定义

Chronicle 是一款以“完整人生”为单位的涌现式文字冒险 RPG。
游戏先生成一个持续运转的世界，再把玩家放入其中。玩家不是任务中心，也不是世界唯一主角，而是在这个世界中选择人生方向、介入局部事件、承担后果、留下痕迹，最终生成一本文学化的人生传记。

核心结构：

世界先存在。
人物活在世界里。
玩家选择一段人生。
人生与世界互相影响。
死亡之后，世界仍然继续。
最终留下个人传记与时代纪事。

# 2. 核心设计支柱

## 2.1 世界先于玩家存在

Chronicle 不以任务链为核心，而以世界状态为核心。

普通文字冒险：

```text
作者写事件 → 玩家触发事件 → 结算结果
```

Chronicle：

```text
世界有状态 → 状态推动人物行为 → 行为留下痕迹 → 玩家撞见局面 → 玩家介入或错过 → 世界继续变化
```

事件不是从事件池中抽取，而是世界状态被玩家看见时的前台翻译。

---

## 2.2 玩家不是无限控制者，而是一个完整的人

每名玩家角色都有完整一生。

角色会：

* 成长
* 变老
* 受伤
* 疯狂
* 失控
* 建立关系
* 错过事情
* 获得名声
* 被误解
* 死亡

角色死亡后，玩家不能复活这个角色，也不能回到过去修改选择。
但同一个世界可以继续开启后续角色。

---

## 2.3 同一世界最多三名玩家角色

一个世界不是一局游戏，而是一部时代小说。
每个世界最多容纳三名玩家角色。

规则：

* 每名角色都是完整一生。
* 三名角色生命可以时间重叠。
* 第一角色死亡后，第二角色通常在 5–10 年后被玩家接管。
* 后续角色不是继承者，不是回声者，不是前角色转世。
* 后续角色只是同一世界中的另一个普通人。
* 后续角色是否听说前角色，取决于传闻是否传播到其出生地。
* 前角色可能留下遗物、传闻、赝品、污名、笑话、屋子、花田、地图、债务、仇恨或一段无人知晓的痕迹。
* 第三角色结束后，世界归档，生成时代纪事。

# 3. 前台核心玩法循环

Chronicle 的核心循环不是“接任务—打怪—升级”，而是：

```text
进入地点局面
↓
观察人物、地点、线索、地区状态
↓
选择行动 / 对话 / 调查 / 旅行 / 生涯方向
↓
行动推动时间
↓
世界状态变化
↓
即时反馈：状态、物品、关系、线索
↓
中期回声：NPC 行为、地点变化、传闻传播
↓
长期回声：特质、名声、遗产、传记
↓
进入下一段人生
```

玩家既会被当前地点的事件撞上，也可以主动打开“生涯”面板选择下一段人生方向。
“遇到事件”和“选择人生方向”不是先后关系，而是并行入口。

# 4. 主界面结构

游戏默认显示“地点局面”。

## 4.1 顶部导航

顶部按钮建议为：

```text
背包｜角色｜世界｜生涯｜设置
```

“纪事”不作为顶部主按钮。
纪事进入“生涯”面板内部，作为已完成经历、阶段结算和人生记录的子目录。
玩家活着时主要查看“生涯”；角色死亡或世界归档后，才正式阅读“纪事”。

## 4.2 左侧：角色状态摘要

左侧显示当前角色的可读状态：

* 生命
* 健康
* 精力
* 理智
* 饥饿
* 伤势
* 六大属性简表
* 当前核心词条
* 开局核心特质 1–3 个

开局核心特质是角色一生的初始底色，例如：

* 诅咒之子
* 富商子女
* 旧伤未愈
* 天生敏锐
* 被遗弃者
* 没落贵族
* 边境军户

核心特质会影响：

* 初始属性
* 出身地点
* 可选路线
* 他人态度
* 判定倾向
* 世界事件吸引概率
* 传记权重

## 4.3 中央：地点局面

中央显示当前地点的叙述文本、可见人物、痕迹、子地点节点和当前行动。

地点局面不是任务列表，而是世界状态的可见切面。

例如：

```text
湖湾镇

老陈铺子已经两天没有开门。
市场上的干粮又涨了一次价。
码头边的商船比往常少，守卫却比往常多。

你看见陈米坐在铺子门口。
她怀里抱着一个旧布袋，看见你时，把袋口往身后藏了藏。
```

中央可以显示子地点：

```text
老陈铺子
市场
码头
守卫所
玛婶家
废弃粮仓
```

点击子地点后进入更细局面，再出现对应行动与对话选项。

## 4.4 右侧：地区状态、线索、地点

右侧分为三个折叠区：

### 地区状态

地区状态使用“抽象词 + 具体发生过的事”。

例如：

```text
粮食：紧张。老陈铺子已经两天没开门，市场上的干粮涨了一次价。
治安：不安。守卫最近增加了夜巡。
商路：受阻。北路商队迟了三天。
人心：压抑。市场里很少有人大声说话。
```

地区状态不能只显示精确数值，也不能完全空泛。
它必须让玩家知道“这里发生了什么”，但不直接暴露后台变量。

### 线索列表

线索先融入场景文本。玩家获得线索后，进入右侧线索列表。
线索按地点折叠，并使用标签区分：

```text
[线索] 废弃粮仓的粮粉
[线索] 北路迟到的商队
[追寻] 北方龙影
[追寻] 失踪的商队
```

### 地点列表

显示当前地区或当前地点下属的可进入节点。

## 4.5 底部：当前行动选项

底部显示当前局面可执行的行动。

选项可以很多，但应按颜色或图标区分：

* 普通行动
* 对话行动
* 线索行动
* 危险行动
* 长期行动
* 特殊行动

例如：

```text
[走近陈米]
[查看涨价告示]
[敲门找老陈]
[去市场打听粮价]
[在湖湾镇停留一月]
[离开湖湾镇]
```

“在湖湾镇停留一月”这种具体长期行动可以放在底部。
但“漂泊、定居、服役、求知、营生、追寻”这种人生方向不放底部，而放在顶部“生涯”面板中。

# 5. 生涯面板

生涯面板是 Chronicle 的中枢界面之一。

它不是任务面板，而是玩家当前人生可能性的集合。

## 5.1 生涯面板显示内容

生涯面板包含：

* 当前人生状态
* 可开始的人生方向
* 正在进行的长期项目
* 可追寻的目标
* 已完成经历
* 阶段结算记录
* 纪事子目录

## 5.2 可开始的人生方向

只显示当前能开始的人生方向。
不能开始的方向不显示。

例如在湖湾镇：

```text
可开始：
定居
营生
漂泊
追寻

不可开始：
服役
求知
```

因为湖湾镇当前没有可加入的军队，也没有合适的求知入口。

## 5.3 听说过但尚未开启的人生可能

为了避免玩家不知道世界上存在某些人生方向，生涯面板可加入“听说过的人生可能”子页。

这个子页不显示所有不可用方向，只显示玩家在当前世界中听说过、但尚未满足条件的可能性。

例如：

```text
你听说北境有人招募边境巡逻者。
你听说王都有图书馆招抄书学徒。
你听说湖湾镇有人想找人照看药铺。
```

这些不是立即可开始项目，但可以给玩家目标感。

## 5.4 人生方向大类

建议使用六类：

```text
漂泊
定居
服役
求知
营生
追寻
```

说明：

* 漂泊：以移动、旅行、偶遇、美景、奇遇和危险为主。
* 定居：以某个地点、人际关系和日常生活为主。
* 服役：加入组织，接受纪律、任务和代价。
* 求知：研究、学习、调查知识、解读古书、理解世界真相。
* 营生：赚钱、工艺、职业实践、开店、行医、锻造、厨艺等。
* 追寻：围绕一个目标、传闻、信仰、仇恨、誓言或传说投入人生。

“经营”建议扩展为“营生”，以容纳医生、厨师、铁匠、药师、猎人等职业实践。
“研究”建议扩展为“求知”，以容纳学徒、抄书、遗迹调查、魔法理论等路径。

# 6. 线索与追寻

线索和追寻相互关联，但不是一回事。

```text
线索 = 你知道了一件事。
追寻 = 你决定把一段人生投入这件事。
```

## 6.1 线索获得

线索可以来自：

* 场景文本
* 对话
* 物品
* 地图
* 传闻
* 关系
* 战斗后果
* 长期项目中的插入信息
* 梦境或精神污染
* 前角色遗产

线索获得后进入右侧线索列表。

## 6.2 线索行动卡

点击线索后，出现线索行动卡。

示例：

```text
线索：北方龙影

你听说北方有商队在雪线附近失踪。
传闻已经转过几手，没人说得清最早是谁讲的。

可行动：
[前往灰松城打听] 15天，需要干粮
[询问来往商队] 半日
[寻找受伤猎人] 2小时
[将其加入追寻]
[暂时搁置]
```

## 6.3 追寻

当玩家选择将某条线索加入追寻，它会进入生涯面板，成为一段人生方向。

例如：

```text
追寻：北方龙影
```

追寻类人生方向可以生成更长线的行动：

```text
[准备物资后北上]
[先在湖湾镇收集传闻]
[寻找熟悉北路的向导]
[暂时搁置]
```

# 7. 行动与时间

Chronicle 不做复杂日程排队。
玩家一般是一个选项一个选项地推动时间。

## 7.1 行动分级

行动按时间尺度分为：

* 瞬时行动
* 小时行动
* 半日行动
* 日行动
* 周行动
* 月行动
* 年行动
* 长期项目

规则：

* 不超过一小时的行动一般后台结算，不显式提示时间。
* 一小时以上的行动显示时间成本。
* 半日以上必须显示时间成本。
* 跨日、跨月、跨年的行动必须明显提示。
* 行动失败也消耗时间。
* 短行动不能中途打断。
* 长期项目不是一次不可打断行动，而是一组阶段节点。

## 7.2 行动示例

```text
[问粮从哪来的]
[去守卫所举报] 1小时
[陪她去废弃粮仓查看] 半日
[跟随商队前往北境] 12天
[在第七哨站服役] 5年
```

## 7.3 时间的作用

行动推动时间，时间推动世界。

行动可能导致：

* 天色变化
* 疲劳累积
* 食物消耗
* 错过商队
* 错过某个局面
* 地区状态变化
* 线索传播或消失
* NPC 采取下一步行动

前台只提示重要时间成本，后台结算普通时间流动。

# 8. 状态系统

角色状态分为六个核心项：

```text
生命
健康
伤势
精力
理智
饥饿
```

## 8.1 生命

生命主要在战斗中起作用。
战斗中，谁的生命先归零，谁战败。

生命受以下因素影响：

* 体质
* 健康
* 装备
* 伤势
* 特质
* 临时状态
* 药物或食物增益

## 8.2 健康

健康是长期身体状态。
健康归零通常意味着死亡。

健康受以下因素影响：

* 疾病
* 营养
* 长期饥饿
* 伤势
* 年龄
* 食物质量
* 医疗
* 魔法污染
* 身体强化
* 义体或改造

## 8.3 伤势

伤势是健康的子集，也是一组具体 debuff。

例如：

* 断手
* 失明
* 断腿
* 旧冻伤
* 肺病
* 左臂旧伤
* 烧伤
* 魔化伤口

伤势会影响：

* 战斗
* 旅行
* 长期项目
* 职业实践
* 传记权重

## 8.4 精力

精力承载行动消耗和疲劳。
精力以长期疲劳压力为主，以短期行动点为辅。

精力影响：

* 行动判定
* 战斗表现
* 旅行安全
* 长期项目效率
* 是否容易错过线索
* 是否容易失误

## 8.5 理智

理智包含原本的心情系统。
心情不单独设状态，归入理智。

理智表示：

* 精神稳定
* 恐惧
* 压力
* 精神污染
* 梦境干扰
* 意志消耗
* 长期心理状态

理智数值本身不直接影响精力。
但理智词条和理智数值会影响判定、战斗、对话、幻觉、精神污染事件和失控风险。

理智归零不固定等于死亡，而是进入失控结算。

## 8.6 饥饿

饥饿与食物系统相关。
干粮主要补充饥饿值。
长期吃干粮可能降低理智。
美食可以提高理智，甚至恢复健康。

# 9. 六大属性与成长

角色拥有六大属性：

```text
力量
敏捷
智慧
魅力
体质
感知
```

## 9.1 属性作用

力量：搬运、破坏、近战压制、重武器、体力工作。
敏捷：躲避、潜行、逃跑、攀爬、快速反应。
智慧：学习、研究、记忆、逻辑、魔法理论、复杂计划。
魅力：说服、交易、领导、威慑、被人注意或信任。
体质：生命上限、抗病、恢复、承受伤势、寿命倾向。
感知：发现线索、察觉危险、读懂情绪、判断异常、追踪。

## 9.2 成长逻辑

Chronicle 不使用通用经验值自由加点。

成长逻辑为：

```text
经历什么
↓
对应属性成长槽增加
↓
阶段结算时生成成长候选
↓
玩家在合理范围内选择
```

不是：

```text
获得经验 → 想加什么就加什么
```

而是：

```text
这段人生允许你变成什么
```

## 9.3 阶段结算中的加点

长期项目结束后，系统根据玩家在这段经历中的行为，展示可加属性和获得特质。

例如第七哨站服役五年后：

```text
你这五年的经历主要改变了：

体质：你熬过了五个北境冬天。
感知：你学会了在雾雪里分辨脚步。
魅力：你多次在军纪与人情之间调停。
力量：你参与修墙、守城和近战。
```

玩家可选择其中一项或几项作为明显成长。

## 9.4 特质类型

特质分为：

* 属性型特质
* 被动型特质
* 选项解锁型特质
* 痕迹 / 负担型特质
* 社会身份型特质
* 传记素材型特质

属性点让角色更强。
特质让角色更像自己。

# 10. 人生阶段结算

人生阶段结算用于把一段生活压缩成成长、伤痕、关系和记忆。

适用场景：

* 长期项目结束
* 人生阶段变化
* 重大人生转折
* 失控后苏醒
* 重伤后隐居
* 重要关系断裂
* 角色死亡前总结

结算结构：

```text
展示这段时间发生过的关键事实
↓
自动获得必然留下的特质、伤痕、关系、装备历史
↓
展示属性成长候选
↓
展示人生取向选择
↓
结算 NPC、地点、组织、地区状态
↓
进入下一段人生
```

例如：

```text
边境服役 · 五年结算

你在第七哨站度过了五个冬天。
第一年，你冒雪寻找失踪的新兵伊莱。
第二年，你放过了一个敌方少年斥候。
第三年，村民偷军粮时，你没有按军法处置。
第四年，黑旗袭击哨站时，你守住了东墙。
第五年，你拒绝了军官任命，选择退役。

自动获得：
【边境老兵】
【夜巡习惯】
【左臂旧冻伤】
罗恩记住了你守住东墙
旧短刀获得“第七哨站防守”历史

可选择成长：
[体质 +1]
[感知 +1]
[魅力 +1]
[力量 +1]
```

# 11. 长期项目系统

长期项目不是跳过时间，而是一组阶段节点。

长期项目包括：

* 服役
* 定居
* 营生
* 求知
* 追寻
* 漂泊
* 学徒
* 照顾某人
* 隐居恢复

## 11.1 长期项目字段

每个长期项目包含：

* 项目类型
* 地点
* 预计持续时间
* 承诺强度
* 核心人物
* 重复仪式
* 年度节点池
* 退出条件
* 退出代价
* 成长倾向
* 外界信息入口
* 结算方式

## 11.2 中途退出

长期项目可以中途退出。
退出前给模糊提示：

```text
代价可能很小。
代价可能很大。
某些人可能理解你。
某些人可能永远不再信任你。
```

后果由世界状态、关系、组织纪律、项目类型和当前局面涌现决定。

失败、半途而废、被迫中断不算完整经历，但仍有得有失的结算。

# 12. 关系与记忆系统

关系不是单一好感度，而是多种态度和记忆的组合。

关系可以包含：

* 信任
* 恐惧
* 感激
* 怨恨
* 债务
* 亲近
* 熟悉
* 羞愧
* 利用意图
* 误解
* 旧事记忆

同一事件会被不同角色以不同方式理解。

例如玩家帮助陈米：

```text
陈米：感激上升，恐惧下降，记住你给过食物。
老陈：可能感激，也可能羞愧。
玛婶：如果听说，会认为你心软。
刘账房：如果听说，可能认为你会干涉债务。
守卫：未必知道。
```

关系会影响：

* 对话选项
* 信任门槛
* 传闻传播
* 长期项目
* 出身与出生地
* 遗产出现
* 世人评价
* 传记内容

# 13. 传闻传播系统

传闻产生于事实，但会在传播中失真。

传播路径包括：

* 目击者
* 酒馆
* 商队
* 士兵
* 信件
* 家族
* 组织
* 市场
* 难民
* 旅人

传闻结构：

```text
事实
↓
目击记忆
↓
一手传闻
↓
二手传闻
↓
多手传闻
↓
传说 / 假故事
```

后台记录：

* 真实性概率
* 传播层数
* 来源链
* 传播路线
* 是否被夸大
* 是否被恶意篡改

前台只显示模糊描述：

```text
有人亲眼见过。
这是商队带来的消息。
这话已经传了好几手。
像是酒馆里夸大的故事。
没人说得清最早是谁讲的。
```

假的传闻也可能导致真实后果。

# 14. 地图与旅行

地图分四层：

```text
世界地图
地区地图
地点节点
室内 / 子地点节点
```

路线有状态：

* 泥泞
* 封锁
* 盗贼活跃
* 狼群迁徙
* 商队频繁
* 雪崩风险
* 传闻指向
* 军队管制

旅行不是每天点击一次，而是选择旅行方式：

* 跟随商队
* 独自赶路
* 沿途打听
* 绕开大道
* 追随传闻
* 漫无目的漂泊
* 护送某人

旅行途中会由世界状态生成遭遇：

* 美景
* 奇遇
* 危险
* 错过
* 传闻
* 物资消耗
* 天气影响

隐藏地点可以小概率遇到。
前置条件、传闻、地图、职业、特质、感知属性会提高发现概率。

# 15. 职业、技艺与营生

职业不是开局按钮，而是长期实践涌现出来的身份。

玩家通过反复做某类事，逐渐被世界视为某种人。

职业 / 技艺包括：

* 厨师
* 医生
* 铁匠
* 猎人
* 士兵
* 商人
* 药师
* 抄书人
* 遗迹调查者
* 驯兽师
* 符文匠
* 领路人
* 守夜人

技艺提升来源：

* 相关选择
* 长期项目
* 失败与成功
* 作品反馈
* NPC 教导
* 自我练习
* 特殊材料或工具
* 地区需求

技艺作品会成为实体，参与世界运行。

例如：

* 菜品可以被售卖、传播、改良，成为地方特色。
* 武器可以被使用、修理、断裂，进入装备历史。
* 医案可以被保存、传授、误用，影响后世医疗。
* 改良技术可以被玩家出售、传播、垄断或被偷学。

NPC 也可以拥有技艺成长，也可以创新菜品、打造装备、改良技术。

# 16. 食物、料理与地方文化

食物不是单纯饥饿条，而是生活质量、文化和职业系统的一部分。

食物字段包括：

* 饱腹值
* 理智影响
* 健康影响
* 保质期
* 腐败规则
* 食材来源
* 菜品稀有度
* 厨师水平影响
* 特殊词条

食物示例：

```text
军用干粮：
饱腹高
理智影响低
保质期长
长期连续食用会降低理智

湖湾鱼汤：
饱腹中
理智提升
健康轻微恢复
保质期短

腐败麦子：
饱腹低
理智下降
疾病风险上升
已腐败

霜狼炖肉：
饱腹高
理智提升
短期抗寒
魔物料理
```

高品质食物通常更容易腐败，特殊保存词条除外。
可以存在罐头、封存盒、冷藏魔法、保存道具等例外机制。

玩家和 NPC 都可以创新菜品。
菜品可以通过售卖、赠送、商队、军营、节庆、灾荒替代食品、厨师改良等方式传播。

# 17. 战斗系统方向

Chronicle 不做复杂操作型战斗。
战斗采用自动结算。

结构：

```text
遭遇敌意对象
↓
选择处理方式：战斗 / 逃跑 / 威慑 / 交涉 / 利用地形 / 投降
↓
若进入战斗，选择战斗方式
↓
属性 + 装备攻防 + 词条 + 状态 + 天气 + 敌人特性 + 随机性
↓
自动结算双方攻防
↓
生命先归零者失败
↓
进入后果结算
```

战斗方式不能有万金油：

* 稳健防守：防御上升，攻击下降。
* 强攻压制：攻击上升，受伤风险上升。
* 寻找破绽：暴击和特殊结果上升，失败风险上升。
* 保持距离：远程与逃跑机会提升，近战压制下降。
* 拼死一搏：逆转概率提升，永久伤势风险提升。

智慧生物可以出现交涉、威慑、求饶、谈条件、放过、处决等选择。
狼群、食人魔等直接攻击对象主要使用战斗姿态、逃跑、地形和诱饵等选项。

---

# 18. 战斗后果

战斗是否进入传记或地区记录，不由“是否战斗”决定，而由影响权重决定。

判断因素：

* 敌人重要性
* 战斗地点
* 是否有目击者
* 是否影响地区安全
* 是否改变关系网
* 是否造成永久伤势
* 是否影响装备历史
* 是否产生名声、恐惧、仇恨
* 是否具有情感权重

例如：

普通森林中杀死几头狼，通常不进入传记。
但如果狼群导致玩家断腿，或救下重要 NPC，或某把剑因此获得“弑狼者”进度，就可能被记录。

杀死长期伤人毁田的魔兽野猪，会影响村民关系和地区安全，进入记录概率高。

战败不死通常扣健康并产生伤势。
伤势由状态、战斗对象、装备、环境和结算结果涌现。
智慧生物战斗可能引发关系网后果。

---

# 19. 理智归零与失控

健康归零通常死亡。
战斗生命归零意味着战败。
理智归零进入失控结算。

理智归零可能导致：

* 死亡
* 游戏结束
* 疯癫
* 失控数年
* 被夺舍
* 多年后恢复清醒
* 获得禁忌特质
* 身体衰老
* 关系断裂
* 世界已发生巨大变化

失控期间世界自行演进。
角色恢复后，玩家首先看到：

* 过去了多少年
* 这几年发生了什么
* 自己身体变成什么样
* 世界变成什么样
* 自己新增了哪些词条
* 哪些关系已经断裂
* 哪些事件因自己缺席而错过

失控可以成为个人传记中的一章。

---

# 20. 个人传记

个人传记不是事件列表，而是一本文学化小说式纪事。

前台不一定显式分章，但后台需要分段生成：

* 开局
* 青年期
* 关键人生项目
* 重大转折
* 中年变化
* 晚年
* 死亡
* 后世评价

传记包含：

* 客观事实
* 角色亲历
* 他人记忆
* 世人评价
* 后世传闻

原则：

* 事实叙述不能误解玩家。
* 世人评价和传闻可以误解玩家。
* 传记不写成冷冰冰事件列表。
* 传记根据权重选择内容。
* 情感权重也是权重。

示例结构：

```text
事实：
阿尔维斯那晚确实把干粮给了陈米。

记忆：
陈米多年后只记得有人在雨里蹲下来，把食物塞进她手里。

世人评价：
湖湾镇后来有人说，他是为了收买老陈一家。
也有人说，他只是路过，连名字都没有留下。
```

玩家可以下载个人纪事。

---

# 21. 时代纪事

三名玩家角色结束后，世界归档，生成时代纪事。

时代纪事不是三名主角合集，而是这个世界在这一时代发生了什么变化。

内容包括：

* 地区兴衰
* 战争
* 饥荒
* 商路改道
* 技艺传播
* 食物文化变化
* 传闻与传说
* 玩家角色造成的影响
* 玩家角色未造成影响时，其人生中权重最高的事情

如果某个角色改变了世界，就写入时代纪事。
如果没有改变世界，只写其权重最高、最能代表这一生的事情。

# 22. 模块化开发原则

Chronicle 系统复杂，必须像搭积木一样分层实现，不能所有系统混在一起。

推荐模块拆分：

```text
WorldState 世界状态模块
Entity 实体模块
Location 地点模块
Trace 痕迹模块
Memory 记忆模块
Rumor 传闻模块
Clue 线索模块
Action 行动模块
LifeProject 长期项目模块
Settlement 阶段结算模块
CharacterState 角色状态模块
AttributeGrowth 属性成长模块
Relationship 关系模块
Travel 路线旅行模块
Skill 技艺模块
Food 料理模块
Combat 战斗模块
Equipment 装备模块
Legacy 遗产模块
Chronicle 传记模块
NarrativeSurface 叙事表面模块
```

每个模块必须遵守原则：

* 不直接生成剧情结论
* 只写入事实、状态、痕迹、记忆或候选行动
* 由叙事表面层负责翻译成玩家可读文本
* 由结算层负责把长期变化压缩成人生结果

# 24. 当前版本结论

Chronicle 当前的核心结构已经成立：

```text
地点局面是现在。
生涯是接下来。
线索是可能性。
纪事是已经发生过的人生。
世界状态是根。
玩家选择是刀。
痕迹、关系、伤势、物品、传闻和传记，是人生留下的形状。
```

下一步不应继续泛泛扩系统，而应从主界面和湖湾镇最小闭环开始，把这些系统拆成可实现的积木。
