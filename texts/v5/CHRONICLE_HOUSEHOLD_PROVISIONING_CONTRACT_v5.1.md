# 家庭供给与人物基础要素合同

更新于 2026-09-06，归属 H2，接续[寻粮合同](CHRONICLE_RESIDENT_FOOD_ACCESS_CONTRACT_v5.1.md)，不另立排期。

## 因果缺口

回音港 81001 的七日基线中，一个家庭的两名谋生成员各吃 14 餐，两名退休同住者均零餐，世界却剩余 275 份食品。原寻粮规则只关注个人饥饿，没有依据当面获知的家庭需要采购和返家的动机。

用户提出参考矮人要塞，以需求、性格、关系和记忆构成人物基础。这里采用可组合、可产生后果的方向，不采用“词条积累到某个数量就自动产生智能”的假设。更多字段也可能只增加重复动作、失控反馈和计算开销。每个新要素必须说明谁读取、谁改变、知情边界、真实成本，以及删除或改变它时能观察到的行为差异。

## 要素与真值

| 要素 | 本轮复用与接入 | 尚未完成 |
| --- | --- | --- |
| 生理需要 | StateStore 的饥饿、疲劳、健康；吃实物缓解饥饿，身体约束出行和工作 | 完整饮水、睡眠质量、疼痛、舒适和心理需求 |
| 性情 | 已生成的 temperament 影响家庭寻粮可接受的单程道路小时数 | 连续人格、价值观、信仰及经历改变性格 |
| 关系 | trust、familiarity、resentment 决定帮助意愿，实际收到粮食增加信任 | 全部社交行为的统一动机权重与社会推理 |
| 记忆 | MemoryStore 保存有事实来源、时间、地点的当面需要，离场后仍影响选择 | 传闻可信度、复杂遗忘、误认、创伤和长期人生规划 |
| 意图 | 从有效记忆、自己的钱和物品、已知供给、道路、身体产生采购或返家目标 | 通用效用规划器、多日预算、协商分工和承诺 |
| 所有权 | ItemStore 真实转移，ExchangeStore 付款，社会往来检查在场与本人财物 | 家庭共有账户、委托权限和成熟信用市场 |

不新增并行人格、库存或家庭资金 Store。种族、地理和文明服从原设定衔接合同；本轮没有新增矮人城镇或把原型镇改称正式地理。

## 规则与兼容

新世界在保存的 `resident_daily_life.food_access.household_provisioning` 显式启用 version 1。缺少配置的旧档继续旧行为。`social_presence_version: 1` 单独冻结社会到场规则，缺少子版本的早期实验档也不静默升级。

1. 成年同住者只有实际同处、不在路上，才能得知对方自报的饥饿和自身缺粮。没有远程读取实时饥饿或库存。远方后来吃饱也不会自动通知。
2. 记忆保存原事实、观察时间、当时家庭与回家目的地，有效期暂定 48 小时。未改变的交谈不每小时生成记录。再见到对方已经吃饱或持有食物时清除需要；过期后不继续用旧需要采购。
3. 最低帮助关系分为 `trust + familiarity - resentment >= 50`。先顾记忆中的极饿者，再按关系分和稳定 ID 排序，最多四人。数值是可逆基线，不是心理学定律。内向不等同于自私。
4. 谨慎单程容忍 2 小时、大胆 6 小时，其余 4 小时，记忆中有人极饿加 2 小时。身体需要休息优先，意愿不能跨越断路。购物时段和供给知识沿用寻粮合同。
5. 自己吃饱也可为家人采购。食品生产者仍可通过原作业取得食物；有粮时携粮返家。没有粮且无钱不生成虚假采购，不增金库或初始物资。
6. 到场采购只用自己的钱与现货价格，目标为每个待帮助者一份加自己一份。钱或当前可售批次不足就少买，未承诺整家必定吃饱。没有默认家庭共享钱袋。
7. 食物随真实持有人分段移动。有效家庭需要使携带者留粮，不自动把预留份额赠给无关者或卖掉；自己严重饥饿仍可吃携带口粮，所以允许途中带不够。
8. 到家且见到收粮人，才转移一份真实物品。对方已持粮、吃饱、死亡或不在场时不交付。先转物权，再由原规则消费，不直接改饥饿。饥饿者自己的最后一份口粮不能因 ID 排序被别人先取走。
9. 收粮人增加对提供者的信任并记住帮助。后续帮助选择读取真实关系。观察、采购、分段出行、交付和进食都有来源事实，不用日志冒充结果。
10. 资金排查暴露旧社会规则可远程拿同住者的钱还债。新版债务人仅在与债权人碰面时用本人财物偿还，仍记得家人需粮时先留补给预算。不在场的邻居不能因未发生的求助而被记作拒绝，也不能隔空争执。旧档兼容不等于认可旧路径的真实感。

这是有限条件选择，不是完整效用规划。未买到粮不算完成，不把记忆条数、成交数或关系值变化计作涌现完成度。没有新增随机危机、强制援助或指定 NPC 的剧情任务。

## 验收与后续

正常链的反例包括没交谈、记忆过期、远方恢复不知情、再见面取消、关系敌对、同一路程不同性情、断路、无款无货、收粮人缺席或死亡、重复交付、取用非本人资产和远程偿还。

原生保存、恢复及续跑一小时比较完整 Stores、会话、时间、随机数和日志，采用既有 JSON 精度。错误的证据、目标引用、观察日期和未知版本要拒绝。三种子七日对照同时间、资源和人口的禁用版本，分别审计实际餐数、极饿人时、真实交付和资金去向；没有改善也保留结果。合法旅行与等待通过 Godot 实际渲染观察用途和返家；这不等于真人试玩。

活动顺序只以[世界优先计划](CHRONICLE_WORLD_FIRST_PLAN_v5.1.md)为准。先完成有限付款方的实际需求、劳动、收入与物资使用，避免照顾家庭只能花尽积蓄；再用至少三个不同处境检验通用动机候选，继而连接原设定的粮食、工具与许可。

新增需求维度须连接一种真实满足方式、一种放弃的代价和至少一个受影响的他人。羞耻、孤独、信仰等尚无满足与反应规则的词条保持待设计，不先堆进人物面板宣称智能增加。这是 B3 的准入要求，不是新开一套人格系统排期。
