# Chronicle v5.1 地点局面与主界面交互规格

## 1. 文档定位

本文件是 Chronicle v5.1 重构阶段的第一阶段交互规格文档。

它不负责说明完整游戏系统，也不负责战斗、装备、职业、食物、天气等后续复杂系统。

本文件只回答一个问题：

```text
玩家打开 v5 重构原型后，主界面上有什么？玩家点哪里？点完发生什么？
```

本文件服务于路线图阶段 1：

```text
地点局面主界面原型
```

目标是先搭出 Chronicle 的前台承载面，让后续地点、线索、生涯、状态、长期项目都能放到同一个清晰框架中。

---

## 2. 核心原则

Chronicle 默认显示“地点局面”。

地点局面是当前时刻的世界切面。
它不是任务面板，不是纯地图，不是事件列表，也不是人生选择菜单。

核心关系：

```text
地点局面 = 现在
生涯 = 接下来
线索 = 可能性
纪事 = 已经发生过的人生
```

玩家可以在地点局面中：

* 查看当前地区状态
* 查看当前地点叙述
* 点击子地点
* 与人物互动
* 查看线索
* 选择行动
* 打开生涯面板
* 查看角色状态
* 查看背包、世界、设置等入口

“遇到事件”和“选择人生方向”是并行入口。
玩家既会被当前地点的局面撞上，也可以主动打开生涯，选择下一段生活方向。

---

## 3. 主界面区域

主界面分为五个区域：

```text
顶部导航栏
左侧角色状态
中央地点局面
右侧地区状态 / 线索 / 地点
底部行动选项
```

推荐布局：

```text
┌──────────────────────────────────────────────┐
│ 背包｜角色｜世界｜生涯｜设置                    │
├──────────┬───────────────────────┬───────────┤
│ 角色状态 │      地点局面          │ 地区/线索/地点 │
│          │                       │           │
├──────────┴───────────────────────┴───────────┤
│ 当前行动选项                                   │
└──────────────────────────────────────────────┘
```

---

## 4. 顶部导航栏

顶部导航栏显示：

```text
背包｜角色｜世界｜生涯｜设置
```

### 4.1 背包

本阶段只做入口占位。

点击后可显示：

```text
背包系统尚未接入。
```

后续用于：

* 物品
* 装备
* 食物
* 材料
* 遗物

### 4.2 角色

点击后显示角色详情面板。

角色详情至少包含：

* 六大属性
* 属性对应特质
* 生命、健康、精力、理智、饥饿
* 伤势
* 核心特质
* 关系展开入口

本阶段可以先显示静态详情，不要求完整关系系统。

### 4.3 世界

本阶段只做入口占位。

点击后可显示：

```text
世界地图尚未接入。
```

后续用于：

* 世界地图
* 地区地图
* 势力
* 时代信息
* 传闻传播范围

### 4.4 生涯

点击后打开生涯面板。

生涯面板是本阶段必须实现的占位功能。

至少显示：

```text
可开始的人生方向
听说过但尚未开启的人生可能
已完成经历
纪事
```

本阶段不实现完整长期项目，只实现结构和展示。

### 4.5 设置

本阶段只做入口占位。

## 5. 左侧角色状态

左侧是角色当前状态摘要。

它不是完整角色面板，只展示玩家随时需要看到的信息。

### 5.1 必须显示

```text
姓名
年龄
身份
当前地点

生命
健康
精力
理智
饥饿

伤势词条
精神词条
核心特质
六大属性简表
```

### 5.2 示例

```text
阿尔维斯
26 岁｜流浪者｜湖湾镇

生命：32 / 32
健康：76 / 100
精力：48 / 60
理智：67 / 100
饥饿：28 / 100

伤势：无明显伤势
精神：夜里睡得不深

力量 7
敏捷 8
智慧 9
魅力 6
体质 8
感知 10

核心特质：
- 流浪者
- 天生敏锐
```

### 5.3 左侧与角色面板的区别

左侧只显示摘要。

顶部“角色”面板显示完整展开。

例如左侧显示：

```text
感知 10
```

角色面板中展开为：

```text
感知 10
- 天生敏锐
- 旅途警觉
- 灰粉辨识进度
```

## 6. 中央地点局面

中央是主界面核心。

它显示当前地区或地点的具体局面。

### 6.1 地点局面必须包含

```text
当前地区 / 地点标题
当前叙述文本
可见人物
可见痕迹
子地点节点
当前局面提示
```

### 6.2 初始示例：湖湾镇

```text
湖湾镇

老陈铺子已经两天没有开门。
市场上的干粮又涨了一次价。
码头边的商船比往常少，守卫却比往常多。

你看见陈米坐在铺子门口。
她怀里抱着一个旧布袋，看见你时，把袋口往身后藏了藏。
```

### 6.3 子地点节点

湖湾镇初始应至少包含：

```text
老陈铺子
市场
码头
守卫所
废弃粮仓
```

点击子地点后，中央叙述切换到该地点。

例如点击“老陈铺子”：

```text
老陈铺子

铺门半掩着，门口贴着一张被雨水泡皱的告示。
台阶边有一点散开的灰白粮粉。

陈米坐在门边，怀里的布袋压得很紧。
```

点击“废弃粮仓”：

```text
废弃粮仓

这里离市场街不远，却很少有人白天过来。
门板裂开了一道缝，地上有灰白色的粮粉。

空气里有一股潮湿的霉味。
```

## 7. 右侧区域

右侧区域分三块：

```text
地区状态
线索
地点
```

建议使用折叠结构。

默认状态：

* 地区状态展开
* 线索有新内容时展开
* 地点保持可见

---

## 8. 地区状态

地区状态使用：

```text
抽象词 + 具体发生过的事
```

不能只显示精确数值。
也不能只写空泛词语。

### 8.1 示例

```text
粮食：紧张。
老陈铺子已经两天没开门，市场上的干粮涨了一次价。

治安：不安。
守卫最近增加了夜巡，码头边有人说昨晚听见仓库方向有响动。

商路：受阻。
北路商队迟了三天，码头边的货箱比往常少。

人心：压抑。
市场里很少有人大声说话，买粮的人总是先看一眼守卫。
```

### 8.2 本阶段要求

本阶段地区状态可以是静态数据 + 行动后局部变化。

例如点击“去市场打听粮价”后，粮食状态变为：

```text
粮食：紧张。
市场上的干粮涨了一次价。有人低声说，北路商队迟了三天。
```

## 9. 线索列表

线索先融入场景文本。
玩家通过行动获得线索后，才进入右侧线索列表。

### 9.1 线索标签

线索使用标签区分：

```text
[线索]
[追寻]
```

### 9.2 线索显示

示例：

```text
[线索] 粮价明天再涨一次
[线索] 北路商队迟到
[追寻] 北方龙影
```

### 9.3 按地点折叠

线索应按关联地点折叠。

示例：

```text
湖湾镇
- [线索] 粮价明天再涨一次
- [线索] 北路商队迟到

废弃粮仓
- [线索] 灰白色粮粉

北境传闻
- [追寻] 北方龙影
```

本阶段可以先用简单分组，不要求复杂树结构。

---

## 10. 线索行动卡

点击线索后打开线索行动卡。

### 10.1 行动卡字段

线索行动卡至少显示：

```text
线索标题
来源
可信度模糊描述
关联地点
可行动项
是否可加入追寻
```

### 10.2 示例

```text
线索：粮价明天再涨一次

来源：
老陈铺子门口的涨价告示。

可信度：
这是贴在店门口的告示，看起来不像传闻。

关联地点：
湖湾镇 / 老陈铺子

可行动：
[去市场打听粮价] 1小时
[询问老陈]
[暂时搁置]

是否可加入追寻：
否
```

另一个示例：

```text
线索：北方龙影

来源：
湖湾镇酒馆里一个受伤猎人的说法。

可信度：
这话已经传过几手，没人说得清最早是谁讲的。

关联地点：
北境 / 灰松城

可行动：
[前往灰松城打听] 15天，需要干粮
[寻找受伤猎人] 半日
[询问来往商队] 2小时
[将其加入追寻]

是否可加入追寻：
是
```

## 11. 地点列表

右侧地点列表显示当前地区的所有可见地点节点。

湖湾镇初始地点：

```text
老陈铺子
市场
码头
守卫所
废弃粮仓
```

点击地点节点应与中央子地点按钮效果一致。

地点列表不是世界地图，只是当前地区的可进入节点集合。

## 12. 底部行动选项

底部显示当前局面可执行行动。

### 12.1 行动类型

行动可分为：

```text
普通行动
对话行动
线索行动
危险行动
长期行动
特殊行动
```

本阶段可以用文字前缀区分，不要求美术颜色。

示例：

```text
[普通] 查看涨价告示
[对话] 走近陈米
[线索] 去市场打听粮价
[危险] 前往废弃粮仓
[长期] 在湖湾镇停留一月
[普通] 离开湖湾镇
```

### 12.2 行动点击规则

点击行动后：

```text
调用 apply_action(action_id)
更新状态
更新中央叙述
更新右侧地区状态
更新线索列表
更新底部行动选项
记录行动历史
```

### 12.3 时间成本

本阶段可先用文本提示时间成本，不做完整时间系统。

规则：

```text
不超过一小时：可以不显示时间
一小时以上：显示时间
半日以上：必须显示
跨日、跨月、跨年：必须明显提示
```

示例：

```text
[普通] 查看涨价告示
[线索] 去市场打听粮价 1小时
[危险] 前往废弃粮仓 半日
[长期] 在湖湾镇停留一月
```

### 13.1 本阶段目标

本阶段只做生涯面板占位，不实现完整长期项目。

必须显示：

```text
可开始的人生方向
听说过但尚未开启的人生可能

```

### 13.2 示例

```text

- 漂泊
- 定居
- 营生
- 追寻

听说过但尚未开启：
- 北境边境巡逻者
- 王都抄书学徒

- 暂无

- 暂无
```


```text

- 在湖湾镇停留一月
```

本阶段不要求生成正式结算，只做占位闭环。

## 15. 最小交互闭环

本阶段必须至少实现以下闭环。

### 15.1 初始局面

打开场景后显示：

* 阿尔维斯状态
* 湖湾镇叙述
* 地区状态
* 地点列表
* 初始行动

### 15.2 走近陈米

点击：

```text
[对话] 走近陈米
```

结果：

* 中央叙述变为陈米近景
* 底部行动变为：

  * 给她食物
  * 问粮从哪来的
  * 装作没看见
* 行动历史增加

### 15.3 查看涨价告示

点击：

```text
[普通] 查看涨价告示
```

结果：

* 中央出现涨价告示描述
* 右侧线索列表新增：

  * `[线索] 粮价明天再涨一次`
* 该线索可点击打开行动卡

### 15.4 去市场打听粮价

点击：

```text
[线索] 去市场打听粮价 1小时
```

结果：

* 中央出现市场打听文本
* 地区状态“粮食”说明发生变化
* 可能新增：

  * `[线索] 北路商队迟到`

### 15.5 前往废弃粮仓

点击：

```text
[危险] 前往废弃粮仓 半日
```

结果：

* 当前地点切换到废弃粮仓
* 中央显示废弃粮仓文本
* 底部行动变化为废弃粮仓相关行动

### 15.6 在湖湾镇停留一月

点击：

```text
[长期] 在湖湾镇停留一月
```

结果：

* 中央显示简短月度摘要
* 角色精力、饥饿或理智至少一项发生变化
* 地区状态至少一项发生变化
* 生涯面板“已完成经历”新增：

  * 在湖湾镇停留一月

## 16. 数据与代码拆分建议

本阶段代码应至少拆为三层：

```text
State
ViewModel
Viewer
```

### 16.1 State

负责保存当前原型状态。

职责：

```text
当前角色
当前地点
地区状态
地点列表
线索列表
行动历史
生涯摘要
apply_action(action_id)
```

### 16.2 ViewModel

负责把状态转换成 UI 可读数据。

职责：

```text
get_character_summary()
get_location_scene()
get_region_status()
get_clues_by_location()
get_location_nodes()
get_action_options()
get_life_panel_summary()
get_clue_action_card(clue_id)
```

### 16.3 Viewer

负责 Godot 界面展示与按钮绑定。

Viewer 不应直接写大量世界逻辑。
世界状态变化应放在 State 或 Actions 中。

## 19. 阶段成功标准

最低成功标准：

```text
存在独立 rebuild 场景
能显示地点局面
能显示角色状态
能显示地区状态
能显示线索和地点
能点击至少 3 个行动刷新 UI
能获得至少 1 条线索
能打开线索行动卡
能打开生涯面板占位
有测试或测试说明
不修改保护文件
```

理想成功标准：

```text
Godot 中可直接打开运行
测试输出 PASS
UI 区域清晰
State / ViewModel / Viewer 分离
报告完整
工作区干净
```

## 20. 后续连接

本阶段完成后，下一阶段进入：

```text
湖湾镇最小状态闭环
```

也就是从静态交互原型升级为：

```text
粮食压力
↓
粮价上涨
↓
老陈压力
↓
陈米饥饿
↓
发霉麦子
↓
玩家介入
↓
关系、痕迹、地区状态变化
```

本阶段不要提前实现第二阶段，只为第二阶段留下清晰接口。
