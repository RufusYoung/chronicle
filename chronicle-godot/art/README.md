# Chronicle 美术资源

所有正式美术及后续新增图像、字体、音频、模型、源文件都集中在此目录，不再分散到脚本、场景或项目根目录。新增资产必须同时记录来源、用途与发布状态。

| 目录 | 用途 | 当前发布状态 |
| --- | --- | --- |
| `environments/` | 地点环境画与其生成记录 | 苇岸地点画已接入；静态氛围画，不代表实时世界实体 |
| `fonts/` | 正式 UI 字体及完整许可 | 思源宋体，随包附 OFL 许可 |
| `icons/` | 项目与界面图标 | 现有 Godot 占位图标，尚非最终品牌美术 |
| `reference/legacy/` | 用户备用素材的集中检索副本，包括图标、贴图、音频和备用字体 | 授权未核实，不导入、不进入发布包 |

2026-09-05 从旧 `assets/world/`、`assets/fonts/` 和根 `icon.svg` 迁入正式资产，保留 Godot UID，更新实际引用。旧报告截图属于验收证据，保留在报告目录；历史项目 `_archive` 不作为当前资产源。

原 `素材包/` 是禁止清理移动的备份，本轮保留原件。`reference/legacy/` 是除 Godot 自动导入文件外的逐文件原样副本，非授权声明；不能因复制入 art 就转为可发布素材。后续确认某项可用时，再将其单独接入正式分类并补来源。没有实际接入的备用音效不能计作 Demo 已有声音。

目录约定：后续音效放 `audio/`、角色放 `characters/`、装备和道具放 `items/`；有模型或分层工程文件时放 `source/`，并记录导出文件对应关系。需要时创建，不预填空资产。`source/` 和 `reference/` 不作为运行资源导出。

正式资源、尺寸、哈希及隔离目录可通过 `python tools/check_art_assets.py` 检查。导出 Windows 包前自动执行同一检查。
