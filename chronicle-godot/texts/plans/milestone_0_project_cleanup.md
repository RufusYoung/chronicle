# Milestone 0：项目清理

## 目标

在不改变当前 Demo 玩法的前提下，建立清晰的活动代码、历史代码、长期文档和备用素材边界。

## 完成条件

- 当前入口文件保持原位。
- 嵌套旧项目副本移入 `_archive/legacy_project_copy/`。
- 旧 `world_generation.gd` 和对应旧 UI 入口完成归档。
- `data/` 与 `素材包/` 保持原位。
- `texts/` 形成 reports、specs、decisions、plans、archive 结构。
- 项目能够通过 Godot 加载和 Demo 冒烟验证。
- 形成正式清理报告并提交独立分支。

## 非目标

- 不开发世界模拟器。
- 不扩写事件。
- 不调整 UI。
- 不重构当前 v0.3 玩法脚本。
