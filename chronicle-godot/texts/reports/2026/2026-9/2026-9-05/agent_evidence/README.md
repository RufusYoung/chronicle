# 本轮证据索引

- `summary.json`、`agent_trace.jsonl`：两种子各三日自然演算，以及首轮脚本游玩。首轮区域策略错误地读取缺失字段导致往返，保留原始输出，不用于最终游玩覆盖结论。
- `play_checked/`：修正策略后的区域与第一冬正式接口游玩。无强制骰点、无 Stores 写入，不是人类 UI 输入或 LLM 自由探索。
- `contracts/`：初轮 50 项合同测试的 49 项通过记录，失败为存档末位小数规范化。
- `contracts_final/`：按原生存档精度比较并补上续跑后，51 项断言全部通过。其他行动与只读检查仍采用完整精度。
- `life_projects/`、`native_save/`、`time/`、`ux/`：本轮既有测试的 stdout、stderr 与结构化结果，共 8 个文件通过。
- `transport_final.log`：最终真实 Godot 进程通信 6 组测试通过，含中文分片、EOF、错误帧及超时处理。

本目录不包含公开参赛录屏、美术资产板或完整 Demo 人测结论。所有报告引用最终验证时应说明上面的范围，不能仅凭日志条数判断游戏质量。
