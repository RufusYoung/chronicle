# ADR-0003：事件与线索作为世界投影层

## 状态

已采纳

## 背景

如果事件直接成为世界变化的根源，项目会重新退回“抽事件 -> 选选项 -> 改计数器”的模式。这样即使事件很多，也无法证明世界本身正在运行。

## 决策

事件和线索不是世界变化的根源，而是世界状态变化被玩家看见后的表现层。

世界模拟先产生事实，例如资源短缺、生态衰退、势力摩擦或道路失序；投影层再把这些事实转换成传闻、环境线索、行动机会和事件。

## 后果

- 每个事件应能追溯到一个或多个世界状态原因。
- 事件结果必须写回世界状态，并影响后续投影。
- 线索可以失真、延迟或不完整，但不能脱离世界事实凭空生成。
- 内容设计需要同时记录触发原因、可见表现和状态写回。
