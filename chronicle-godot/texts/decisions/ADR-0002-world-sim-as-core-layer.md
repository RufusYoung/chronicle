# ADR-0002：世界模拟层作为核心层

## 状态

已采纳

## 背景

当前 Demo 的强项是线索、行动、事件和后果回流，但局部世界状态仍主要由玩家点击和事件模板推动。项目的长期目标不是构建更大的事件池，而是让世界在玩家不介入时也能持续变化。

## 决策

Chronicle 的长期核心是自运行世界模拟层。

地区、势力、资源、生态、关系和时间先形成可持续演化的状态；传闻、线索和事件从这些状态变化中产生。事件池扩写的优先级低于世界状态模型和演化规则。

## 后果

- 下一阶段优先实现最小地区状态、势力状态和 tick 规则。
- 玩家行为必须写回世界，而不是只产生一次性文本。
- 旧世界脚本只作为历史参考，不继续扩展。
- 系统验收应关注无玩家干预时世界是否仍会产生可解释变化。
