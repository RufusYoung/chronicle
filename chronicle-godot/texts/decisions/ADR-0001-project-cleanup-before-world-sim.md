# ADR-0001：在世界模拟开发前清理项目

## 状态

已采纳

## 背景

当前 Demo 已经可以运行，但仓库同时包含旧世界脚本、嵌套项目副本、未接入的数据驱动框架和缺少分类的文档。继续直接开发 `world_sim_mvp` 会让新逻辑与历史实验继续混杂，增加引用误判和回归风险。

## 决策

在开发 `world_sim_mvp` 前，先完成项目引用审计、旧代码归档、文档索引和目录规则整理。

清理只移动已确认不参与当前 Demo 的内容，不删除文件，不移动 `data/` 与 `素材包/`，不修改当前玩法和 UI。

## 后果

- 当前运行入口和长期资料的边界更清楚。
- 历史内容仍可恢复，但不会被 Godot 当作活动代码扫描。
- 新世界模拟层可以在明确的位置开始建设。
- 后续新增文件必须遵守文档和归档规则。
