# Chronicle 连续世界局面候选

2026-09-30 连续局面候选（`world_situation_v2`）。默认不运行预写旅途节点，从真实在场人物、亲见危险、装备需要及有限资源生成可行动作。可以追寻听到的去向、问别人是否见过某人，重逢时获知实际后续。普通结果留在现场，不弹“继续旅途”。本版验证因果玩法方向，不是已验收的参赛 Demo；此前真人体验失败，必须重新检验。

## 启动

同一目录保留 `Chronicle.exe` 与 `Chronicle.pck`，双击 EXE。无需安装 Godot 或 Python。

默认开启镜湖北岸、回音港外的旅途，种子81001；世界先自行运行两小时，从第1天10:00开始。第一次开局有12铜币、两份口粮、四份熏鱼和原有旧衣，均为有限初始财物，不会每日补发。有新版保存时自动继续；「新旅途」重新开始，但不立即覆盖保存。

## 怎么玩

- **当前打算**：只由你选择目的地；有关消息会对照本人防护显示，不把听到的每件事都变成任务。已经抵达的行程不会因为后来的消息自动要求你再去一次；明确重新选择才表示重访。旧存档没有选择时刻依据时，不会替你补造此前的旅行目的。
- **现场**：眼前人物、可见伤损、实际听到的打算及可行动作。有多个人时可切换关注对象，切换不耗时。普通行动后直接再选；关键反馈就地显示，超长细节按需打开。鼠标停在选项上可看说明，交出钱物前会确认实际代价。不会为凑剧情保证有人等你，地点无人也可等待。
- **地图与去向**：查看道路、读当地口信，沿已经听到或亲见的线索找人或查看险地。消息标注时间且会过时，不是远程定位；这是一张路线列表，不是完整地形地图。
- **行囊**：实物数量、耐久、装备效果与穿戴。换装10分钟，途中或交锋中不能换装；翻页不耗时。
- **人物**：六项属性、四项技艺和四种经历特质。成长来自实际行动，不保证每次升级。
- **旅途记录**：当前行动完整说明、已得消息与冒险经过。只在这里滚动查看长记录。
- **交谈、买卖与赠送、吃饭与休整**：按需打开。同类行动先折叠，再选人物或物品。交易要求对方真实在场、有货或有钱，不是无限商店。
- **谋生 / 制作**：自选生活方式，不是冒险前置。长工作仍有真实工时和材料代价，不靠反复制作填充旅程。
- **菜单 / Esc**：操作说明、音量、退出。音量为零时静音。关闭窗口可保存退出、不保存退出或取消。

普通问话、吃饭、交易和换装花10分钟；探查按按钮标注花10–60分钟或原有长行动时间。每累计整小时才结算普通世界活动，分钟余量保存在同一个原生世界。长途、劳动和交锋仍按标注小时计算。阅读、翻页和取消不耗时。

## 可以探索的内容

本实验只使用两处聚落及居民真实工作的地点。两个聚落的住户在实际回家后可提供有限夜间接待；可等待十分钟、一小时，或等至17时/明早6时。有人到来、服务开放、危险或身体恶化会打断长等待，不需要来回走路消磨时间。

当面询问后，可能了解到对方的装备需求。是否能送出、卖出、出钱或维修，取决于自己的物品、钱、现场条件和对方当前状态；不是固定事件的同一组选项。帮助不保证回报或立即出发。跟上亲见离开的人使用真实道路，不是强制组队或付费护送。资助不是借贷。原有24个条件节点和6个探索点保留在旧模式，未删除，但不计入本原型涌现证据。

也可以把身上正在穿的护具让给对方，但你会实际失去这件装备的防护。收下钱的人可能先买家里需要的口粮，也可能暂时买不到装备；答复只报告实际发生过的事。没人看见去向时会明确说不知道，旧消息不会自动更新。重复同一种劳动不再反复变成“新后续”。

选择长途道路会逐小时走到终点，危险或健康恶化会中断；途中时间、疲劳和世界变化均照常结算。疲劳时可选择“歇到恢复精神”，不用每小时重复点击；饥饿、危险或现场变化会提前打断。

田边交锋展示对象、状态、攻守脱离选项。点击先查看具体失败代价，再确认或取消；阅读与取消不消耗回合。结果说明伤害、损耗、成长和是否仍在交锋。对方因吃饱离开不等于被你击败。危险种类和战术深度仍有限，没有完整击杀战利品体系。

## 保存与旧版

新版保存位置：

`%APPDATA%\Godot\app_userdata\CHRONICLE_GODOT\agent_play\play\echo_realm\situation_manual.json`

「保存」覆盖这个新版手动槽；退出前请主动保存，没有自动存档。「读档」确认放弃未保存进展。失败会显示错误，不自动重试。

旧原件仍在 `world_demo\manual.json`，新版不读取、不覆盖、不迁移其规则。继续旧版可运行 `Chronicle.exe -- --legacy-world-viewer`。旧入口只用于兼容，不是本次体验入口。

9月30日早期局面存档仍按 `world_situation_v1` 运行，标题提示“旧世界”，不会自动增加新知识和新行为。点击“新旅途”开始v2；开始本身不覆盖旧保存，之后主动保存才会覆盖同一手动槽。

9月28日漫游版用 `Chronicle.exe -- --authored-roaming`，仍读取 `roaming_manual`，不把旧规则静默升级。后台 AI 使用 `Chronicle.exe --headless -- --agent-stdio`，新组合为 `scenario="echo_realm"`、`economy_variant="world_situation_v2"`；v1仍可显式启动。UI与代码代理调用同一合法行动入口，来源分别为 `native_ui` 和 `code_agent`；代理测试使用独立槽。不要让两个实例同时写 `situation_manual`。

旧 `world_adventure_v3` 对应规则2，`world_adventure_v2` 对应规则1，既有存档保留原规则。
