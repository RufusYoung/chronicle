# Chronicle 自由漫游原型

2026-09-28 玩家端重建候选。默认入口换为像素插图、单一情境、选择与结果页，不再展示生产仪表盘。保留背后的居民、物品、时间与关系模拟。本版不是已验收的参赛 Demo；此前真人体验失败，必须由新版实际试玩重新检验。

## 启动

同一目录保留 `Chronicle.exe` 与 `Chronicle.pck`，双击 EXE。无需安装 Godot 或 Python。

默认开启镜湖北岸、回音港外的旅途，种子81001。第一次开局有12铜币、两份口粮、四份熏鱼和原有旧衣，均为有限初始财物，不会每日补发。有新版保存时自动继续；「新旅途」重新开始，但不立即覆盖保存。

## 怎么玩

- **现场**：眼前的一件事和少量选择。可以调查、冒险、绕路或放弃，不必先完成谋生任务。行动后结果保留，点击「继续旅途」再选。
- **地图与去向**：查看可走道路和探索目的，可以离开未解决事件。这是路线列表，不是完整地形地图。
- **行囊**：实物数量、耐久、装备效果与穿戴。换装10分钟，途中或交锋中不能换装；翻页不耗时。
- **人物**：六项属性、四项技艺和四种经历特质。成长来自实际行动，不保证每次升级。
- **旅途记录**：当前行动完整说明、已得消息与冒险经过。只在这里滚动查看长记录。
- **交谈、买卖与赠送、吃饭与休整**：按需打开。同类行动先折叠，再选人物或物品。交易要求对方真实在场、有货或有钱，不是无限商店。
- **谋生 / 制作**：自选生活方式，不是冒险前置。长工作仍有真实工时和材料代价，不靠反复制作填充旅程。
- **菜单 / Esc**：操作说明、音量、退出。音量为零时静音。关闭窗口可保存退出、不保存退出或取消。

普通问话、吃饭、交易和换装花10分钟；探查按按钮标注花10–60分钟或原有长行动时间。每累计整小时才结算普通世界活动，分钟余量保存在同一个原生世界。长途、劳动和交锋仍按标注小时计算。阅读、翻页和取消不耗时。

## 可以探索的内容

回水洞、废灯台、断崖小径，以及新增的林缘、断桥和路碑，都是原设定锚点内的局部地点。两个聚落的住户在实际回家后可提供有限夜间接待。

现有共24个有条件的原创短事件节点，包含辨路、失物、过桥、夜探、有限装备和见闻分享。它们不是24条长剧情，也不是自主生成故事。知识打开更安全的选项；取走实物耗尽来源；护衣与路鞋不能在同一次发现中全拿。夜谈、住宿与饮料仍受主人是否在场及库存约束。

田边交锋展示对象、状态、攻守脱离选项。点击先查看具体失败代价，再确认或取消；阅读与取消不消耗回合。结果说明伤害、损耗、成长和是否仍在交锋。对方因吃饱离开不等于被你击败。危险种类和战术深度仍有限，没有完整击杀战利品体系。

## 保存与旧版

新版保存位置：

`%APPDATA%\Godot\app_userdata\CHRONICLE_GODOT\agent_play\play\echo_realm\roaming_manual.json`

「保存」覆盖这个新版手动槽；退出前请主动保存，没有自动存档。「读档」确认放弃未保存进展。失败会显示错误，不自动重试。

旧原件仍在 `world_demo\manual.json`，新版不读取、不覆盖、不迁移其规则。继续旧版可运行 `Chronicle.exe -- --legacy-world-viewer`。旧入口只用于兼容，不是本次体验入口。

后台 AI 使用 `Chronicle.exe --headless -- --agent-stdio`。新组合为 `scenario="echo_realm"`、`economy_variant="world_roaming_v1"`，原生规则 `journey_rules_version=3`。UI与代码代理调用同一合法行动入口和原生格式，来源分别为 `native_ui` 和 `code_agent`；代理测试使用独立槽。不要让两个实例同时写 `roaming_manual`。

旧 `world_adventure_v3` 对应规则2，`world_adventure_v2` 对应规则1，既有存档保留原规则。
