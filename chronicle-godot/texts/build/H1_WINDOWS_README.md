# Chronicle 回响之境世界原型

这是内部世界原型，用于检查连续世界、人物作息、存档、区域视图和资产打包。它还没有足够的玩家行动、危险出行、声音和内容来构成参赛 Demo，不应对外宣传为完成版本。

新世界现在从原设定的镜湖北岸、回音港周边启动。两处小聚落与 16 名居民属于港外生成细节，不代表整座回音港。区域页列出六个界域的背景，其他地区和大势力尚未运行模拟。旧三镇和湖湾镇、哨站存档不自动改名或迁入原设定；已有手动存档仍会原样继续，选择「新世界」才进入新的锚点范围。

## 启动与操作

在同一目录保留 Chronicle.exe 和 Chronicle.pck，双击 Chronicle.exe。无需安装 Godot 或 Python。

- 「现场」选择行动或旅行，按钮注明时间与已知代价。
- 「区域」查看聚落与道路示意；连线来自当前世界，道路图并非按比例地形图。
- 「角色」看属性；「记录」查看完整结果与世界信息。
- 现场结果右上角的「查看完整结果」可以直接打开记录，再用「返回现场」继续选择。
- 「保存」写入当前整个世界，覆盖已有存档时需要确认。
- 「读档」恢复保存时的状态，未保存行动会丢失；下一次启动也会继续这份存档。
- 「新世界」可输入种子，已有存档不自动覆盖；相同种子生成相同初始区域。
- 结算期间请等待提示，按钮暂时禁用；不需要反复点击。
- Esc 或关闭窗口会询问退出方式，可取消、保存并退出或退出而不保存。结算进行中会先等待完成。

存档位于 `%APPDATA%\Godot\app_userdata\CHRONICLE_GODOT\world_demo\manual.json`。退出前请手动保存，本版本没有自动存档。若读档失败，原文件会保留，屏幕显示错误；不要马上覆盖旧存档。

后台控制使用 `Chronicle.exe --headless -- --agent-stdio`，与源码代理入口共用协议，不使用桌面控制。可从源码仓库的 `tools/agent_play.py` 导入 `ChronicleClient(godot=<Chronicle.exe 绝对路径>, packaged=True)`；Python 只是测试客户端，正常游戏不需要 Python。代理存档与 UI 存档分属独立目录，不能直接互相加载。

## 现有边界

世界中有生成的居民、设施、资源和道路；组织生成仍保留在旧测试世界，原设定的大势力本轮只作为背景目录。人物的日常活动与聚合跨镇运输已经存在，但持续经济、玩家工作与危险旅途仍在开发。初始公共空间有时无人，不代表世界中没有居民；目前尚缺能自然引导玩家接触这些生活的行动。

本次新建的生成世界启用居民作息规则 v1。白天工人与守夜人按不同班次出行，到岗后才积累劳动时数，收工或身体不适时返回住处休息。途中和刚抵达的一小时不算生产；家庭不能从远处直接取走别人携带的食物。现场能看到真正到达的人，并显示本地人物动向。

新建世界还启用寻粮与到场采购。成年人会因饥饿带钱寻找本地或相邻聚落的供给，在实际碰见卖家后支付铜币、取得食物，再按原有规则吃下或同处分享；没有余粮、没钱和道路不可达会产生不同结果。现场能显示实际成交的人、货物和金额。

旧世界存档只升级所需定义清单，保留原来的模拟规则，不强制转换。要检查新作息和寻粮，请用「新世界」新建一次；原手动存档不会因此被覆盖。现阶段虽有食物现货销售和个人跨镇采购，持续收入、家庭补给与大宗运输仍不足以维持所有居民生活，资源面板的充足不等于居民口粮充足，不能把持续饥饿当作已完成的经济系统。

旧测试世界的苇岸地点画面由内置 imagegen 生成，属于静态美术样例，不代表画中人数、天气、船只或货物已被逐一模拟。回音港周边尚未制作专属地点画，不挪用原型图冒充原设定场景。

Godot 图标尚未替换；可执行文件没有数字签名。此构建仅完成开发机冒烟，不代表所有 Windows 电脑兼容。没有录制参赛视频，也没有提交作品。
