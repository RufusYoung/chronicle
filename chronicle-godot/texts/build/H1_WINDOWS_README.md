# Chronicle 回响之境世界原型

这是内部世界原型。正式新建世界已接入旅人生活、加工食品、沿岸装备、经历成长与危险出行，旧存档保留旧规则。像素场景、人物与装备、结果音效已接入；完整首次体验与独立玩家试玩尚未验收，不应对外宣传为参赛 Demo 完成版。

新世界现在从原设定的镜湖北岸、回音港周边启动。两处小聚落与 16 名居民属于港外生成细节，不代表整座回音港。区域页列出六个界域的背景，其他地区和大势力尚未运行模拟。旧三镇和湖湾镇、哨站存档不自动改名或迁入原设定；已有手动存档仍会原样继续，选择「新世界」才进入新的锚点范围。

## 启动与操作

在同一目录保留 Chronicle.exe 和 Chronicle.pck，双击 Chronicle.exe。无需安装 Godot 或 Python。

- 「现场」选择行动或旅行，按钮注明时间与已知代价。
- 「区域」查看聚落与道路示意；连线来自当前世界，道路图并非按比例地形图。
- 「角色」看属性；「记录」查看完整结果与世界信息。
- 「行囊与成长」查看实物、耐久、条件被动、四项技艺和四种经历特质。查看不耗时，穿戴或取下装备花费一小时；途中和交锋中不能换装。
- 「怎么玩」打开三页旅人手册；「声音」调整结果音效，0% 为静音。设置不改变世界存档，不推进时间。
- 现场结果右上角的「查看完整结果」可以直接打开记录，再用「返回现场」继续选择。
- 「保存」写入当前整个世界，覆盖已有存档时需要确认。
- 「读档」恢复保存时的状态，未保存行动会丢失；下一次启动也会继续这份存档。
- 「新世界」可输入种子，默认开启沿岸生活及其家庭、作业依赖；已有存档不自动覆盖，相同版本、规则与种子生成相同初始区域。要比较前轮规则，先取消玩家生活与沿岸扩展，再取消作业框架或家庭联动。
- 结算期间请等待提示，按钮暂时禁用；不需要反复点击。
- 短工可能因为雇主离场、遇险或不能付款而中断。结果会说明这次的实际原因、耗时和保留进度；继续同一份作业可接续，换作业会重计工时。中断不保证工资，也不会补发产物。
- 「地方生活实验」可单独开启；默认沿岸生活整合已经包含它。居民需要实际传话才能知道邻地供给，可走访、提出本地留粮约定、出资托运或亲自送出自有余粮。没有新增共享钱包或保证成功的援助剧情。
- 默认新建世界勾选「沿岸生活整合：谋生、装备与邻里协商」，同时启用玩家生活、身体代价、实体危险、交往及作业依赖。田边威胁会与居民竞争实际可采资源，吃到食物后暂退；居民与旅人仍可能遇险。新旅人只有两份口粮和一件旧衣，不会每日刷新补给。
- 后台当前组合为 `economy_variant="world_adventure_v1"`。`world_integration_v1`、`world_body_v1`、`world_content_v1`、`world_content_v2` 保留前轮规则；取消沿岸整合但保留玩家生活可体验原生活 v2。取消玩家生活也会取消沿岸整合，旧存档不自动迁移。
- 新世界中，旅人和初始居民持续极饿每六小时损失两点健康，本版饥饿损耗下限为 40；极饿作业多耗两点疲劳，进攻/防守判定减二。进食止损，恢复健康仍要休养，不会凭空补给；撤离不受此项减值。原有手动存档不会获得这些新规则，需新建世界体验。
- 720p 现场路线每页两条，人物摘要三条；路线可翻页、人物完整详情在记录页。字号不缩小，翻页不推进时间。
- Esc 或关闭窗口会询问退出方式，可取消、保存并退出或退出而不保存。结算进行中会先等待完成。

存档位于 `%APPDATA%\Godot\app_userdata\CHRONICLE_GODOT\world_demo\manual.json`。退出前请手动保存，本版本没有自动存档。若读档失败，原文件会保留，屏幕显示错误；不要马上覆盖旧存档。

后台控制使用 `Chronicle.exe --headless -- --agent-stdio`，与源码代理入口共用协议，不使用桌面控制。可从源码仓库的 `tools/agent_play.py` 导入 `ChronicleClient(godot=<Chronicle.exe 绝对路径>, packaged=True)`；Python 只是测试客户端，正常游戏不需要 Python。代理存档与 UI 存档分属独立目录，不能直接互相加载。

## 现有边界

世界中有生成的居民、设施、资源和道路；组织生成仍保留在旧测试世界，原设定的大势力本轮只作为背景目录。人物的日常活动、运输与有限玩家生计已经存在，但持续生活平衡和旅途内容仍在开发。初始公共空间有时无人，不代表世界中没有居民。

本次新建的生成世界启用居民作息规则 v1。白天工人与守夜人按不同班次出行，到岗后才积累劳动时数，收工或身体不适时返回住处休息。途中和刚抵达的一小时不算生产；家庭不能从远处直接取走别人携带的食物。现场能看到真正到达的人，并显示本地人物动向。

新建世界还启用寻粮与到场采购。成年人会因饥饿带钱寻找本地或相邻聚落的供给，在实际碰见卖家后支付铜币、取得食物，再按原有规则吃下或同处分享；没有余粮、没钱和道路不可达会产生不同结果。现场能显示实际成交的人、货物和金额。

新建世界也启用家庭供给 v1：居民在碰面时得知家人缺粮，记住需要，可能用自己的钱采购并沿道路带回。帮助意愿读取关系，出行容忍度读取性情；食物交给实际在场的家人后才会被吃掉。现场能看到为谁买粮、买了什么、花了多少钱，以及随后带粮返家的动作。旧社会规则中的远程还债和直接挪用同住者财物，在新规则中被禁止。

默认新世界进一步接通家庭备粮、作业地存粮、共有粮柜与付费送粮。生产者实际拿出粮食和铜币，车夫沿道路送达后才取得运费；家人还要回到粮柜所在住处取粮、进食。没有足够存粮、付款能力、道路或收货空间时，托付不能照常成交，逾期的货包需要带回。

买不起口粮的成年人可能放下原安排，去已知的本地公用作业地采食。身体、时间、道路和采收权限仍然约束行动；采食产量低于专业劳动，不付工资，也不改变永久职业。这为无食品职业的家庭提供了有限的求生途径，还不是成熟的专业分工经济。

旧世界存档只升级所需定义清单，保留原来的模拟规则，不强制转换。要观察家庭与谋生联动，请用「新世界」并保留勾选；原手动存档不会因此被覆盖。也可以在后台开局明确指定 `scenario="echo_realm"`、`economy_variant="household_livelihood_v1"`。没有完整效用规划、复杂人格、跨镇政治或玩家人生；现场摘要后的完整人物与结果在「记录」查看。

「区域」中已接入回音港外镜湖北岸的专属环境插画，可点「查看原设定背景」阅读六界域资料。画面由内置 image_gen 生成并标为静态，不代表实时天气、船只、人物和库存。旧测试世界的苇岸插画单独保留，没有改名冒充原设定场景。

作业框架 v1 让捕捞、制绳及修补共用实际工时、材料和物品事务。绳具会用坏，居民可在身体、家人和工时的约束下选择修补、当面付钱购买或另谋口粮；卖家不在场、没有余货、没有钱时，不会凭空成交。修补只能恢复部分耐久，次数有限。现场显示实际库存、耐久、作业结果和主人是否在场。后台显式使用 `economy_variant="work_framework_v1"`；未指定的旧 API 默认值不变。

不勾选玩家生活时，这是原有观察入口；勾选后可以本人作业、购买和维护工具。七日检查中仍有人长时间缺粮，不能将跨用途机制通过等同持续生活或游玩趣味通过。

地方生活实验的后台入口为 `economy_variant="community_life_v1"`。消息保留原始观察时刻与传递来源，48 小时过期，最多转述四次；供货消息不保证到场仍有货。代表提出的约定只影响真正听到的人。现场突出一条完整的近期消息，更多经过可打开完整记录。自送援助会占用出粮者自己的路程和时间，没有运费收入；请勿将它与受雇车夫的付费运输混为一谈。这仍是内部世界观察实验，不代表玩家生活与跨镇政治已经做完。

此前独立地方生活实验的三种子三十日验证了有限的自然请求、送粮、留粮拒绝与生活反馈，也发现交往挤占工时、部分被抚养者长期缺粮。新版沿岸整合调整了食物生产与采食取舍，并增加拒绝后的有限减量协商；旧实验的结果不作为新版本平衡已通过的证明。验证因果不等于验证生存平衡、完整协商或游戏性。

沿岸新世界有 12 种可制作装备，覆盖武器、外衣与随身用具；图鉴列出效果、制作门槛与代价。长枪有利进攻但妨碍撤离，叠层苇甲偏防守，轻披和结绳带有利退路。制作从真实苇材与工具开始，沿岸编织经验打开高级配方，不会凭等级奖励直接发装备。居民使用同一物品与穿戴系统；没货、缺钱、卖家不在场时交易可能失败。这是沿岸起步装备集，还没有完整金属、稀有词缀或战利品体系。

交锋消耗武器或外衣耐久；带有随身用具磨损规则的新世界，每轮交锋还消耗随身用具一点耐久。归零装备失效并卸下，实物仍留在行囊。回工棚修补需要材料与工时，次数有限；不能通过反复穿脱恢复耐久。实际制作、行路、攻守和受伤可以留下技能或特质，守势习惯与伤后警觉也会牺牲进攻能力，伤势仍需另行恢复。

应用图标已替换为原创像素书页图标；可执行文件没有数字签名。此构建仅完成开发机冒烟，不代表所有 Windows 电脑兼容。没有录制参赛视频，也没有提交作品。

本包保留一个**默认关闭**的自费倒卖实验。后台指定 `economy_variant="worksite_carting_v1"` 可运行；它与默认联动规则中的付费送粮不同。先掏钱买货再卖出的旧实验在三种子中均未形成运抵后盈利成交，生活表现恶化，未采用为默认方案。失败记录仍保留，没有用增加初始钱或保证买家掩盖结果。

## 实体危险实验

新世界勾选该实验，或后台使用 `economy_variant="world_danger_v1"`。种子 81001 白天沿路去石渡坞坡田可以接触危险，但是否仍在交锋取决于当地时间、居民和威胁状态，不保证固定剧情。

进攻、防守和脱离都是正式行动，各经过一小时。防守积累最多四点优势，进攻或脱离消耗优势；成功脱离后需自行选择道路离场。威胁受到重创会暂时退入同一地块的灌丛，之后可能回来。没有额外战利品，也没有永久击杀。

安全处可休养，每小时降低一点疲劳。恢复健康与挫伤需要随身食物，一份支持六小时，挫伤需要十二小时实际休养。仅消除疲劳不吃口粮；无粮时休息仍可降疲劳，但不能治疗。结果显示健康、挫伤进度、剩余食物和疲劳的实际变化。伤势及衣物损耗随原生存档保留。

这里验证的是危险、装备与居民生活的有限联动。玩家可以通过现有库存购买和采食补充消耗，但仍没有完整职业、永久死亡、旅程事件密度或独立玩家试玩，不能当作已完成的可玩 Demo。

## 正式旅人生活

开局后可到芦湾埠泊台。白天采集自己的口粮，或帮有钱、有需要且在场的人采收，完成后由对方支付三铜币，产物交给对方。雇主可能离开，资源也可能不足；不要把可见选项当成保证成功的任务。

长工棚的工匠有现货且在场时可买绳具。绳具可用于网具捕捞，提高产量，但每轮磨损一耐久。耐久耗尽后回长工棚，花时间与当地材料修补；修补次数有限。购买、出行、工作和休息都推进同一个世界。

入夜做不完的工作可在翌日继续同一项；选项显示已做及剩余工时，换活会重新准备。新版本的当地公地允许访客按每日有限额度采收，不改变居民归属；坡田一轮用 0.75，今日一单位扣取后剩下的额度不足再做同一轮，可改为加工自带材料、交易或另路。实际资源和工时仍须付出，不会次日补发食物。缺少权限、原料或工具时显示原因。有人使用了你参与补充的粮食，碰面后可能出现询问后续的选项，回答来自真实存粮或进食事实。混合存放的食物不逐份追踪独占来源。

通常每六小时饥饿加深一级，吃饭实际扣除所选的那份食物。新版本可选择吃鲜食还是留好的熟食；熏湖鱼额外维持六小时不变饿，烤根块四小时，吃饭本身会用掉一小时。界面显示真实剩余饱腹时间，时间用完后照常变饿。途中只可继续赶路，抵达前不能隔空劳动和购物。请在「角色」查看行囊、耐久与全部属性。当前短工与供货可能稀少，等待密度仍待改善；不要用连续点击等待代替所有选择。

v2 可以当面询问居民的作业地点、工时和余货，消息带有时间，12 小时后标为过时。路线下方说明地点用途，不承诺远处还有货。没有人在场时，不能隔空问话。

有余粮时，可主动卖给饥饿且付得起钱的在场成年人，也可以把一份食物无偿分给缺粮者。两种方式都转移实际食物；对方之后进食、存粮或分给家人，依其自身处境决定。局部帮助不保证所有居民日后更宽裕。

行动区可按「谋生」「买卖与分粮」「交谈」「休整与赶路」筛选，筛选和翻页不耗时间。夜间可连续歇一阵，途中可走完当前路段；世界仍逐小时运行，严重饥饿会打断休整，遇险需另作决定。现场只突出当前需要和近期后续，完整回答与经过在「记录」。

## 工具与第三方资料

沿岸生活扩展中，渔场可把鲜鱼加工为熏湖鱼，田地可加工烤根块；新版本的加工食品有真实饱腹时长，尚无保鲜、腐败与完整营养模拟。长工棚能捻细绳、合股，绳具耐久不同，实际材料与磨损写在作业说明里。绳股起毛、在场者缺粮时会出现短插曲，选项仍执行正常劳动或真实分粮买卖；可以不处理，没有额外奖励或强制任务。完成后选项冷却，不必反复点击。
