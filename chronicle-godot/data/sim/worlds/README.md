# World 实例数据

## 职责

`worlds/` 保存正式世界的版本化启动配置。生成后的实例及其全部 Stores 由原生 SaveEnvelope 保存到用户目录，不把游戏存档混入源码。

## 与 raw 的区别

Raw 定义“什么可以存在”。

World 启动配置选择哪一片范围、哪些生成规则；生成后的世界实例记录已经存在的实体与发生的事情。世界设定目录在 `raw/world_defs/`，设定文本本身不是已执行的模拟。

## 与 fixtures 的区别

Fixture 服务测试。

World 实例服务正式运行和存档。

## 当前状态

`echo_port_environs_v1.json` 是回响之境首个正式地理锚点启动配置。回音港周边两处小聚落共生成 16 名居民；这不是回音港全城人口。旧北境三镇位于 `fixtures/`，保持回归用途，不自动迁入原设定。
