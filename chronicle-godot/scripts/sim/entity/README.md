# Entity System

## 职责

管理世界中存在的实体。

## 管理的数据

人物、物品、地点对象、组织、商队、小队、痕迹载体和其他可模拟对象。

## 输入

Raw Definition、世界生成结果、行动事务、长期项目结算和世界推进事件。

## 输出

实体查询、实体生命周期、实体位置、实体组件和可见性。

## 不负责什么

不负责决定行动，不负责写文学文本，不负责结算关系变化。

## 与其他系统的关系

State、Relationship、Location、Item、Action 等系统会读取实体存在性和组件信息。

## 当前状态

阶段 5.5 步骤 2A 已接入正式运行链：

- `SimSession` 启动时先注册 ObjectDef，再由 `EntityStore` 装载世界实体。
- `EntityStore` 是实体身份、类型、显示名、标签等静态元数据的唯一真值。
- 位置和其他可变字段由 `StateStore` 管理，Snapshot 只负责合并投影。
- 严格模式拒绝未知实体类型；旧 fixture 通过兼容模式迁移并报告警告。

当前还未实现通用的运行时实体创建、销毁和跨存档重建合同。
