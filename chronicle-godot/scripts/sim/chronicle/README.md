# Chronicle Output System

## 职责

把一生和时代整理成个人纪事与世界纪事。

## 管理的数据

个人传记、时代纪事、角色归档、世界归档、事实权重、传闻评价和阶段回顾。

## 输入

事实、长期项目、关系、记忆、伤势、装备历史、传闻、地区变化和死亡事件。

## 输出

个人传记、时代纪事、Markdown 导出素材和世界归档摘要。

## 不负责什么

不负责生成虚假事实，不负责替代 Fact / History System，不负责实时 UI 行动文本。

## 与其他系统的关系

Chronicle 读取 Fact 作为骨架，读取 Memory、Rumor、Relationship 和 Equipment History 作为叙事层材料。

## 当前状态

骨架阶段，暂未实现正式逻辑。
