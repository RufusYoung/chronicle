# Location System

## 职责

管理局部空间、子地点和可激活对象。

## 管理的数据

城镇、街道、店铺、仓库、哨站、厨房、市场、码头、图书馆、医馆、矿洞、森林和遗迹。

## 输入

PlaceDef、地区状态、实体位置、行动事务、世界推进、传闻和长期项目。

## 输出

当前地点上下文、可见实体、可见物品、可见痕迹、地点标签、风险、子地点和行动候选上下文。

## 不负责什么

不负责保存最终按钮表，不负责直接改变世界，不负责写文学文本。

## 与其他系统的关系

Action 读取地点上下文生成候选，Narrative Surface 读取地点素材生成前台文本。

## 当前状态

骨架阶段，暂未实现正式逻辑。
