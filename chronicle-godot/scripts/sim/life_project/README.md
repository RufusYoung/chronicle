# Life Project System

## 职责

管理跨日、跨月、跨年的人生阶段。

## 管理的数据

服役、定居、营生、求知、追寻、漂泊、学徒、照顾某人和隐居恢复。

## 输入

角色状态、地点、组织、制度、关系、地区状态、线索、玩家选择和世界推进。

## 输出

年度节点、阶段摘要、状态变化、关系变化、事实、记忆、特质、伤势、技能成长、阶段结算和纪事素材。

## 不负责什么

不负责把长期项目简化为跳过时间，不负责直接写最终传记，不负责 UI 面板绘制。

## 与其他系统的关系

World Tick 推进长期项目，Transaction 写入关键节点，Chronicle 读取项目事实生成传记。

## 当前状态

骨架阶段，暂未实现正式逻辑。
