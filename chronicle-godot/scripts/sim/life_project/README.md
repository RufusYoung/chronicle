# Life Project System

## 职责

管理跨日、跨月、跨年的人生阶段。

## 管理的数据

服役、定居、营生、求知、追寻、漂泊、学徒、照顾某人和隐居恢复。

## 输入

角色状态、地点、组织、制度、关系、地区状态、线索、玩家选择和世界推进。

## 输出

年度节点、阶段摘要、状态变化、关系变化、事实、记忆、特质、伤势、技能成长、阶段结算和纪事素材。

## 不负责什么

不负责把长期项目简化为跳过时间，不负责直接写最终传记，不负责 UI 面板绘制。

## 与其他系统的关系

World Tick 推进长期项目，Transaction 写入关键节点，Chronicle 读取项目事实生成传记。

## 当前状态

已实现第一冬与第一季度的正式生活项目控制器，包括职责条件、统一效果事务、阶段结算、成长候选、阶段交接、存档恢复和状态约束生活插曲。

生活插曲先根据地点、职责标签、人物或据点状态筛选候选，再由 Session RNG 决定是否出现及选中哪一项。待回应时职责和交易会暂停；回应只结算一次，并随 `life_project_runtime` 保存和恢复。

标记为 `incidental` 的插曲只能直接改变状态、关系、物品和普通记忆，不能创建传闻、调查、义务、延迟后果或 Chronicle。需要长期展开的内容必须使用独立的重大事件合同，不能借生活插曲绕过因果边界。
