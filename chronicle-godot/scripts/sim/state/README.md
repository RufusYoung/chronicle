# State / Need System

## 职责

管理实体的数值、状况和需求压力。

## 管理的数据

生命、健康、精力、理智、饥饿、恐惧、疲劳、年龄、疾病、腐败度、新鲜度、湿度和损坏度。

## 输入

时间推进、行动事务、物品效果、地点环境、地区压力和长期项目。

## 输出

状态变化、需求压力、行为倾向、行动条件、叙事素材和结算素材。

## 不负责什么

不负责直接写 UI 文本，不负责创建实体，不负责生成传闻。

## 与其他系统的关系

Action 读取状态作为候选条件，Transaction 写回状态变化，Narrative Surface 把状态翻译为文本。

## 当前状态

骨架阶段，暂未实现正式逻辑。
