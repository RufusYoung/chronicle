# Combat Encounter System

## 职责

把一次短遭遇转换为可预览、可复现、可解释的自动检定，并通过正式事务写回事实、健康、疲劳、伤势特质和装备耐久。

## 当前合同

- 敌人必须提供可观察特征、危险等级以及战斗、防追击或交涉难度。
- 每个处理方式声明计分目标、行动标签、失败代价和装备磨损栏位。
- 六维属性形成基础攻击、防守、撤离、影响与控制数值。
- `V5ActionContractResolver` 汇总行动、天赋、特质、印记、技艺和已装备物品的 Modifier。
- 预览同时返回已触发修正和未触发条件，不能只显示一个最终数字。
- 结算使用外部传入的 1 至 6 点可复现骰值，不在解析器内部偷偷抽取随机数。
- 失败最多把健康降到 1，并可形成伤势、疲劳和装备磨损；立即死亡不属于默认失败。

## 当前边界

G2.5-B 已把合同接入 `SimSession` 与正式可玩界面。玩家在行动前能看到对手的可观察特征、危险、三种处理方式的最低骰点与失败代价；结算后立即看到公式、状态和装备损耗，全部处理方式同时消费，普通探索恢复。

G2.5-C 已加入 `CombatEncounterDirector`。同一独占组可以声明多个候选及权重，并以地点标签、地区状态、压力、在场敌人标签、既有事实、角色最低状态和时间窗口筛选；正式种子从合格候选中可复现地选择一个，选择写入存档游标。未选候选不进入界面，已解决候选会消费整个独占组，遭遇期间等待与旅行同时锁定。

当前两个遭遇定义和敌人仍为手工内容，系统负责选择何者出现，并根据当前属性、伤势、装备、耐久、环境、处理方式和骰值产生结果。这还不是敌人或遭遇内容生成器，也不包含复杂回合操作或战斗动画。
