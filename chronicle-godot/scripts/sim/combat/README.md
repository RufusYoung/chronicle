# Combat Encounter System

## 职责

把一次短遭遇转换为可预览、可复现、可解释的自动检定，并通过正式事务写回事实、健康、疲劳、伤势特质和装备耐久。

## 当前合同

- 敌人必须提供可观察特征、危险等级以及战斗、防追击或交涉难度。
- 每个处理方式声明计分目标、行动标签、失败代价和装备磨损栏位。
- 六维属性形成基础攻击、防守、撤离、影响与控制数值。
- `V5ActionContractResolver` 汇总行动、天赋、特质、印记、技艺和已装备物品的 Modifier。
- 预览同时返回已触发修正和未触发条件，不能只显示一个最终数字。
- 结算使用外部传入的 1 至 6 点可复现骰值，不在解析器内部偷偷抽取随机数。
- 失败最多把健康降到 1，并可形成伤势、疲劳和装备磨损；立即死亡不属于默认失败。

## 当前边界

这一模块不负责界面按钮、敌人生成、复杂回合操作或战斗动画。G2.5-B 会把该合同接入短决策遭遇和正式可玩界面。
