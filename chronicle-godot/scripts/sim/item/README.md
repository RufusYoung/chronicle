# Item / Material System

## 职责

管理物品、材料、食物、工具、货物、书籍、药物和普通道具。

## 管理的数据

材质、用途、所有权、价值、腐败度、耐久、可食用性、可交易性、危险性、文化意义和历史记录。

## 输入

Raw ItemDef、MaterialDef、制作规则、腐败规则、交易规则、行动事务和世界生成。

## 输出

行动条件、经济影响、装备构成、食物效果、痕迹生成和传记素材。

## 不负责什么

不负责装备专属历史规则，不负责完整经济模拟，不负责地点叙述。

## 与其他系统的关系

Equipment 读取可装备物品，Transaction 写入物品变化，Trace 可由物品状态生成。

## 当前状态

骨架阶段，暂未实现正式逻辑。
