# Economy / Pressure System

## 职责

管理资源压力、短缺和物价趋势。

## 管理的数据

粮食压力、药品压力、武器短缺、口粮短缺、债务压力、贸易中断、物价趋势和供需关系。

## 输入

地区状态、商路状态、库存、消耗、灾害、战争、玩家交易和 NPC 行动。

## 输出

价格变化、地区状态、NPC 行为压力、偷窃风险、走私风险、行动候选和传闻素材。

## 不负责什么

不负责完整金融模拟，不负责直接写 UI 文本，不负责生成最终行动结果。

## 与其他系统的关系

Region 读取压力趋势，Action 读取压力生成候选，Transaction 写入资源变化。

## 当前状态

骨架阶段，暂未实现正式逻辑。
