# Settlement Migration And Absorption

本目录负责居民抵达目的聚落后的住房、生计和最小社会嵌入。迁徙本身仍由 `resource/settlement_network_system.gd` 决定。

`SettlementAbsorptionSystem` 每日扫描尚未完成的 `household_migrated` 事实，并在配置的等待天数后执行一次正式评估：

1. 根据住宅地点的所属聚落、当前住户和单处容量寻找能容纳整户的真实住屋；
2. 根据目的聚落的职业定义、最大槽位、当前从业人数和本地工作地点为迁入劳动者匹配生计；
3. 形成迁入家庭与当地接引者、同事之间带来源的关系变化；
4. 成功时写入住房、再就业、吸纳事实和纪事；失败时写入临时安置评估、住房需求或失业压力。

系统只返回 `TransactionResult`，由统一 Writer 原子提交状态、关系、压力、事实和 Chronicle。住房与岗位不足时不能创建不存在的住宅、职业或工作地。

当前边界不包含建房、租赁、住宅所有权、工资、企业生命周期、可进入的临时营地或再次迁徙决策。这些压力只能作为后续组织响应和持续演化的输入。
