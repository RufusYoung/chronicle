# World Tick System

## 职责

在玩家行动之间推动世界变化。

## 管理的数据

每日推进、半日推进、月度推进、年度推进、长期项目推进、失控期间推进、角色死亡后推进和第二角色出生前推进。

## 输入

时间、地区状态、实体需求、经济压力、组织目标、当前事实、长期项目和随机种子。

## 输出

新事实、状态变化、NPC 行动、地点变化、传闻传播、地区趋势、死亡、出生和迁徙。

## 不负责什么

不负责只围绕玩家推进世界，不负责 UI 展示，不负责纪事文本润色。

## 与其他系统的关系

World Tick 调用 State、Region、Economy、Institution、Fact、Rumor 和 Life Project 的推进入口。

## 当前状态

骨架阶段，暂未实现正式逻辑。
