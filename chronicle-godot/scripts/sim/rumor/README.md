# Rumor System

## 职责

管理事实和记忆在社会中的传播与失真。

## 管理的数据

来源事实、当前版本、传播层数、真实性概率、传播路线、夸大标记、恶意篡改标记、所在地点和可继续传播性。

## 输入

事实、记忆、见证者、地点人流、商路、酒馆、组织网络和人物名声。

## 输出

新线索、误解、名声、地区舆论、后续角色可听到的前角色传闻和纪事中的世人评价。

## 不负责什么

不负责改写事实，不负责最终传记，不负责行动事务。

## 与其他系统的关系

Fact 提供客观来源，Memory 提供主观版本，Chronicle 可引用传闻但不能把假传闻写成事实。

## 当前状态

骨架阶段，暂未实现正式逻辑。
