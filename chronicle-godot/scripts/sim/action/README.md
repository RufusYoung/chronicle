# Action Affordance System

## 职责

生成当前可以执行的行动候选。

## 管理的数据

行动候选、行动来源、目标实体、时间成本、规则来源、优先级和可见性条件。

## 输入

当前地点、可见实体、可见痕迹、玩家状态、物品、关系、制度、地区压力、已知线索和当前长期项目。

## 输出

`ActionCandidate[]`。

## 不负责什么

不负责直接改变世界，不负责写叙事文本，不负责决定长期结局。

## 与其他系统的关系

Action 读取各系统上下文，Transaction 执行被选中的候选，Narrative Surface 显示候选文本。

## 当前状态

骨架阶段，暂未实现正式逻辑。
