# Institution System

## 职责

管理组织、制度、社会规则、权力结构和角色义务。

## 管理的数据

家庭、军队、小队、商会、教团、学院、地方守卫、贵族家族、工坊、黑市、债务关系、法律、军纪和行会规矩。

## 输入

组织定义、实体身份、关系、地点、事实、行动事务、长期项目和地区状态。

## 输出

行为限制、行动候选、后果规则、惩罚规则、身份变化、组织记忆和传闻传播。

## 不负责什么

不负责通用人物状态，不负责物品效果，不负责叙事文本。

## 与其他系统的关系

Action 读取制度约束，Transaction 写入制度后果，Relationship 和 Memory 承接组织内反应。

## 当前状态

骨架阶段，暂未实现正式逻辑。
