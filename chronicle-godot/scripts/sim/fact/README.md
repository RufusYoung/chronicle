# Fact / History System

## 职责

管理客观发生过的事实和历史记录。

## 管理的数据

事实 ID、事实类型、参与实体、地点、时间、来源事务、可见性、纪事权重和历史索引。

## 输入

行动事务、世界推进、长期项目、战斗、交易、死亡、出生和迁徙。

## 输出

记忆、关系变化、传闻、纪事素材、地区历史和世界历史。

## 不负责什么

不负责写文学文本，不负责保存主观误解，不负责直接生成行动候选。

## 与其他系统的关系

Memory 从 Fact 生成主观记忆，Rumor 从 Fact 或 Memory 传播，Chronicle 读取事实作为骨架。

## 当前状态

骨架阶段，暂未实现正式逻辑。
