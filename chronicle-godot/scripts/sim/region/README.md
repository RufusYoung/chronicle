# Region System

## 职责

管理比地点更大的地区状态和长期压力。

## 管理的数据

粮食压力、治安、商路、疾病、战争压力、物价、人心、天气倾向、势力控制和传闻密度。

## 输入

经济系统、世界推进、地点事件、商队流动、战争、疾病和玩家行动。

## 输出

地点初始状态、行动候选条件、传闻传播、长期项目背景和世界纪事素材。

## 不负责什么

不负责保存单个地点内部对象，不负责人物关系，不负责具体交易事务。

## 与其他系统的关系

Economy 调整地区压力，Location 读取地区状态，World Tick 推动地区趋势。

## 当前状态

骨架阶段，暂未实现正式逻辑。
