# Relationship System

## 职责

管理实体之间的长期关系和短期态度。

## 管理的数据

信任、恐惧、感激、怨恨、债务、熟悉、亲近、羞愧、利用意图、误解、忠诚、服从和竞争。

## 输入

共同经历、行动事务、事实、记忆、组织关系、血缘、职业关系、帮助和背叛。

## 输出

NPC 行为倾向、行动候选条件、传闻传播倾向、长期项目节点、叙事素材和纪事权重。

## 不负责什么

不负责保存客观事实，不负责生成地点文本，不负责替代制度规则。

## 与其他系统的关系

Transaction 写入关系变化，Memory 记录主观记忆，Action 读取关系条件。

## 当前状态

骨架阶段，暂未实现正式逻辑。
