# Trait / Tag System

## 职责

提供可复用的特质、标签和语义匹配入口。

## 管理的数据

人物特质、对象标签、地点标签、规则标签、材料标签、纪事权重标签。

## 输入

Raw Definition、行动结果、阶段结算、身份系统、装备历史和地点原型。

## 输出

规则匹配条件、叙事修饰、行动候选、传闻传播条件和纪事筛选权重。

## 不负责什么

不负责把标签写成剧情，不负责替代具体系统的状态数据。

## 与其他系统的关系

Action、Narrative、Rumor、Chronicle 和 Raw / Rule 层都会读取标签。

## 当前状态

骨架阶段，暂未实现正式逻辑。
