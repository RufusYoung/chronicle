# Equipment System

## 职责

管理装备作为工具、身份象征和历史物件的三重性质。

## 管理的数据

装备类型、材质、基础数值、耐久、契合度、词条、历史、修理记录、杀敌记录、所有者和传承状态。

## 输入

Item / Material System、战斗事务、修理事务、赠送事务、长期项目、传闻和遗产系统。

## 输出

战斗修正、身份识别、传闻素材、纪事素材、遗产物和赝品条件。

## 不负责什么

不负责普通物品通用逻辑，不负责战斗公式，不负责最终传记文本。

## 与其他系统的关系

Item 提供材料基础，Fact 记录装备历史，Chronicle 读取高权重装备事实。

## 当前状态

骨架阶段，暂未实现正式逻辑。
