# 2026-06-15.8 指令：建立湖湾镇开发者可视化世界面板

## 一、任务目标

上一阶段已经完成 `LocalStoryModule` 抽象，湖湾镇已被包装为 `lake_town_food_crisis_module`。

当前湖湾镇模块已经具备：

```text
食物危机因果链
微观行动解析
后续反应
恢复与关系回声
多 seed 历史差异
替代路径闭合
极端饥饿二级闭合
历史质量审计
LocalStoryModule 接口
RegionSimProfile
LocalStoryPipeline
```

但目前这些结果主要存在于 Markdown 输出和无头测试中。用户很难直观看见：

```text
某个 seed 为什么形成这个历史
某一天发生了哪些事实
陈米、老陈、玛婶、刘账房状态如何变化
Trace / Memory / NarratableState 如何累积
质量审计是否发现问题
```

本任务目标是建立第一个 Godot 内部开发者可视化世界面板：

```text
LakeTownWorldViewer
```

它不是正式玩家 UI。

它不接入当前 Demo。

它不修改 `story_player.gd`。

它不修改 `world_generation_v03.gd`。

它只读取 `LocalStoryModule / LocalStoryPipeline` 的无头模拟结果，并以可视化面板方式展示湖湾镇自运行世界。

---

## 二、任务边界

本任务只做开发者可视化面板、ViewModel、无头数据测试和报告。

不要接正式 UI。

不要改变当前 Demo 行为。

不要修改 `story_player.gd`。

不要修改 `world_generation_v03.gd`。

不要修改 `mainui.tscn`。

不要新增第二地点。

不要扩写事件池。

不要让 UI 生成 WorldFact。

不要让 UI 修改世界状态。

UI 只能：

```text
运行本地无头模拟
读取结果
展示 seed
展示时间线
展示 NPC / 地点状态
展示 WorldFact / Trace / Memory / NarratableState
展示质量审计
```

UI 不允许：

```text
决定事实
决定结局
直接写入 state
绕过 module.resolve_action()
```

## 六、界面目标

新增开发者场景：

```text
scenes/dev/lake_town_world_viewer.tscn
```

推荐布局：

```text
左侧：Seed 列表
中间：历史时间线
右侧：当前选中日详情
底部：状态 / 事实 / 痕迹 / 记忆 / 质量审计分页
```

第一版不追求美术。

第一版要求清楚、能看、能调试。

### 左侧 Seed 列表

显示 20 个 seed：

```text
2026061501
2026061502
...
2026061520
```

每个 seed 显示：

```text
outcome_class
quality_flags 数量
是否 bad_hunger_outcome
是否有取粮
是否有守卫封仓
是否有空粮仓
```

示例：

```text
2026061501 | guard_locked_guard_attention | OK
2026061502 | guard_locked_guard_attention | bad_hunger_outcome
2026061503 | forced_shop_closure_no_theft | OK
```

点击 seed 后，中间时间线和右侧详情刷新。

---

### 中间历史时间线

展示该 seed 30 天内的关键事实。

每一行：

```text
Day N | fact_type | 简短说明
```

例如：

```text
Day 1 | lake_town_food_price_rising | 粮价上涨
Day 3 | guard_locked_abandoned_granary | 守卫封锁废弃粮仓
Day 11 | chen_mi_blocked_by_guard_seal | 陈米被封条挡回
Day 12 | old_chen_sold_shop_goods_for_food | 老陈卖掉店内物品换食物
Day 13 | chen_mi_collapsed_from_hunger | 陈米倒在店门口
```

要求：

* 按日期排序。
* 可点击某一日。
* 点击某一日后右侧显示该日详情。
* 不要展示所有无关宏观事实，优先展示湖湾镇相关 facts。
* 可保留“显示全部 facts”的开关，但第一版不强制。

---

### 右侧当前日期详情

显示：

```text
当前 day
该日新增 WorldFact
该日新增 Trace
该日新增 Memory
该日新增 NarratableState
当前 NPC 状态
当前地点状态
当前质量标记
```

NPC 至少包括：

```text
old_chen
chen_mi
ma_shen
liu_zhangfang
```

NPC 状态显示字段：

```text
hunger
fear
health
stress
debt
family_food
location_id
status_tags
```

不存在的字段显示 `-`，不要报错。

地点至少包括：

```text
old_chen_shop
abandoned_granary
lake_town_market
ma_shen_home_temp
```

地点状态显示：

```text
is_open
partial_open
food_stock
spoiled_grain_stock
status_tags
traces
```

---

### 底部分页

底部使用 TabContainer 或等价控件。

分页：

```text
WorldFact
Trace
Memory
NarratableState
QualityAudit
Profile
Raw Signature
```

每页只读展示。

#### WorldFact 页

显示该 seed 全部湖湾镇事实：

```text
fact_id
day
type
actors
location_id
cause_fact_ids
```

#### Trace 页

显示：

```text
trace_id
type
location_id
source_fact_id
```

#### Memory 页

显示：

```text
memory_id
owner_id
source_fact_id
tags
```

#### NarratableState 页

显示：

```text
narratable_state_id
title / label
source_fact_ids
trace_ids
status
```

#### QualityAudit 页

显示：

```text
quality_flags
dangling_major_fact
impossible_shop_state
unresolved_extreme_hunger
bad_hunger_outcome
branch_closure_depth
consequence_depth
```

#### Profile 页

显示该 seed 的 RegionSimProfile 或 seed profile 摘要。

#### Raw Signature 页

显示 HistorySignature 的 JSON 或格式化字典。

## 七、ViewModel 要求

新增：

```text
scripts/dev/lake_town_world_view_model.gd
```

ViewModel 负责把 LocalStoryModule 批量运行结果整理为 UI 可读结构。

建议接口：

```gdscript
func build_view_data(seeds: Array, days: int = 30) -> Dictionary

func build_seed_summary(run_result: Dictionary) -> Dictionary

func build_timeline(run_result: Dictionary) -> Array

func build_day_detail(run_result: Dictionary, day: int) -> Dictionary

func build_npc_snapshot(run_result: Dictionary, day: int) -> Dictionary

func build_location_snapshot(run_result: Dictionary, day: int) -> Dictionary

func build_fact_rows(run_result: Dictionary) -> Array

func build_trace_rows(run_result: Dictionary) -> Array

func build_memory_rows(run_result: Dictionary) -> Array

func build_narratable_rows(run_result: Dictionary) -> Array

func build_quality_summary(run_result: Dictionary) -> Dictionary
```

要求：

* ViewModel 可以调用 `LocalStoryPipeline`。
* ViewModel 不直接生成 WorldFact。
* ViewModel 不直接修改 state。
* ViewModel 输出必须是纯 Dictionary / Array，方便测试。
* UI 场景只消费 ViewModel 输出。
