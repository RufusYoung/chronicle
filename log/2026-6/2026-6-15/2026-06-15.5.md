# 2026-06-15.5 指令：湖湾镇替代路径闭合与历史质量校准

## 一、任务目标

上一阶段已经完成湖湾镇多 seed 历史差异验证。

当前结果证明：

```text
20 个 seed 均可运行 30 天。
唯一历史签名达到 20 个。
出现 5 种 outcome_class。
陈米取粮不是固定发生，也不是固定不发生。
同 seed 可复现，不同 seed 有差异。
```

但观察输出暴露出新的问题：

```text
历史已经分叉，
但部分分叉没有后续闭合。
```

典型问题包括：

```text
守卫封锁粮仓后，陈米不能取粮，但后续饥饿仍涨到 100。
陈米忍耐饥饿后，没有足够后续生理或社会反应。
空粮仓路径出现后，陈米返回空手，但后续缺少替代求助、崩溃或迁移。
老陈 stress/debt 达到 100，但店铺仍可能保持 open=true。
mixed_or_unclassified 说明部分历史没有被清楚分类。
guard_locked_granary 占比偏高，且后续常显得悬空。
```

本任务目标是让替代路径也能继续生活化演化：

```text
不是只有“陈米取粮 → 生病 → 玛婶送粥”这一条路径有后续。
守卫封仓、空粮仓、忍耐饥饿、提前催债、其他家庭先取粮，也都必须有后续反应。
```

本任务不是增加 UI。

本任务不是扩写新剧情。

本任务不是随机事件池。

本任务是给已出现的历史分叉补上后续因果与质量检查。

## 五、核心原则

### 1. 历史分叉必须有后续

错误：

```text
守卫封锁粮仓
↓
陈米不能取粮
↓
后面什么都不发生
↓
陈米 hunger=100
```

正确：

```text
守卫封锁粮仓
↓
陈米不能取粮
↓
陈米返回空手 / 守卫注意到孩子 / 玛婶听见传闻 / 老陈尝试赊账 / 陈米忍耐饥饿
↓
新的 WorldFact、Trace、Memory 出现
```

### 2. 数值极端必须推动状态变化

错误：

```text
old_chen.stress = 100
old_chen.debt = 100
old_chen_shop.is_open = true
没有任何异常状态
```

正确：

```text
压力和债务达到极端
↓
店铺强制进入 abnormal 状态：
closed / partial_open / debt_seized / unattended / actor_access_blocked
↓
生成 WorldFact 和 Trace
```

### 3. mixed_or_unclassified 不是失败，但不能成为垃圾桶

允许少量 mixed。

但 mixed 必须代表：

```text
多条路径交织，尚未归类。
```

不能代表：

```text
系统不知道发生了什么。
```

## 九、历史质量审计器

新增：

```text
chronicle-godot/scripts/dev/lake_town_history_quality_auditor.gd
```

接口建议：

```gdscript
func audit_history_signature(signature: Dictionary) -> Dictionary

func audit_state(state: Variant) -> Dictionary

func audit_batch(signatures: Array, states: Array = []) -> Dictionary

func build_quality_report(batch_result: Dictionary) -> String
```

质量审计至少检查：

```text
1. dangling_major_fact：重大替代路径是否没有后续。
2. impossible_shop_state：stress/debt 极端但 shop_open 仍 true 且无恢复事实。
3. unresolved_extreme_hunger：chen_mi.hunger >= 95 持续多日但无后续事实。
4. unclassified_without_reason：mixed_or_unclassified 是否缺乏解释。
5. branch_closure_depth：每个 seed 的替代路径后续事实数量。
6. contradiction_flags：同一状态是否同时 closed 与 open 且无 partial 解释。
7. consequence_depth：主要路径后续 WorldFact 数量。
```

输出示例：

```gdscript
{
    "seed": 2026061501,
    "quality_flags": ["guard_locked_without_child_followup"],
    "branch_closure_depth": 0,
    "impossible_shop_state": true,
    "notes": [...]
}
```
