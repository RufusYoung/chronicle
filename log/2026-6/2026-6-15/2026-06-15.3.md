# 2026-06-15.3 指令：建立湖湾镇微观恢复与关系回声系统

## 一、任务目标

上一阶段已经完成湖湾镇微观后续反应系统。

当前无外部模拟行动时，湖湾镇已经能够从：

```text
陈米取走发霉麦子
↓
老陈闭店
↓
陈米吃发霉麦子
↓
陈米生病
↓
玛婶注意闭店
↓
玛婶送粥
↓
刘账房催债
```

继续向后演化。

但目前系统仍偏向“恶化链”：

```text
饥饿
偷粮
生病
闭店
催债
恐惧上升
压力上升
```

本任务建立“恢复与关系回声”系统，让帮助、伤害、忽略、举报、低价收购等行为不仅产生即时后果，也能影响后续生活、关系态度、行动候选和可叙述状态。

本任务要验证：

```text
世界不只是会恶化。
世界也会恢复、记住、感恩、记仇、疏远、重新开门。
```

目标链条：

```text
外部模拟行动 / 后续反应
↓
Memory 与 RelationshipState 改变
↓
NPC 后续态度改变
↓
地点状态变化
↓
新的 WorldFact / Trace / NarratableState 出现
↓
后续行动候选受关系影响
```

## 五、核心原则

### 1. 恢复不是奖励结算

错误：

```text
给食物 → 好感 +10 → 任务完成
```

正确：

```text
给食物
↓
陈米当天没有吃发霉麦子
↓
陈米记住测试 actor 给过食物
↓
老陈压力下降但债务还在
↓
玛婶听说有人帮过老陈家
↓
老陈之后可能半开店
↓
陈米以后看见同一个 actor 会先停一下
↓
行动候选发生变化
```

### 2. 坏选择也要有回声

错误：

```text
举报她 → 关系 -10 → 结束
```

正确：

```text
举报她
↓
守卫来店门口盘问
↓
陈米恐惧升高
↓
老陈把测试 actor 视为危险来源
↓
玛婶听见传闻后疏远
↓
后续“询问”“求助”“买东西”等候选受限
```

### 3. 关系不是单一好感度

本任务要建立可扩展的微观关系结构。

最少包括：

```text
trust
fear
gratitude
resentment
debt
familiarity
last_interaction_day
tags
```

关系变化必须来自具体事实或记忆，不能凭空改变。

## 十、必做恢复与关系回声规则

### 1. 陈米因食物帮助短期恢复

ID：

```text

```

触发条件：

```text
actor_gave_food_to_chen_mi 事实存在
chen_mi.hunger < 60
chen_mi 没有吃过 spoiled_grain
```

结算：

```text
chen_mi_recovery_level 上升
chen_mi.status_tags += stabilized_by_actor_help

WorldFact += chen_mi_stabilized_after_food_help

Relationship: chen_mi -> test_actor trust/gratitude 上升
NarratableState += chen_mi_remembers_help_scene
```

### 2. 老陈因帮助短期缓和

ID：

```text
old_chen_softened_after_actor_help
```

触发条件：

```text
actor_gave_food_to_chen_mi 事实存在
old_chen.stress < 90 或 trust_to_actor > 0
chen_mi 没有立刻恶化
```

结算：

```text
old_chen_recovery_level 上升
old_chen.stress 下降
old_chen.status_tags += actor_help_acknowledged
WorldFact += old_chen_softened_after_actor_help
Memory += old_chen_remembers_actor_helped_chen_mi
Trace += shop_door_unlatched_for_actor 或 old_chen_kept_actor_food_wrap
Relationship: old_chen -> test_actor trust/gratitude 上升
```

### 3. 老陈半开店铺

ID：

```text
old_chen_reopened_shop_half_day
```

触发条件：

```text

old_chen_recovery_level >= 阈值
family_food > 0 或 ma_shen_brought_porridge 已发生
old_chen.stress < 95
```

结算：

```text
old_chen_shop.state.is_open = true 或 state.partial_open = true

WorldFact += old_chen_reopened_shop_half_day

Trace += limited_goods_on_shelf
NarratableState += half_open_old_chen_shop_scene
```

注意：半开店不等于危机彻底解决。

```text

```

触发条件：

```text
ma_shen_brought_porridge 已发生
ma_shen.concern 高
chen_mi.health 或 hunger 仍未完全恢复
```

```text
WorldFact += ma_shen_kept_checking_on_chen_mi
Trace += neighbor_visit_marks
Memory += chen_mi_remembers_ma_shen_checking
Relationship: ma_shen -> old_chen trust/familiarity 上升
```

## 十一、行动候选受关系影响

更新 `micro_action_resolver.gd`。

行动候选不仅受物品和 Trace 影响，也受关系影响。

### 1. 正向关系影响

当满足：

```text
chen_mi -> test_actor trust 或 gratitude 高
```

可以新增候选：

```text
comfort_chen_mi
```

显示条件：

```text
chen_mi_trust_echo_for_actor 已发生
chen_mi fear > 20
```

结算：

```text
chen_mi.fear 下降
Memory += chen_mi_remembers_being_comforted
WorldFact += actor_comforted_chen_mi
Trace += quiet_talk_at_shop_step
```

### 2. 负向关系影响

当满足：

```text
chen_mi_avoidance_echo_for_actor 已发生
```

以下候选应被隐藏或不可执行：

```text
ask_grain_origin
comfort_chen_mi
```

`can_resolve_action()` 返回 false，并给出错误：

```text
relationship_blocked
```

### 3. 老陈负向关系影响

当满足：

```text
old_chen_closes_door_to_actor 已发生
```

涉及老陈合作的候选应被限制。

例如后续如果存在：

```text
ask_old_chen_about_debt
offer_debt_help
buy_from_old_chen_shop
```

本阶段不要求实现全部，只要求为关系拦截预留结构和测试一个最小样例。

```text
低价收购分支：

- 陈米饥饿风险维持
```
