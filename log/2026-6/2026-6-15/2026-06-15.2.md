# 2026-06-15.2 指令：建立湖湾镇微观后续反应系统

## 一、任务目标

上一阶段已经完成：

```text
NarratableState：陈米藏着一袋发霉麦子
↓
ActionCandidate：给食物、询问来源、举报、忽略、低价收购
↓
MicroActionResolver：五类无头模拟行动均可写回 WorldFact、Trace、Memory 和世界状态
```

但当前观察输出仍暴露出一个问题：

```text
Day 6 生成“陈米藏着一袋发霉麦子”后，
Day 7 之后湖湾镇多数天显示“无新增事实、痕迹或可叙述状态”。
老陈压力、债务、陈米饥饿、恐惧继续升高，
但世界没有继续自发反应。
```

本任务建立湖湾镇微观后续反应系统，让已有微观场景继续推动生活变化：

```text
陈米拿到发霉麦子
↓
如果没人处理，她可能吃掉、藏起来、生病、被老陈发现
↓
老陈可能求助、赊账、卖掉店里东西、被债主盯上
↓
邻居可能察觉、议论、施舍或远离
↓
店铺可能长期关闭、半开门、贴出新告示
↓
新的 WorldFact、Trace、Memory、NarratableState 出现
```

本任务不是新闻润色。

本任务不是扩写事件池。

本任务不是正式 UI 接入。

本任务要让湖湾镇在没有外部模拟行动时，也能继续发生具体生活反应。

## 五、核心原则

### 1. 反应不是事件池

错误：

```text
每天随机抽一个“邻居发现”“陈米生病”“债主上门”事件。
```

正确：

```text
陈米持有 spoiled_grain
chen_mi.hunger 持续高位
chen_mi.disease_risk 存在
old_chen_shop 连续关闭多日
old_chen.debt 持续上升
邻居可见 closed_shop / price_notice / child_hiding_bag 等 Trace
于是按状态阈值产生后续反应
```

### 2. Day 6 后不能只有数值继续上涨

当前观察输出中，Day 6 后湖湾镇经常只是：

```text
old_chen.stress 上升
old_chen.debt 上升
chen_mi.hunger 上升
chen_mi.fear 上升
湖湾镇微观链：无新增事实、痕迹或可叙述状态
```

本任务要改变这一点。

Day 6 之后至少应出现：

```text
陈米处理发霉麦子
老陈发现或没有发现
邻居注意到店铺异常
债务压力留下可见痕迹
食物短缺造成新的求助或冲突
```

### 3. 外部模拟行动要影响后续

上一阶段五类行动已经能写回状态：

```text
give_food_to_chen_mi
ask_grain_origin
report_to_guard
ignore_chen_mi
buy_spoiled_grain_low
```

本任务要让这些行动进入后续反应：

```text
给食物后：陈米短期不会吃发霉麦子，信任记忆保留。
询问后：废弃粮仓线索更容易暴露。
举报后：守卫可能来店门口盘问。
忽略后：陈米可能继续挨饿或吃发霉麦子。
低价收购后：陈米失去粮袋，饥饿风险更高。
```

## 七、微观后续反应状态结构

在 `WorldSimState.micro_state` 下新增或维护：

```gdscript
{
    "reaction_history": Array,
    "scene_followup": Dictionary,
    "closed_shop_days": int,
    "unresolved_scene_days": int,
    "neighbor_attention": float,
    "debt_pressure": float,
    "health_pressure": float,
    "rumor_pressure": float
}
```

建议 `scene_followup` 包含：

```gdscript
{
    "chen_mi_scene_started_day": int,
    "chen_mi_scene_resolved": bool,
    "last_reaction_day": int,
    "chen_mi_ate_spoiled_grain": bool,
    "old_chen_discovered_grain": bool,
    "neighbor_noticed_closed_shop": bool,
    "creditor_visited": bool,
    "ma_shen_helped": bool,
    "guard_checked_shop": bool
}
```

每条反应都必须有唯一 key，避免每天重复生成同一条反应。

示例：

```text
reaction_key = "chen_mi_ate_spoiled_grain"
reaction_key = "old_chen_discovered_spoiled_grain"
reaction_key = "ma_shen_brought_porridge"
reaction_key = "creditor_left_debt_notice"
```

## 九、后续反应规则

在 `lake_town_reaction_system.gd` 中实现每日反应推进。

建议接口：

```gdscript
func tick_reactions(state: Variant) -> Array

func build_reaction_candidates(state: Variant) -> Array

func apply_reaction(state: Variant, reaction_id: String) -> Dictionary

func has_reaction_happened(state: Variant, reaction_key: String) -> bool

func record_reaction(state: Variant, reaction_key: String, fact_id: String) -> void
```

`tick_reactions()` 在每日宏观 tick、湖湾镇粮食链 tick、新闻摘要之后或之前都可以，但报告中必须写清楚顺序。

推荐顺序：

```text
1. world_sim 宏观 tick
2. lake_town_food_chain tick
3. micro_action_resolver 只在外部模拟行动调用时运行
4. lake_town_reaction_system tick
5. news digest / observer 读取结果
```

如果为避免牵动现有新闻断言，也可以让 reaction facts 使用：

```text
scope = "micro"
```

并不进入宏观新闻计数。

## 十、必做反应类型

### 1. 陈米吃掉一部分发霉麦子

ID：

```text
chen_mi_ate_spoiled_grain
```

触发条件：

```text
chen_mi.inventory contains spoiled_grain
chen_mi.hunger >= 85
scene unresolved
没有收到 give_food_to_chen_mi 的 Memory
没有 buy_spoiled_grain_low 导致麦子被拿走
```

结算：

```text
chen_mi.hunger 下降 15~25
chen_mi.health 下降
chen_mi.fear 轻微下降或不变
chen_mi.status_tags += ate_spoiled_grain
WorldFact += chen_mi_ate_spoiled_grain
Memory += chen_mi_remembers_eating_spoiled_grain
Trace += spoiled_grain_crumbs
Trace += sick_child_cough 或 stomach_pain_sign
```

如果 `disease_risk` 高，则后续可能触发：

```text
chen_mi_fell_sick_from_spoiled_grain
```

### 2. 陈米因发霉麦子身体变差

ID：

```text
chen_mi_fell_sick_from_spoiled_grain
```

触发条件：

```text
chen_mi 已吃过 spoiled_grain
chen_mi.health <= 80 或 disease_risk 存在
至少间隔 1 天
```

结算：

```text
chen_mi.health 下降
chen_mi.status_tags += sick_from_spoiled_grain
old_chen.stress 上升
WorldFact += chen_mi_fell_sick_from_spoiled_grain
Trace += sick_child_at_shop_door
Memory += old_chen_remembers_chen_mi_sick
NarratableState += sick_child_after_spoiled_grain_scene
```

### 3. 老陈发现发霉麦子

ID：

```text
old_chen_discovered_spoiled_grain
```

触发条件：

```text
trace_child_hiding_bag 存在
trace_spoiled_grain_bag 存在
old_chen_shop closed
old_chen.stress >= 80
scene unresolved 或 陈米未得到有效帮助
```

结算：

```text
old_chen.memories += old_chen_found_spoiled_grain
old_chen.stress 上升或短期下降，视实现决定
chen_mi.fear 上升
WorldFact += old_chen_discovered_spoiled_grain
Trace += old_chen_hidden_grain_bag 或 overturned_grain_bag
NarratableState += old_chen_found_spoiled_grain_scene
```

当前 MVP 不要求复杂父女对话，只要求事实与痕迹成立。

### 4. 玛婶注意到店铺异常

ID：

```text
ma_shen_noticed_closed_shop
```

触发条件：

```text
old_chen_shop.is_open == false
closed_shop_days >= 2
trace_closed_shop 存在
ma_shen.concern >= 阈值 或 old_chen 家庭危机存在
```

结算：

```text
ma_shen.concern 上升
ma_shen.memories += noticed_old_chen_shop_closed
WorldFact += ma_shen_noticed_closed_shop
Trace += neighbor_footprints_at_shop
Trace += whispered_market_rumor
rumor_pressure 上升
```

### 5. 玛婶送来一碗粥

ID：

```text
ma_shen_brought_porridge
```

触发条件：

```text
ma_shen_noticed_closed_shop 已发生
ma_shen.food_spare > 0
chen_mi.hunger >= 85 或 chen_mi sick
ma_shen.trust_to_old_chen >= 阈值
```

结算：

```text
ma_shen.food_spare 下降
chen_mi.hunger 下降
old_chen.stress 下降
micro_relationships.ma_shen_to_old_chen 或 old_chen_to_ma_shen trust 上升
WorldFact += ma_shen_brought_porridge
Trace += empty_porridge_bowl_at_door
Memory += chen_mi_remembers_ma_shen_porridge
NarratableState 可选：neighbor_helped_during_food_crisis_scene
```

### 6. 刘账房留下催债告示

ID：

```text
creditor_left_debt_notice
```

触发条件：

```text
old_chen.debt >= 70
old_chen_shop closed
closed_shop_days >= 3
liu_zhangfang.patience 下降到阈值
```

结算：

```text
liu_zhangfang.debt_claim 上升
old_chen.stress 上升
WorldFact += creditor_left_debt_notice
Trace += debt_notice_on_shop_door
Memory += old_chen_remembers_debt_notice
NarratableState += debt_notice_at_closed_shop_scene
```

### 7. 守卫来店门口盘问

ID：

```text
guard_checked_old_chen_shop
```

触发条件：

```text
actor_reported_chen_mi_to_guard 事实存在
guard_attention_at_old_chen_shop Trace 存在
至少间隔 1 天
```

结算：

```text
wardens 或 guard_attention 上升
chen_mi.fear 上升
old_chen.stress 上升
WorldFact += guard_checked_old_chen_shop
Trace += guard_boot_marks_at_shop
Memory += chen_mi_remembers_guard_visit
NarratableState += guard_visit_after_report_scene
```

该反应只在举报行动分支或测试注入分支中出现，基线不应凭空出现。
