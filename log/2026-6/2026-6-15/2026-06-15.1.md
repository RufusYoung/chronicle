# 2026-06-15.1 指令：建立湖湾镇微观行动解析与后果写回

## 一、任务目标

上一阶段已经建立湖湾镇粮食危机最小因果链：

```text
宏观粮食压力
↓
粮价上涨
↓
老陈家庭压力上升
↓
陈米饥饿上升
↓
陈米取走发霉麦子
↓
老陈关店
↓
Trace 生成
↓
NarratableState：陈米藏着一袋发霉麦子
```

本任务建立下一段闭环：

```text
NarratableState
↓
根据世界状态生成可行动选项
↓
外部模拟行动选择其中一项
↓
行动写回 NPC、地点、物品、关系、记忆、WorldFact、Trace
↓
观察输出展示不同后果
```

本任务不是接 UI。

本任务不是写剧情选项文本。

本任务不是事件池。

本任务要验证：玩家在这个局面下“逻辑上能做什么”，以及每种行动如何改变世界。

---

## 二、任务边界

本任务只做无头模拟和测试。

不要修改当前 Demo 行为。

不要接正式 UI。

不要修改 `story_player.gd`。

不要修改 `world_generation_v03.gd`。

不要修改 `mainui.tscn`。

不要写随机事件池。

不要让行动只输出文本。

所有行动必须写回世界状态。

## 五、核心原则

### 1. 选项来自可行动性，不来自固定按钮模板

错误：

```text
固定生成：帮助 / 举报 / 无视
```

正确：

```text
测试 actor 有食物 → 可以给食物
测试 actor 有钱 → 可以买下麦子
测试 actor 看见 child_hiding_bag Trace → 可以追问粮从哪来
地区有守卫系统 → 可以举报
测试 actor 可以离开 → 可以装作没看见
```

### 2. 行动必须写回状态

错误：

```text
你帮助了她。
```

正确：

```text
actor.inventory.food -= 1
chen_mi.hunger -= 35
chen_mi.fear -= 10
chen_mi.memories += actor_gave_food
old_chen.stress -= 8
WorldFact += actor_gave_food_to_chen_mi
Trace += chen_mi_empty_food_wrap
NarratableState 状态更新或关闭
```

### 3. 测试中的行动叫“外部模拟行动”

本阶段没有真实 UI 输入。

测试脚本中调用行动解析器时，必须称为：

```text
外部模拟行动
模拟行动
无头测试行动
测试 actor 的行动
```

不得称为：

```text
玩家选择
玩家行为
真实玩家输入
玩家干预
```

除非后续真的从 UI 调用。

## 七、ActionCandidate 结构

为可叙述状态生成行动候选。

最少字段：

```gdscript
{
    "id": String,
    "label": String,
    "source_narratable_state_id": String,
    "actor_id": String,
    "target_ids": Array,
    "required_state": Dictionary,
    "visible_if": Dictionary,
    "risk": float,
    "outcome_preview": String,
    "world_cause": String,
    "source_fact_ids": Array,
    "trace_ids": Array,
    "origin": "micro_world"
}
```

注意：

* `label` 可以是中文短文本。
* `outcome_preview` 是调试说明，不是正式 UI 文案。
* `source_fact_ids` 和 `trace_ids` 必须来自 NarratableState。
* 不允许生成没有来源状态的行动。
* 不允许生成无法解释来源的行动。

## 八、针对“陈米藏着一袋发霉麦子”的最小行动集合

当 `chen_mi_hiding_spoiled_grain_scene` 存在时，至少生成以下行动候选。

---

### 1. 给她食物

ID：

```text
give_food_to_chen_mi
```

显示条件：

```text
测试 actor inventory.food > 0
chen_mi.hunger >= 50
```

结算：

```text
actor.inventory.food -= 1
chen_mi.hunger 下降
chen_mi.fear 下降
chen_mi.status_tags += helped_by_actor
old_chen.stress 下降
micro_relationships.actor_to_chen_mi.trust 上升
micro_relationships.actor_to_old_chen.trust 上升
WorldFact += actor_gave_food_to_chen_mi
Memory += chen_mi_remembers_actor_gave_food
Trace += chen_mi_empty_food_wrap
```

---

### 2. 问粮从哪来的

ID：

```text
ask_grain_origin
```

显示条件：

```text
child_hiding_bag Trace 存在
spoiled_grain_bag Trace 存在
```

结算：

```text
WorldFact += actor_asked_chen_mi_about_grain
Memory += chen_mi_was_asked_about_grain
chen_mi.fear 小幅变化
Trace 或 clue += granary_hint
```

当前 MVP 可以固定为温和询问，不做复杂说服判定。

---

### 3. 举报她

ID：

```text
report_to_guard
```

显示条件：

```text
lake_town 或 border_town 存在守卫/秩序系统
chen_mi_took_spoiled_grain 事实存在
```

结算：

```text
chen_mi.fear 上升
old_chen.stress 上升
micro_relationships.actor_to_chen_mi.trust 下降
micro_relationships.actor_to_old_chen.trust 下降
wardens 或 local_guard 关注度上升
WorldFact += actor_reported_chen_mi_to_guard
Memory += chen_mi_remembers_actor_reported_her
Trace += guard_attention_at_old_chen_shop
```

注意：是否逮捕陈米暂不做。当前只做举报后世界压力变化。

---

### 4. 装作没看见

ID：

```text
ignore_chen_mi
```

显示条件：

```text
无特殊条件
```

结算：

```text
WorldFact += actor_ignored_chen_mi_scene
chen_mi.hunger 不下降
chen_mi.disease_risk 或 health_risk 继续存在
old_chen.stress 不下降
Memory 可选：scene_was_ignored
NarratableState 标记为 seen_but_unresolved 或 ignored_by_actor
```

注意：忽略也必须写 WorldFact，不能什么都不发生。

---

### 5. 趁机低价收购

ID：

```text
buy_spoiled_grain_low
```

显示条件：

```text
actor.money > 0
chen_mi.inventory contains spoiled_grain
```

结算：

```text
actor.money -= low_price
actor.inventory += spoiled_grain
chen_mi.inventory 移除 spoiled_grain
chen_mi.fear 上升
chen_mi.hunger 可能小幅下降或不变，取决于是否给钱
old_chen.stress 上升
micro_relationships.actor_to_chen_mi.trust 下降
WorldFact += actor_bought_spoiled_grain_low
Memory += chen_mi_remembers_actor_took_grain
Trace += missing_spoiled_grain_bag
```

该行动允许存在。Chronicle 不强制玩家善良。

## 九、MicroActionResolver 接口

在 `micro_action_resolver.gd` 中实现：

```gdscript
func build_action_candidates(state: Variant, actor_state: Dictionary, narratable_state_id: String) -> Array

func resolve_micro_action(
    state: Variant,
    actor_state: Dictionary,
    action_id: String,
    narratable_state_id: String
) -> Dictionary

func can_resolve_action(
    state: Variant,
    actor_state: Dictionary,
    action_id: String,
    narratable_state_id: String
) -> bool

func build_action_result_summary(before_state: Variant, after_state: Variant, result: Dictionary) -> Dictionary
```

`resolve_micro_action()` 返回最少包含：

```gdscript
{
    "ok": bool,
    "action_id": String,
    "created_fact_ids": Array,
    "created_trace_ids": Array,
    "created_memory_ids": Array,
    "state_changes": Dictionary,
    "error": String
}
```

如果前置条件不足：

```gdscript
{
    "ok": false,
    "error": "missing_required_state"
}
```

不得静默失败。

不得只输出文本。
