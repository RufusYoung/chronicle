# 2026-06-15.6 指令：湖湾镇极端饥饿二级闭合与生存出口校准

## 一、任务目标

上一阶段已经完成湖湾镇替代路径闭合与历史质量校准。

当前结果已经达到：

```text
dangling_major_fact = 0
impossible_shop_state = 0
无理由未分类 = 0
平均 branch_closure_depth = 3.05
```

但仍存在一个明确问题：

```text
20 个 seed 中仍有 3 个 seed 被标记为 unresolved_extreme_hunger。
```

这说明：

```text
店铺、债务、守卫封仓、空粮仓、提前催债等路径已经有闭合，
但孩子侧的“极端饥饿”还没有形成足够清晰的生存出口。
```

本任务目标是建立“极端饥饿二级闭合”：

```text
陈米长期饥饿达到极端
↓
系统不能只让 hunger 停在 100
↓
必须出现生存出口、崩溃后果、邻里介入、临时迁移或健康恶化
↓
并留下 WorldFact / Trace / Memory / NarratableState
```

注意：

本任务不是把所有坏结果改成好结局。

本任务不是强行让陈米获救。

本任务要让极端饥饿不再悬空。

可以出现：

```text
获救
短期缓解
倒下
被邻居发现
被老陈带走求助
临时离开店铺
健康严重恶化
```

但不能出现：

```text
hunger=100 连续很多天
没有任何新事实
没有任何 Trace
没有任何 Memory
没有任何社会反应
```

## 五、核心原则

### 1. 极端饥饿不能只停留在数值上

错误：

```text
chen_mi.hunger = 100
chen_mi.health = 88
持续 20 天
无事实
无痕迹
无记忆
```

正确：

```text
chen_mi.hunger >= 95
持续或达到危急阈值
↓
触发虚弱、昏倒、求助、邻居介入、临时迁移、紧急赊食或健康恶化
↓
写入 WorldFact / Trace / Memory
```

### 2. 生存出口不是必然好结局

允许：

```text
玛婶送来最后一点粥
老陈卖掉店里最后一件东西
陈米倒在店门口
邻居发现但只留下传闻
老陈带陈米去市场赊食
陈米被临时送到玛婶家
陈米健康恶化
```

不允许：

```text
一律救活
一律恢复
一律幸福结局
```

### 3. 质量审计不只看最终值，也要看连续天数

当前审计器主要看最终状态和事实图。

本任务要增加：

```text
extreme_hunger_days
last_hunger_relief_day
last_hunger_closure_fact_day
```

用于判断“极端饥饿是否被处理过”。

## 九、必做二级闭合规则

### 1. 陈米极端饥饿后倒在店门口

ID：

```text
chen_mi_collapsed_from_hunger
```

触发条件：

```text
chen_mi.hunger >= 98
chen_mi.health <= 85 或 extreme_hunger_days >= 2
没有近期 food help
没有 temporarily_relocated
```

结算：

```text
chen_mi.health 下降
chen_mi.fear 下降或冻结
chen_mi.status_tags += collapsed_from_hunger
hunger_closure_state.chen_mi_collapsed = true
WorldFact += chen_mi_collapsed_from_hunger
Trace += child_collapsed_at_shop_step
Memory += chen_mi_remembers_collapse_blur
NarratableState += collapsed_child_at_shop_step_scene
```

### 2. 玛婶进行紧急送食

ID：

```text
ma_shen_emergency_food_for_chen_mi
```

触发条件：

```text
chen_mi_collapsed_from_hunger 已发生 或 neighbor_noticed_silent_hungry_child 已发生
ma_shen.concern 高
ma_shen.food_spare > 0 或 neighbor_help_level 高
```

结算：

```text
chen_mi.hunger 下降
chen_mi.health 小幅恢复或停止下降
ma_shen.food_spare 下降，若为 neighbor_help_level 支持则 community_support 下降
WorldFact += ma_shen_emergency_food_for_chen_mi
Trace += emergency_food_bowl
Memory += chen_mi_remembers_emergency_food
Relationship ma_shen -> old_chen familiarity/trust 小幅上升
```

### 3. 老陈卖掉店内物品换食物

ID：

```text
old_chen_sold_shop_goods_for_food
```

触发条件：

```text
old_chen.stress >= 90
family_food <= 0
chen_mi.hunger >= 90
old_chen_shop.food_stock <= 0 或 shop_recovery 不足
old_chen_shop 仍有可变卖物品标记或未触发过本闭合
```

结算：

```text
family_food 上升少量
old_chen.debt 可小幅下降或不变
old_chen.stress 小幅下降
old_chen_shop.status_tags += sold_goods_for_food
WorldFact += old_chen_sold_shop_goods_for_food
Trace += missing_shop_goods
Memory += old_chen_remembers_selling_goods_for_food
NarratableState += old_chen_sold_goods_scene
```

注意：这不是恢复店铺，而是牺牲店铺资产换短期食物。

### 4. 老陈带陈米离开店铺求助

ID：

```text
old_chen_took_chen_mi_to_seek_help
```

触发条件：

```text
chen_mi_collapsed_from_hunger 已发生 或 chen_mi.health <= 70
old_chen.stress >= 85
old_chen_shop.is_open == false 或 forced_abnormal_closure 已发生
```

结算：

```text
chen_mi.location_id = lake_town_market 或 ma_shen_home_temp
old_chen.location_id = lake_town_market
hunger_closure_state.chen_mi_temporarily_relocated = true
WorldFact += old_chen_took_chen_mi_to_seek_help
Trace += shop_left_unattended
Memory += old_chen_remembers_carrying_chen_mi_for_help
NarratableState += old_chen_left_shop_to_seek_help_scene
```

### 5. 湖湾镇临时救济赊食

ID：

```text
lake_town_emergency_credit_food
```

触发条件：

```text
old_chen_took_chen_mi_to_seek_help 已发生
lake_town_market.credit_available 高 或 neighbor_help_level 高
old_chen.debt 尚未完全封死救济渠道
```

结算：

```text
family_food 上升
old_chen.debt 上升
chen_mi.hunger 下降
market.credit_available 下降
WorldFact += lake_town_emergency_credit_food
Trace += emergency_credit_mark
Memory += old_chen_remembers_emergency_credit_food
```

注意：救济赊食解决短期饥饿，但制造债务后续压力。

### 6. 陈米健康严重恶化

ID：

```text
chen_mi_health_crashed_from_hunger
```

触发条件：

```text
extreme_hunger_days >= 3
没有 emergency_food
没有 temporary relocation
chen_mi.health <= 75 或持续下降
```

结算：

```text
chen_mi.health 明显下降
chen_mi.status_tags += critical_hunger_health
WorldFact += chen_mi_health_crashed_from_hunger
Trace += feverish_child_breath
Memory += old_chen_remembers_hunger_crash
NarratableState += critical_hunger_child_scene
```

注意：这是坏结果闭合，不是失败。

### 7. 陈米被临时安置到玛婶家

ID：

```text
chen_mi_temporarily_stayed_with_ma_shen
```

触发条件：

```text
ma_shen_emergency_food_for_chen_mi 已发生
ma_shen.concern 高
old_chen_shop forced_abnormal_closure 或 old_chen 无力照看
```

结算：

```text
chen_mi.location_id = ma_shen_home_temp
chen_mi.status_tags += temporarily_staying_with_ma_shen
ma_shen.status_tags += caring_for_chen_mi
WorldFact += chen_mi_temporarily_stayed_with_ma_shen
Trace += small_blanket_at_ma_shen_door
Memory += chen_mi_remembers_staying_with_ma_shen
NarratableState += chen_mi_stays_with_ma_shen_scene
```

### 8. 饥饿问题被结构化标记为未解决但已恶化

ID：

```text
chen_mi_hunger_unresolved_but_recorded
```

触发条件：

```text
extreme_hunger_days >= 3
其他救济、迁移、倒下、健康崩溃都因条件不足未触发
```

结算：

```text
WorldFact += chen_mi_hunger_unresolved_but_recorded
Trace += unchanged_empty_bowl
Memory += system_recorded_unresolved_hunger_pressure
NarratableState += unresolved_hunger_pressure_scene
```

注意：

* 这是兜底闭合。
* 不能频繁出现。
* 它不解决饥饿，但让世界明确记录“没人处理这件事”。
* 审计器不应再把它视作悬空，但可以标记为 bad_outcome。
