# 2026-06-15.4 指令：建立湖湾镇多 seed 历史差异验证

## 一、任务目标

当前湖湾镇已经具备：

```text
粮食危机因果链
微观行动解析
后续反应
恢复与关系回声
```

但仍存在一个核心风险：

```text
如果每次运行都是：
Day 1 粮价上涨
Day 6 陈米取粮
Day 7 陈米吃发霉麦子
Day 8 陈米生病
Day 9 玛婶送粥
Day 12 刘账房催债

那么它虽然不是传统事件池，
但玩家体感仍然会像一条隐藏脚本。
```

本任务建立湖湾镇多 seed 历史差异验证系统。

目标是验证：

```text
同一套世界规则
不同初始条件
不同 NPC 性格权重
不同资源状态
不同外部压力
可以生成不同的湖湾镇历史。
```

本任务不是继续扩写剧情。

本任务不是增加 UI。

本任务不是增加随机事件池。

本任务要让湖湾镇从“固定因果链”变成“可分叉的局部历史生成器”。

---

## 二、任务边界

本任务只做无头模拟、批量 seed 运行、历史签名提取、差异统计、观察输出和测试。

不要接正式 UI。

不要修改当前 Demo 行为。

不要修改 `story_player.gd`。

不要修改 `world_generation_v03.gd`。

不要修改 `mainui.tscn`。

不要新增玩家系统。

不要做战斗、装备、成长、人生模式、纪事系统或 AI 文本。

不要把不同结果写成固定事件列表。

不要写：

```text
seed == X 时触发 A 结局
seed == Y 时触发 B 结局
```

不同历史必须来自：

```text
初始状态差异
NPC 性格权重
资源差异
地点状态差异
宏观压力差异
现有规则推进
```

## 五、核心原则

### 1. 同 seed 可复现，不同 seed 有差异

必须同时满足：

```text
同一 seed 重跑，历史签名完全一致。
不同 seed 批量运行，历史签名出现明显差异。
```

### 2. seed 不直接触发事件

错误：

```gdscript
if seed == 2026061503:
    generate_ma_shen_helped_early()
```

正确：

```text
seed 只影响：
老陈初始债务
家庭粮食
玛婶余粮
刘账房耐心
废弃粮仓库存
陈米胆量
守卫盘查压力
宏观粮食压力起点

然后由规则自然推进出不同历史。
```

### 3. 目标是历史分叉，不是文案变化

无效差异：

```text
Day 6 陈米取粮
只是标题换了说法
```

有效差异：

```text
陈米没有取粮
陈米提前取粮
陈米取粮但没吃
玛婶提前介入
刘账房先催债
老陈赊账成功
粮仓没有粮
守卫提前封锁粮仓
```

## 七、SeedProfile 结构

新增 `lake_town_seed_profile.gd`，用于根据 seed 生成湖湾镇初始差异。

接口建议：

```gdscript
func build_profile(seed_value: int) -> Dictionary
func apply_profile_to_state(state: Variant, profile: Dictionary) -> void
func describe_profile(profile: Dictionary) -> Dictionary
```

`profile` 至少包含：

```gdscript
{
    "seed": int,

    "macro_pressure": {
        "initial_scarcity_bias": float,
        "initial_food_bias": float,
        "guard_pressure_bias": float,
        "market_disruption_bias": float
    },

    "old_chen": {
        "initial_debt": float,
        "initial_money": float,
        "family_food": float,
        "pride": float,
        "help_seeking": float,
        "risk_tolerance": float
    },

    "chen_mi": {
        "initial_hunger": float,
        "fearfulness": float,
        "boldness": float,
        "trust_in_adults": float,
        "sickness_resistance": float
    },

    "ma_shen": {
        "food_spare": float,
        "concern": float,
        "risk_aversion": float,
        "trust_to_old_chen": float
    },

    "liu_zhangfang": {
        "patience": float,
        "debt_claim": float,
        "strictness": float
    },

    "abandoned_granary": {
        "spoiled_grain_stock": int,
        "disease_risk": float,
        "visibility": float,
        "guard_watch": float
    },

    "lake_town_market": {
        "credit_available": float,
        "neighbor_help_level": float,
        "rumor_speed": float
    }
}
```

注意：

* seed profile 只生成初始条件和性格权重。
* profile 不得直接写入某个具体 WorldFact。
* profile 不得直接生成某个剧情结果。
* profile 应写入观察输出，方便解释为什么这次历史不同。

## 八、必须支持的替代路径

为了避免所有 seed 收敛到同一条历史，本任务需要补足若干替代路径。

### 1. 玛婶提前介入

ID：

```text
ma_shen_helped_before_theft
```

触发条件：

```text
ma_shen.concern 高
ma_shen.food_spare > 0
old_chen_shop 连续异常或陈米 hunger 高
chen_mi_took_spoiled_grain 尚未发生
```

结算：

```text
chen_mi.hunger 下降
ma_shen.food_spare 下降
old_chen.stress 小幅下降
WorldFact += ma_shen_helped_before_theft
Trace += porridge_bowl_before_crisis
Memory += chen_mi_remembers_ma_shen_help_before_theft
```

效果：

```text
可能推迟或阻止陈米取粮。
```

### 2. 老陈赊账成功

ID：

```text
old_chen_bought_food_on_credit
```

触发条件：

```text
old_chen.help_seeking 高 或 pride 低
lake_town_market.credit_available 高
old_chen.debt 未达到极端
family_food 低但仍未崩溃
```

结算：

```text
family_food 上升
old_chen.debt 上升
old_chen.stress 小幅上升或下降
WorldFact += old_chen_bought_food_on_credit
Trace += market_credit_mark
Memory += old_chen_remembers_credit_purchase
```

效果：

```text
可能避免或推迟陈米取粮，但增加债务后续压力。
```

### 3. 粮仓无可取粮

ID：

```text
chen_mi_found_empty_granary
```

触发条件：

```text
chen_mi 尝试寻找食物
abandoned_granary.spoiled_grain_stock <= 0
```

结算：

```text
chen_mi.hunger 不下降
chen_mi.fear 上升
WorldFact += chen_mi_found_empty_granary
Trace += empty_granary_shelf
Memory += chen_mi_remembers_empty_granary
NarratableState += chen_mi_returned_empty_handed_scene
```

效果：

```text
替代“陈米取走发霉麦子”。
```

### 4. 守卫提前封锁粮仓

ID：

```text
guard_locked_abandoned_granary
```

触发条件：

```text
guard_pressure 高
granary.visibility 高
scarcity 高
chen_mi_took_spoiled_grain 尚未发生
```

结算：

```text
abandoned_granary.status_tags += locked_by_guard
WorldFact += guard_locked_abandoned_granary
Trace += guard_seal_on_granary
Memory 可选
```

效果：

```text
陈米不能直接取粮，可能转向求助、忍耐或返回空手。
```

### 5. 刘账房提前催债

ID：

```text
creditor_pressed_before_theft
```

触发条件：

```text
old_chen.debt 高
liu_zhangfang.strictness 高
liu_zhangfang.patience 低
chen_mi_took_spoiled_grain 尚未发生
```

结算：

```text
old_chen.stress 上升
old_chen_shop.traces += early_debt_mark
WorldFact += creditor_pressed_before_theft
Trace += early_debt_mark_on_shop
Memory += old_chen_remembers_early_debt_pressure
```

效果：

```text
可能让老陈更早关店、求助或赊账。
```

### 6. 陈米忍耐而非取粮

ID：

```text
chen_mi_endured_hunger
```

触发条件：

```text
chen_mi.hunger 高
chen_mi.fearfulness 高
chen_mi.boldness 低
没有可靠食物来源
```

结算：

```text
chen_mi.health 下降
chen_mi.fear 上升
WorldFact += chen_mi_endured_hunger
Trace += child_waited_on_shop_step
Memory += chen_mi_remembers_enduring_hunger
```

效果：

```text
替代“陈米取粮”或延后取粮。
```

### 7. 另一个饥饿家庭先拿走粮仓麦子

ID：

```text
other_family_took_granary_grain
```

触发条件：

```text
market.neighbor_help_level 低
scarcity 高
abandoned_granary.spoiled_grain_stock > 0
seed profile 标记 other_hungry_family_pressure 高
chen_mi_took_spoiled_grain 尚未发生
```

需要在 profile 中增加：

```gdscript
"other_family_pressure": float
```

结算：

```text
abandoned_granary.spoiled_grain_stock 下降
WorldFact += other_family_took_granary_grain
Trace += unfamiliar_footprints_at_granary
Memory 可选
```

效果：

```text
陈米可能后来发现粮仓少粮或空粮。
```

## 十、历史结局分类

`classify_history_outcome()` 至少支持以下类别：

```text
theft_sickness_debt
theft_helped_recovery
early_neighbor_help_no_theft
credit_purchase_delayed_crisis
empty_granary_no_theft
guard_locked_granary
early_debt_pressure
endured_hunger_no_theft
other_family_took_grain
mixed_or_unclassified
```

不要为了凑类别强行改事实。

分类基于事实组合，而不是 seed 编号。

示例：

```text
chen_mi_took_spoiled_grain 存在
chen_mi_fell_sick_from_spoiled_grain 存在
creditor_left_debt_notice 存在
=> theft_sickness_debt
```

```text
ma_shen_helped_before_theft 存在
chen_mi_took_spoiled_grain 不存在
=> early_neighbor_help_no_theft
```

```gdscript

    outcome = "theft_sickness_debt"
```

```gdscript

    generate_no_theft_story()
```

禁止随机抽取“结局”。

禁止把历史差异做成文案差异。

禁止没有来源事实的替代路径。

禁止 UI 参与历史生成。
