## 0. 设计原则

### 0.1 Tick Adapter 不是 World Tick

禁止：

```text
每天自动推进所有地点
全世界 NPC 自动行动
自动结算所有义务
自动结算所有交换
自动触发所有 pending consequence
自动衰减所有 pressure
```

正确方向：

```text
外部明确输入 tick_event
只处理匹配 trigger_key 的 pending deferred consequence
只在当前测试范围内运行
只产生 TransactionResult
只通过 TransactionWorldWriter 写回
```

---

### 0.2 Tick 也是事务来源

Tick 不能直接改 Store。

正确链路：

```text
WorldTickAdapter
↓
ConsequenceTriggerSystem
↓
TransactionResult
↓
TransactionWorldWriter
↓
Stores
↓
WorldLog
```

禁止：

```gdscript
deferred_consequence_store.mark_triggered(...)
```

写回必须仍然由：

```text
TransactionWorldWriter
```

完成。

---

### 0.3 本次只处理 deferred consequence

本次只处理：

```text
pending deferred consequence
```

本次不处理：

```text
obligation 到期
exchange 到期
pressure 衰减
NPC 自主履约
rumor propagation
```

这些留到后续。

# 检查点 1：新增 WorldTickAdapter

## 1.1 新增目录和脚本

新增：

```text
chronicle-godot/scripts/sim/world_tick/world_tick_adapter.gd
```

职责：

```text
接收一个明确 tick_event。
读取当前 SimSnapshot。
找到匹配 trigger_key 的 pending deferred consequence。
调用 ConsequenceTriggerSystem 产生 TransactionResult。
用 TransactionWorldWriter 写回 stores。
把 tick 结果写入 SimWorldLog。
返回 tick result。
```

---

## 1.2 最小接口

实现：

```text
apply_tick_event(context, stores: Dictionary, tick_event: Dictionary) -> Dictionary
```

tick_event 建议结构：

```gdscript
{
  "tick_event_id": "after_patrol_event",
  "trigger_key": "after_patrol",
  "scope_id": "seventh_outpost",
  "day": 1,
  "label": "巡逻结束"
}
```

返回结构建议：

```gdscript
{
  "success": true,
  "tick_event_id": "after_patrol_event",
  "trigger_key": "after_patrol",
  "triggered_count": 1,
  "results": [],
  "world_log_entries": [],
  "store_summary": {}
}
```

---

## 1.3 stores 输入

`stores` 至少支持：

```text
fact_store
state_store
relationship_store
memory_store
trace_store
rumor_store
pressure_store
obligation_store
exchange_store
deferred_consequence_store
```

如果缺少非必要 store，不崩溃。
但缺少 `deferred_consequence_store` 时，返回失败结果：

```text
success = false
error_reason = "missing_deferred_consequence_store"
```

---

## 1.4 内部流程

`apply_tick_event` 内部流程：

```text
1. 用 SimSnapshotBuilder 从 context + stores 构建 snapshot。
2. 从 tick_event 读取 trigger_key。
3. 调用 ConsequenceTriggerSystem.trigger_deferred_by_key(snapshot, trigger_key)。
4. 对每个 TransactionResult 调用 TransactionWorldWriter.apply_result(result, stores)。
5. 把每个 result 写入 SimWorldLog entry。
6. 返回 tick result。
```

不要直接调用 store 的 mark 函数。

---

## 1.5 WorldLog entry

tick 产生的 WorldLog entry 建议包含：

```text
entry_type: "tick_event"
tick_event_id
trigger_key
source: "WorldTickAdapter"
facts_added
pressure_change_count
deferred_consequence_update_count
narrative_summary
```
