## 任务性质


# 检查点 1：Relationship Axis Metric

## 1.1 新增关系轴定义

新增：

```text
chronicle-godot/data/sim/raw/relationship_defs/relationship_axis_defs.json
```

至少定义以下关系轴：

```text
trust
gratitude
fear
resentment
discipline_respect
familiarity
debt
```

每个关系轴必须包含：

```text
axis_id
display_name
range_min
range_max
default_value
axis_type
description
behavior_effects
tier_thresholds
```

建议定义：

```text
trust: -100 到 100
gratitude: 0 到 100
fear: 0 到 100
resentment: 0 到 100
discipline_respect: -100 到 100
familiarity: 0 到 100
debt: 0 到 100
```

含义：

```text
trust
是否相信对方不会害自己，是否相信对方会守约。
影响：透露秘密、跟随、接受建议、开放私人空间。

gratitude
是否记得对方给过帮助。
影响：回报、替对方说好话、危机时帮忙。

fear
是否觉得对方具有威胁。
影响：回避、服从、隐瞒、撒谎、求助权力者。

resentment
是否怨恨对方。
影响：拒绝帮助、传播负面传闻、报复。

discipline_respect
在制度 / 军纪场景中是否认可对方维护秩序。
影响：上级评价、军事组织信任、军纪相关事件。

familiarity
熟悉程度。
影响：称呼、闲谈、基础对话开放度。

debt
人情债或实际亏欠。
影响：还债、交换、后续请求、被要求回报。
```

---

## 1.2 变化幅度标准

关系变化不再使用 `+1 / -1` 作为主要表达。

统一采用：

```text
轻微影响：±5
明确影响：±10
重要影响：±15
重大影响：±25
救命 / 严重背叛：±40 以上
```

第一版事务数值改为：

### 给陈米食物

```text
chen_mi -> player gratitude +15
chen_mi -> player trust +5
chen_mi -> player fear -5
```

### 报告伊莱

```text
recruit_elai -> player resentment +25
recruit_elai -> player trust -20
captain_ron -> player discipline_respect +15
```

### 替伊莱隐瞒

```text
recruit_elai -> player gratitude +15
recruit_elai -> player trust +15
recruit_elai -> player debt +10
```
