本次完成一个最小 Raw / Rule 原型。

必须证明：

```text
1. 行动不是从 location.actions 手写按钮表读取。
2. 行动由 fixture 中的 active entities / objects / traces / institutions / region pressure 生成。

5. 执行动作后能写入 FactStore。
```

## 3.4 实现 ActionAffordanceSystem

```text

```


```text

```

```text
entity.type == "person"
entity.tags contains "recruit"
entity.states.hunger == "high"
institution.discipline_level == "strict"
location.tags contains "military"
region_state.food_pressure == "high"
```
