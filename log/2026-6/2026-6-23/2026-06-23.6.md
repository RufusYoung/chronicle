
本次目标是先建立通用 effect atoms 和 stores：

```text id="jeylpm"

obligation
exchange
deferred_consequence
deadline
```

然后让三条规则作为第一批使用这些通用结构的样例。

本次不要接 UI。
不要修改 rebuild 原型。
不要实现完整世界 Tick。
不要实现完整传闻传播。
不要实现 AI 文本。
不要实现湖湾镇完整闭环。
不要实现第七哨站长期项目。
不要把世界实体做成 Godot Node。
不要把世界状态写入 Godot 场景树。

## 0. 设计原则

### 0.1 本次不是写三条剧情

禁止：

```text id="8xcb1v"
if rule_id == "trade_watch_duty_for_silence":
    专门写伊莱今晚替玩家站岗
```

正确方向：

```text id="u3io3g"
trade_watch_duty_for_silence
↓
trade_duty_for_silence_effect
↓
exchange_added
obligation_added
deferred_consequence_added
```

也就是说，这条规则只是第一个使用通用 exchange / obligation / deferred_consequence 的样例。

---


---

### 0.3 Store 与 Snapshot

本次新增 stores：

```text id="xmyy7x"

DeferredConsequenceStore
```

本次让 `SimSnapshot` 能读取这些 store。

但本次不实现完整 tick。
不触发 deferred consequence。
不自动结算 deadline。
不判断交换是否完成。

本次只记录这些结构，让世界开始“记住承诺、压力和延后后果”。

# 检查点 1：新增四个 Store

## 1.1 新增 PressureStore

新增：

```text id="rvvskk"
chronicle-godot/scripts/sim/pressure/pressure_store.gd
```

职责：

```text id="ghpl8u"
保存某个地点、组织、地区或领域的压力值与压力来源。
```

最小接口：

```text id="n42gfe"
add_pressure_change(change: Dictionary)
list_pressures() -> Array
list_pressures_by_domain(domain: String) -> Array
list_pressures_by_location(location_id: String) -> Array
get_pressure_value(scope_id: String, pressure_type: String) -> int
```

pressure record 建议结构：

```gdscript id="prkkb6"
{
  "pressure_id": "outpost_discipline_pressure",
  "scope_id": "seventh_outpost",
  "scope_type": "institution",
  "domain": "military_discipline",
  "pressure_type": "discipline_tension",
  "value": 10,
  "source_fact_type": "actor_deferred_issue_until_after_patrol"
}
```

本次只做记录和查询，不实现自动衰减。
