# 2026-06-23.4 指令：Transaction Contract + Legacy Resolver Cleanup

## 任务性质

本次是 v5.1 世界模拟层的 raw rule 事务契约收口任务。

上一轮已经完成：

```text id="rvjx2i"
Raw Action Rule
↓
effect_template_id
↓
ActionCandidate
↓
TransactionResolver
↓
EffectTemplateResolver
↓
TransactionResult
↓
TransactionWorldWriter
```

并通过：

```text id="qjdxpr"

[V5 RAW RULE PROTOTYPE RESULT] PASS
[V5 TRANSACTION STATE MEMORY RESULT] PASS
[V5 RELATIONSHIP TRACE RUMOR NARRATIVE RESULT] PASS
[V5 SIM RUNNER WORLD LOG RESULT] PASS
[V5 SIM SNAPSHOT CANDIDATE CONTEXT RESULT] PASS
[V5 SNAPSHOT TRANSACTION EFFECT TEMPLATE RESULT] PASS
```

但当前还有两个结构问题：

```text id="u4bf6n"
1. TransactionResolver 仍保留 legacy rule_id -> effect_template_id fallback。
2. effect_template_id 为 null 的规则只是“碰巧不写回”，没有明确事务契约。
```

本次目标不是给更多规则补效果模板。
本次目标是让每条 action rule 明确声明自己的事务模式。

最终要形成：

```text id="zgkdi4"
Raw Rule 声明 transaction_mode
↓
ActionCandidate 携带 transaction_mode + effect_template_id
↓
TransactionResolver 按契约执行
↓
effect_template 模式调用 EffectTemplateResolver
↓
candidate_only 模式返回明确的空事务结果
↓
缺字段 / 错绑定在测试中失败
```

本次不要接 UI。
不要修改 rebuild 原型。
不要实现完整世界 Tick。
不要实现完整传闻传播。
不要实现 AI 文本。
不要实现湖湾镇完整闭环。
不要实现第七哨站长期项目。
不要把世界实体做成 Godot Node。
不要把世界状态写入 Godot 场景树。

## 0. 设计原则

### 0.1 Raw Rule 必须声明事务契约

每条 action rule 必须显式声明：

```text id="wi1r44"
transaction_mode
```

第一版只允许两种：

```text id="wfff71"
effect_template
candidate_only
```

含义：

```text id="mj6l5a"
effect_template:
该行动执行后会产生事务写回，必须绑定 effect_template_id。

candidate_only:
该行动当前只作为候选出现，执行时不产生事务写回。
```

---

### 0.2 effect_template 模式

示例：

```json id="sy9lxh"
{
  "rule_id": "give_food_to_hungry_person",
  "transaction_mode": "effect_template",
  "effect_template_id": "give_food_help_effect"
}
```

要求：

```text id="r6o3vu"
transaction_mode == "effect_template" 时，effect_template_id 必须非空。
effect_template_id 必须能在 raw effect templates 中找到。
```

---

### 0.3 candidate_only 模式

示例：

```json id="exowgq"
{
  "rule_id": "hear_rumor_seed",
  "transaction_mode": "candidate_only",
  "effect_template_id": null
}
```

含义：

```text id="a7yw8a"
该规则可以生成候选行动。
当前版本执行它时不写入 Fact / State / Relationship / Memory / Trace / Rumor。
```

注意：

```text id="6fx6f8"
candidate_only 不是错误。
但它必须是显式声明，不能靠 effect_template_id 为空来猜。
```

---

### 0.4 TransactionResolver 不再猜

禁止继续扩大：

```text id="nbqpjw"
rule_id -> effect_template_id legacy map
```

本次应删除 `_legacy_effect_template_for_rule()`，或者让它在所有测试路径中不可触发。

理想目标：

```text id="fspq41"
TransactionResolver 不认识具体 rule_id。
它只认识 transaction_mode。
```
