# 2026-06-13.3 指令：建立 world_sim 到 v0.3 线索系统的适配层

## 一、任务背景

`world_sim_mvp` 第一阶段已经完成。

当前结果：

* `world_sim` 能在无 UI 情况下自运行。
* 30 天模拟能产生世界事实、新闻、线索候选和地区标签变化。
* 第 3 天玩家行为会改变第 10 天以后的世界状态、新闻和线索。
* 所有 `LeadCandidate` 都有 `world_cause` 和 `related_fact_id`。
* 当前尚未接入 v0.3 Demo。

下一步不是做 UI，也不是扩写事件，而是建立一个独立适配层：

> 将 `world_sim` 产生的 `LeadCandidate` 转换为当前 v0.3 线索系统能够理解的线索字典。

本阶段仍然不直接重构 `story_player.gd`，不直接替换 `world_generation_v03.gd` 的主循环。

## 七、线索类型映射规则

### 1. 直接映射

```text
smoke  -> 烟柱
tracks -> 足迹
rumor  -> 传闻
river  -> 河流
```

### 2. 间接映射

```text
apparition -> 传闻
checkpoint -> 足迹
caravan    -> 烟柱
```

解释：

* `apparition` 是玩家听闻或目击的异常现象，先映射到“传闻”。
* `checkpoint` 是人为活动留下的可追查痕迹，先映射到“足迹”。
* `caravan` 通常伴随营火、道路活动、商队残迹或烟柱，先映射到“烟柱”。

不要新增 UI 类型。

本阶段只适配到 v0.3 现有四类线索。

---

## 八、数值映射规则

### freshness

`LeadCandidate.freshness` 直接映射到 v0.3 的 `freshness`。

如果缺失，则默认：

```text
0.8
```

范围限制：

```text
0.0 <= freshness <= 1.0
```

### risk

`LeadCandidate.risk` 直接映射到 v0.3 的 `risk`。

如果当前 v0.3 使用 0-100，则归一化或反归一化时必须写清楚。

建议内部统一：

```text
0.0 <= risk <= 1.0
```

如原始 risk > 1，则按 100 制处理：

```gdscript
risk = clamp(raw_risk / 100.0, 0.0, 1.0)
```

### urgency -> stage

建议映射：

```text
urgency < 0.35       -> stage 1
0.35 <= urgency < 0.7 -> stage 2
urgency >= 0.7      -> stage 3
```

如果 urgency 缺失，则根据 freshness 和 risk 推断：

```text
risk 高且 freshness 高 -> stage 2 或 3
否则 stage 1
```

## 九、方向映射规则

如果 `LeadCandidate` 中已有方向字段，则保留。

如果没有方向，根据 `region_id` 推断：

```text
mirror_lake_forest -> 西北
border_town        -> 东南
old_ruins          -> 北方
```

这只是临时表现层映射，不代表真实地图完成。

方向字段必须稳定，同一 seed 下相同 region 生成相同方向。

## 十、标题与描述生成规则

不要写长文案。

标题要短，能让玩家知道线索是什么。

示例：

```text
smoke + scarcity_high_and_smuggler_raid
-> 远处商队烟迹

tracks + beast_migration
-> 林中迁徙足迹

rumor + information_market
-> 镇上的低声传闻

apparition + cult_ritual_and_mystic_pressure
-> 关于旧遗迹异象的传闻

checkpoint + wardens_patrol
-> 道旁新设的盘查痕迹

river + herb_depletion
-> 河岸药草被采空的迹象
```

描述可以 1 句，不要超过 40 个汉字。

描述必须体现 `world_cause`，不能是无因果泛文本。

## 十一、行动提示映射

`LeadCandidate.possible_actions` 转换为 v0.3 可显示的行动提示。

不要继续使用“稳/赌/退”。

如果原始 action 是：

```text
investigate
protect
rob
ignore
observe
interrupt
follow
report
hunt
set_trap
warn_travelers
```

映射为中文行动名：

```text
investigate     -> 调查
protect         -> 护送
rob             -> 劫掠
ignore          -> 放任
observe         -> 观察
interrupt       -> 打断
follow          -> 跟随
report          -> 报告
hunt            -> 狩猎
set_trap        -> 设陷
warn_travelers  -> 警告旅人
```

如果遇到未知 action：

```text
记录 warning，但不要崩溃。
映射为“谨慎查看”。
```

## 十二、保留世界因果字段

适配后的线索必须保留：

```text
world_cause
related_fact_id

source_faction_id

```

这些字段用于后续：

3. 验证线索不是随机抽卡。
4. 后续接入 `resolve_lead()`。

如果任何适配后的线索缺少 `world_cause`，测试必须失败。
