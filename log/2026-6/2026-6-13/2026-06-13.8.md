# 2026-06-13.8 指令：建立湖湾镇粮食危机最小因果链

## 一、任务目标

本任务建立 Chronicle 的第一条微观世界因果链：

```text
湖湾镇粮食压力
↓
粮价上涨
↓
老陈债务与家庭压力上升
↓
陈米饥饿上升
↓
陈米去废弃粮仓拿走发霉麦子
↓
老陈发现家庭危机后关店
↓
店铺、人物、物品留下痕迹
↓
系统生成可叙述状态
```

本任务不是写“陈米偷粮事件”。

本任务不是扩写事件池。

本任务要让世界状态自然运行到一个局面，使得“陈米抱着发霉麦子坐在店门口”成为可追溯的结果。

---

## 二、任务边界

本任务只做无头世界模拟。

不要接正式 UI。

不要修改当前 Demo 行为。

不要修改 `story_player.gd`。

不要写剧情事件池。

不要做战斗、装备、成长、人生模式、纪事系统或 AI 文本。

不要把这条链写成固定触发事件。

## 五、核心原则

### 1. 不写事件卡

禁止这样做：

```text
随机事件：陈米偷粮
选项：帮助 / 举报 / 无视
```

必须这样做：

```text
地区粮食压力上升
家庭食物不足
老陈债务压力上升
陈米饥饿和恐惧上升
废弃粮仓存在发霉麦子
陈米执行寻找食物行为
行为结果产生 WorldFact
WorldFact 留下 Trace
Trace 被投影为可叙述状态
```

### 2. 文本不是事实

可以生成调试用描述，但事实必须在结构里。

例如：

```text
陈米把袋子往身后藏了藏
```

不能只存在于文本里。

它必须由以下状态支撑：

```text
chen_mi.inventory contains spoiled_grain
chen_mi.fear >= threshold
chen_mi.memories contains took_spoiled_grain_secret
trace child_hiding_bag exists
location old_chen_shop present_npcs contains chen_mi
```

### 3. 世界事实必须可追溯

最终观察输出必须能回答：

```text
陈米为什么偷粮？
粮从哪里来？
老陈为什么关店？
店门口为什么有涨价告示？
玩家为什么能看见她藏袋子？
```

## 九、每日更新规则

每日 world_sim tick 后，必须推进湖湾镇微观链。

推荐顺序：

```text
1. 读取宏观粮食压力
2. 更新湖湾镇粮价
3. 更新老陈家庭食物、债务和压力
4. 更新陈米饥饿与恐惧
5. 判断陈米是否需要寻找食物
6. 如果触发，执行陈米寻找食物行为
7. 如果废弃粮仓有发霉麦子，陈米取得发霉麦子
8. 写入 WorldFact
9. 修改 NPC、地点、物品状态
10. 生成 Trace
11. 老陈根据家庭危机决定是否关店
12. 根据 Trace 生成 NarratableState
```

### 1. 粮价上涨

当宏观粮食压力满足：

```text
scarcity >= 70 或 food <= 50
```

湖湾镇粮价上升。

写入事实：

```text
lake_town_food_price_rising
```

生成 Trace：

```text
price_rise_notice
```

### 2. 老陈家庭压力

老陈压力受以下因素影响：

```text
粮价上涨
家庭食物下降
债务上升
陈米饥饿
店铺库存不足
```

当压力超过阈值：

```text
old_chen.stress >= 70
```

老陈可能关店。

写入事实：

```text
old_chen_closed_shop_due_to_family_crisis
```

生成 Trace：

```text
closed_shop
```

### 3. 陈米寻找食物

当满足：

```text
chen_mi.hunger >= 70
old_chen.family_food <= 20
old_chen.money <= 低阈值
```

陈米进入寻找食物行为。

优先顺序：

```text
1. 家中有食物：吃家中食物
2. 父亲有钱：请求父亲买食物
3. 有可求助对象：求助
4. 废弃粮仓有发霉麦子：拿走发霉麦子
5. 否则：忍耐，饥饿继续上升
```

当前 MVP 只需要实现第 1、2、4、5 项。

当陈米从废弃粮仓拿走发霉麦子时：

写入事实：

```text
chen_mi_took_spoiled_grain
```

状态变化：

```text
chen_mi.inventory += spoiled_grain
chen_mi.fear += 20
chen_mi.health 或 disease_risk 受到影响
abandoned_granary.spoiled_grain_stock -= 1
old_chen_shop.state.family_crisis = true
```

生成 Trace：

```text
child_hiding_bag
spoiled_grain_bag
grain_dust_on_sleeve
granary_missing_grain
```

### 4. 可叙述状态生成

当同时满足：

```text
old_chen_shop is closed
price_rise_notice exists
chen_mi present at old_chen_shop
chen_mi has spoiled_grain
child_hiding_bag trace exists
```

生成 NarratableState：

```text
chen_mi_hiding_spoiled_grain_scene
```

该状态必须包含：

```text
source_fact_ids:
- lake_town_food_price_rising
- chen_mi_took_spoiled_grain
- old_chen_closed_shop_due_to_family_crisis

trace_ids:
- closed_shop
- price_rise_notice
- child_hiding_bag
- spoiled_grain_bag
```
