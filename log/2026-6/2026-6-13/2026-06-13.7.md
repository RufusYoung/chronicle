# 2026-06-13.7 指令：改进 world_news 去重、阶段化与摘要生成

## 一、任务目标

本任务改进 `world_sim` 的新闻生成层。

当前观察器已经证明 world_sim 可以持续生成世界事实、新闻、线索和适配线索，但观察输出显示每日新闻存在明显重复：

```text
守望者突袭走私据点
走私者截走补给
回声教团采集草药
回声教团带出遗物
旧日遗迹出现异象
```

这些事项背后有真实 `WorldFact` 支撑，但作为前台新闻读起来像每日规则循环。

本任务目标：

```text
保留完整 WorldFact
减少重复 WorldNews
让新闻体现阶段变化
让连续事件形成摘要
让观察输出更像“世界消息”，而不是“规则日志”
```

## 四、核心原则

### 1. WorldFact 继续完整记录

每天发生的事实仍然写入 `WorldFact`。

不要为了减少新闻而删除事实。

### 2. WorldNews 不是事实日志

`WorldNews` 是玩家或开发者“听见的消息”。

它需要筛选、合并、降频和阶段化。

### 3. 重复事项不能每日原句播报

错误形式：

```text
Day 1：守望者突袭了边境镇的走私据点。
Day 2：守望者突袭了边境镇的走私据点。
Day 3：守望者突袭了边境镇的走私据点。
```

正确形式：

```text
Day 1：守望者突袭了边境镇的走私据点。
Day 3：边境镇的走私据点连续遭到清剿，守望者开始设立临时盘查点。
Day 7：走私者转入暗线活动，边境镇传闻开始增多。
```

### 4. 新闻必须体现“新变化”

新闻优先展示：

```text
新出现的地区标签
势力关系显著变化
资源进入危险阈值
同类事件累计达到阶段点
某条危机升级
某条危机缓解
A/B 测试注入造成的差异
```

## 六、WorldNews 去重机制

为每条新闻生成稳定的 `news_key`。

建议格式：

```text
region_id + actor_faction_id + action_type + world_cause
```

示例：

```text
border_town|wardens|suppress_smugglers|warden_security_response
border_town|smugglers|raid_supplies|scarcity_high_and_smuggler_raid
old_ruins|echo_cult|perform_ritual|cult_ritual_and_mystic_pressure
```

新增或维护新闻历史索引：

```text
news_key
first_day
last_day
count
last_fact_id
related_fact_ids
stage
last_text
```

同一 `news_key` 在短时间内重复出现时，不再每天创建同句新闻。

## 七、冷却规则

建议设置：

```text
同一 news_key 默认 3 天冷却
```

冷却期间：

```text
WorldFact 继续记录
news_key 计数继续增加
不生成重复 WorldNews
```

但以下情况允许突破冷却：

```text
1. 相关数值跨过重要阈值
2. 地区标签变化
3. 累计次数达到阶段点
4. 事件结果从恶化变为缓解
5. 测试注入造成明显差异
```

---

## 八、阶段化规则

同一类连续事件应产生阶段变化。

### 1. 走私补给线

示例阶段：

```text
首次：一批补给在边境镇外被截走。
累计 3 次：边境镇外的补给线多次遇袭，粮车开始绕路。
累计 5 次：走私者控制了部分暗线，镇上粮价继续上涨。
严重阶段：边境镇粮食见底，守望者开始强制征用民粮。
```

### 2. 守望者清剿

示例阶段：

```text
首次：守望者突袭了边境镇的走私据点。
累计 3 次：守望者连续清剿走私据点，路口盘查变多。
累计 5 次：走私者转入暗线，镇上公开冲突减少但传闻增多。
```

### 3. 回声教团活动

示例阶段：

```text
首次：回声教团从遗迹深处带出了遗物。
累计 3 次：旧日遗迹附近的夜间回声越来越频繁。
累计 5 次：镇民开始梦见同一片倒悬的湖面。
严重阶段：旧日遗迹的神秘压力接近失控。
```

### 4. 草药采集 / 森林资源压力

示例阶段：

```text
首次：森林中的稀有草药被成批采走。
累计 3 次：湖岸药草变少，采药人开始深入危险地带。
累计 5 次：草药短缺影响了镇上的伤病治疗。
```

## 九、新闻摘要输出

观察器中每日新闻应分为两类：

```text
当天新新闻
连续事件摘要
```

示例：

```text
当天新新闻：
- 边境镇粮食跌破危险线，集市上出现空货架。

连续事件摘要：
- 走私者袭击补给线已持续 5 次，边境镇粮食压力继续升高。
- 回声教团活动已持续 4 次，旧日遗迹神秘压力维持高位。
```

观察器每日最多展示：

```text
当天新新闻 3 条
连续事件摘要 3 条
```
