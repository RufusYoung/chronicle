# 2026-06-13.6 指令：建立 world_sim 开发者观察工具

## 一、任务目标

本任务建立一个开发者观察工具，让用户能直接观察 `world_sim` 的世界演化结果。

目标不是接入正式游戏 UI。

目标不是改当前 Demo。

目标是让开发者看到：

```text
当前第几天
地区状态如何变化
势力状态如何变化
每天生成了哪些 world_news
每天生成了哪些 LeadCandidate
LeadCandidate 适配后变成哪些 v0.3 线索
测试注入后世界如何不同
```

本任务属于开发工具层 / 调试层。

## 七、world_sim_observer.gd 功能要求

`world_sim_observer.gd` 提供一个纯脚本观察器。

至少实现：

```gdscript
func run_baseline(days: int = 30) -> Dictionary
func run_with_test_injection(days: int = 30, injection_day: int = 3) -> Dictionary
func build_daily_snapshot(state: Dictionary) -> Dictionary
func build_region_summary(state: Dictionary) -> Array
func build_faction_summary(state: Dictionary) -> Array
func build_news_summary(state: Dictionary, day: int) -> Array
func build_lead_summary(state: Dictionary, day: int) -> Array
func build_adapted_lead_summary(state: Dictionary, day: int) -> Array
func compare_runs(a_result: Dictionary, b_result: Dictionary) -> Dictionary
func export_markdown_report(result: Dictionary, output_path: String) -> void
```

如果现有 `WorldSimState` 不是 Dictionary，可以在观察器内部做安全转换。

## 八、观察输出必须包含

### 1. 每日摘要

每一天至少输出：

```text
Day 1
地区摘要：
- mirror_lake_forest: danger/order/scarcity/mystic/food/herbs/relics/information
- border_town: danger/order/scarcity/mystic/food/herbs/relics/information
- old_ruins: danger/order/scarcity/mystic/food/herbs/relics/information

势力摘要：
- wardens: power/wealth/hostility_to_player/goal
- smugglers: power/wealth/hostility_to_player/goal
- echo_cult: power/wealth/hostility_to_player/goal

当天新闻：
- ...

当天 LeadCandidate：
- type / world_cause / related_fact_id / region / risk / urgency

当天适配后 v0.3 线索：
- 中文类型 / title / direction / freshness / risk / possible_actions
```

### 2. 30 天总览

必须输出：

```text
30 天后地区最终状态
30 天后势力最终状态
world_fact 数量
world_news 数量
LeadCandidate 数量
适配后 v0.3 线索数量
线索类型分布
地区 tag 变化
```

### 3. A/B 对照

必须运行两组：

```text
A 组：无模拟干预
B 组：第 3 天测试注入 help_faction(state, "wardens", "border_town")
```

注意措辞：

必须称为：

```text
测试注入
模拟干预
A/B 对照行为
```

不得称为：

```text
玩家选择
玩家行为
玩家干预
```

对比输出必须包含：

```text
第 10 天是否已出现差异
第 30 天地区状态差异
第 30 天势力状态差异
world_news 数量差异
LeadCandidate 数量差异
适配后线索数量差异
线索签名是否不同
```

## 九、导出文件要求

观察器运行后，应导出一个 Markdown 文件：


```markdown
# world_sim 观察输出

## 1. 运行设置

## 3. 每日摘要

### Day 1
### Day 2
...
### Day 30

## 4. 第 3 天测试注入后 30 天总览

## 5. A/B 差异

## 6. 适配后线索样例

## 7. 结论
```

不要让输出文件过度冗长。

每日摘要可以控制在每日至多：

```text
3 条新闻
3 条 LeadCandidate
3 条适配后线索
```

完整数据可保留在测试输出中，但 Markdown 观察文件要可读。
