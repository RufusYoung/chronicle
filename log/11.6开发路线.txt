# 路线图（从薄片到完整循环）

## 阶段 A｜把“1 小时纪事”跑起来（最小可玩竖切）

**目标**：点一下推进一小时，屏幕出现一段“这一小时发生了什么”的短篇纪事，并附 1–2 个抉择，能反映地区暖/险权重、天气/状态的最基础影响。

**需要做的**

* 数据面：统一地区 Schema（`tone: {warm, peril}`；季节/昼夜微调；风味词库&口吻矩阵的最小版）。
* 逻辑面：`HourTick()` 管线最小实现：`取地区 → 读慢变量 → 抽信号 → 织句器 → 输出纪事段落 + 选项`。
* UI 面：一个“继续一小时”按钮 + 文本面板 + 选项按钮（先简单）。
* 技术约束：只细算“当前地区”，邻区与全球都用宏观占位数据避免卡顿。

**验收点（你自己测）**

* 在一个“90% 暖”的地区与一个“100% 险”的地区连续点 10 次，纪事气质明显不同。
* 选项能改变下一小时的叙事走向（例如“停下休息”让语气变得缓和/睡眠积累下降一点点）。

---

## 阶段 B｜加入“生存条”：睡眠/食物/负重/理智（轻量）

**目标**：小时推进对角色状态产生真实影响，纪事里能“侧写”这些变化。

**需要做的**

* 状态组件：`SleepDebt`（未睡小时数）、`FoodStock`（6 小时 -1 单位）、`CarryLoad`、`Sanity`。
* 睡眠质量公式（理智×身体×环境）与四档疲惫惩罚；简单疾病与寒冷门槛。
* 纪事侧写：状态变化会改变叙事用词（冷/困/饥 的意象），同时提供悬浮数值或日志细节。

**验收点**

* 不睡觉连推 24 小时，纪事文字变“迟钝/头胀/失措”，数值出现疲惫惩罚。
* 没粮食 12 小时后，体质/理智缓慢掉且文字有“空腹/虚弱”的暗示。

---

## 阶段 C｜装备系统落地：**双词条 + 三段状态 + 三种耐久**

**目标**：穿什么，体验立刻不同；装备会磨损，但不同装备“坏法”不同，修理可逆。

**需要做的**

* Item Schema 固定：战斗词条 & 探索词条；`state: Healthy/Worn/Broken`；`durability: gradual/charge/eternal`；`decay_per_hour/uses/shock_rules`；`repair_tags`。
* 判定：探索判定先看探索词条；极寒/坠落等“冲击事件”触发耐久降档检定；修理检定（时间 + 材料/金钱 + 技艺标签）。

**验收点**

* 同一路夜行：灰熊皮披风（gradual 低衰减 + 抗寒高）与麻布短披（高衰减 + 抗寒低）→ 纪事文本、失败率、耗时明显差异。
* 用完 3 次的“照明石”（charge）会暗；“铭文护符”（eternal）通常不坏，但在极端事件后降一档。

---

## 阶段 D｜印记与风格：**成长链清晰可感**

**目标**：行为→印记进度→属性点→风格质变（被动 + 属性再权重）；开局的“背景 = 风格雏形”，玩家可选 1 个起始印记。

**需要做的**

* 起始创建：背景决定基础属性/起装/人脉/风格雏形；可从 3–5 个印记里选 1 个起始印记。
* 印记表：每个印记定义“什么行为涨进度 / 阈值 / 奖励属性点 / 副作用可能”。
* 风格表：由“印记集合 + 属性阈值”触发，给 1–2 个被动（如旅程耗时-5%、夜友好度+等）与少量属性再权重。

**验收点**

* 玩家开局不同背景 + 不同起始印记，2–3 小时内能升出**明确的 +1 属性点**；另一路风格没有解锁。
* 同一条路玩两遍，一次打工搬运多、一次写见闻多 → 风格走向不同，纪事口吻产生细微差别。

---

## 阶段 E｜NPC：性格/情绪/关系/恩怨与“约定”

**目标**：NPC 不是商店，是“人”；好感、怨恨、约定可以兑现或违约，并把你推入地区经济或边境风波。

**需要做的**

* 性格向量（谨慎/鲁莽、利己/利他…）、身份立场（势力/职业/教派…）、关系强度、情绪状态机（冲量+衰减）。
* 恩、怨、约定三类互动；约定带期限与违约惩罚；价格/口吻/事件权重受关系影响。
* 小批量 NPC 样例（湖上商贩/林地向导/官吏），每个 2–3 条可见“兑现链”。

**验收点**

* 与“湖上商贩”先结恩（帮他护送/修船）→ 买价下降/口吻变暖；违约一次→ 价格反弹、月报点名“失信”。
* “林地向导”在高好感时，为你缩短旅程耗时（可见可感）。

---

## 阶段 F｜月报与“宏观世界”：势力/供需/灾象

**目标**：小时只讲“此时此地”；月报讲“天下风云”，并驱动下月的小时素材来源。

**需要做的**

* 宏观变量：供需价差、征税压力、边境张力、迁徙趋势、信仰动荡、气候带移动等。
* 月报生成器：以势力/地区为单位，写 3–5 条风向，并把“信号”写回下月小时权重。
* 订阅邻区：当前地区 + 邻区 1–2 个做细粒度步进，其余跑马尔可夫宏观。

**验收点**

* 某港口月报“海盗猖獗/通行税上调”→ 下月海路耗时/风险上升；你若在当地做“镇压/疏通”→ 下下月月报有所缓解。

---

## 阶段 G｜存档/复盘与“纪事输出”

**目标**：一局结束（死/老化/理智崩/大事件）后，导出一篇“奇幻传记文本”。

**需要做的**

* 存档：状态树与随机种子；可重放关键小时。
* 纪事拼装：把暗记日志按时间轴重写为可读文本；提供导出（txt/markdown）。
* “人生总结”页：印记/风格演化线、关键 NPC、重大抉择、最爱装备等。

**验收点**

* 杀一局档，能在“人物编年”里读到你这局的关键线（看得懂、愿意分享）。

# 工程与内容协同（你现在就能做的准备）

**目录建议**

```
res://
  data/
    regions/            # 地区、邻接、tone、风味词库
    items/              # 装备与消耗品 Schema + 样例
    marks_styles/       # 印记/风格表
    npcs/               # NPC 样例与关系模板
  scripts/
    core/               # HourTick, RegionSim, Chronicle, EventSynth
    systems/            # Survival, Items, Marks, Styles, NPC, MacroWorld, MonthlyReport
    gen/                # Registry, JsonUtil, DeepMerge, WeightedPick
  ui/
    panels/             # 纪事面板、选项、状态栏、月报页
```

**工具与保障**

* **Schema 校验器**：在 Editor 下按钮一键校验 JSON（缺字段/错类型直接报）。
* **内容 Linter**：风味词库里禁词/重复/错拼提示；口吻矩阵缺项提醒。
* **随机种子重放**：重放同一小时段以便调试叙事差异。
* **性能预算**：小时推进 ≤ 8ms（PC）/ ≤ 16ms（移动）；邻区订阅 ≤ 2 个。

# 优先级与时间分块（建议顺序）

1. A 薄片（1–2 天，专注通路与文段最低可用）
2. B 生存条（1–2 天，立刻让文字“有体温”）
3. C 装备（2–3 天，双词条+耐久三型+修理）
4. D 成长（2–3 天，印记加点→风格质变）
5. E NPC（3–5 天，先做 2–3 个高辨识度样例）
6. F 月报（3–5 天，宏观变量+回灌小时）
7. G 存档与纪事输出（2–3 天）

> 你可以在每个阶段结束就发一版给朋友试玩；文本“质感”会随着风味词库与口吻矩阵扩充自然变好，不必一开始就堆量。

# 现在立刻可以开始的 3 件小事

* 把**两个对比鲜明的地区**定稿：一个 90% 暖，一个 100% 险；各写 30 组风味词（意象词优先）。
* 录入 **5 件装备样例**（三种耐久各至少一件）：灰熊皮披风、麻布短披、照明石、铭文护符、登山扣绳。
* 定 **8 个起始印记** 和 **3 个风格雏形**（对应 3 个背景），保证前 2–3 小时就能升出 1 点属性。
